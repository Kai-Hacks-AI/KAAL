# Mnemonics as part of the semantic model: PLAN

Owner: Engineering for now (placement open, see plan.md). Status: PLAN only. Nothing here adds a Node, an edge type, a check, a promotion or a release. Ids below are provisional until the Nodes exist.

## Intent
One KAAL Node states what the Owner's mnemonics are, and every mnemonic definition traces back to it through a well-defined, typed Edge. That makes mnemonics retrievable KAAL-wide from the graph itself (incoming Edges), with no inventory file and no index that has to be kept. Mnemonics stay guides, never capability names.

Direction (Owner): mnemonic learning is pulled by kaal-product and kaal-roadmap (lean pull), so the Changes below are launched by that demand and not pushed from here.

See `plan.md` for the semantic model, placement and the edge name.
