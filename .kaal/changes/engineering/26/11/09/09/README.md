The Boundary Engine's detectors (`token-sequence`, `call-with-literal`) now read syntax trees too (Owner, 9 Nov: no brittle setups; use over build, the parsers are existing libraries): TypeScript for JS and TS, commonmark for Markdown code blocks, `yaml` and JSON for data. - Discovery is complete or refused: every `test` or `it` call in the syntax tree (also `.skip`, `.only`, multiline) must have a literal Case title, an aliased or passed `test` is refused, and a method such as `re.test(` is ignored.
