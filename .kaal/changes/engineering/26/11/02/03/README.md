Map DevOps against KAAL so that KAAL serves DevOps. DevOps is treated like PDCA:
a Process in which KAAL Capabilities are delivered, not a Capability itself. The
mapping starts from the eight DevOps stages (Plan, Code, Build, Test, Release,
Deploy, Operate, Monitor) and shows, per stage, what serves it, how well, and
where the gaps are, separating concept coverage, implementation readiness and distribution readiness. It also states how the DevOps cycle relates to PDCA and GLUE.
