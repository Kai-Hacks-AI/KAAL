# Retro

## Learned

Tests that compile into dist-test must reach package files through the built surface, not relative to src, or the kaal/ directory is missing. A Node-typed Extension slots into the installer with only a test expectation to update.

## Liked

The one-way shape held: the package asks KAAL by process and imports nothing of it, so the controls shrank to Git reading plus delegation.

## Lacked

No parity run against the Bash scripts on live PRs; verdict equivalence rests on case tests until C3 runs the CLI in CI.

## Longed

For the review to precede the Work seal, so what the Observer finds can still change the Work.
