## Findings

### F1. Reject a dangling carriers symlink when checking an attempt

Anchor: R5, R8, and Architecture's promise that check succeeds only when no symlink or stray file is in the record.

In packages/kaal-collecting/skills/kaal-collecting/scripts/collect.mjs:208-229 (and its installed projection), the checks of the carriers directory use existsSync(). For a dangling symlink this returns false: the directory-kind check is skipped, walk returns immediately, and the unreached-carriers check is skipped too. Consequently check reports success for an empty reached record or an unreached record holding a dangling carriers symlink.

Reproduced on the shipped script: make an empty reached attempt and an unreached attempt, add a carriers symlink to a nonexistent target under each, then run check. Exit 0: "3 attempts, every carrier matches" (the third attempt held real producer-made carriers).

Resolve: inspect the directory entry without following its target, reject a dangling link as well as a live link, and cover both empty-reached and unreached records in acceptance. A corrupt record must return nonzero.
