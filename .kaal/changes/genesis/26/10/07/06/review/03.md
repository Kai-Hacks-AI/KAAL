   ```yaml
   compatibility: "Needs Node.js 20 or later, and the kaal\u002dsealing Skill installed beside this one. Written for a KAAL directory, by default .kaal/, whose changes/ holds the change records."

Add acceptance for the escaped equivalent declaration and for comment text outside the scalar. This requires no new Core meaning or dependency field.
