## Persistence of learning (Owner clarification, 3 Nov)

- **ACT persists learning in the context where it occurred.** The context owns the knowledge it persists.
- **Learning owns retrieval and learning practices**, and retrieves that knowledge **without creating a duplicate authoritative store.** Analysis and decision-making are further learning activities, and new learning is persisted in its own owning context.
- **Process owns PDCA's semantics.** A later PLAN can consume the resulting knowledge.
- **Not introduced:** a mandatory central ACT record, a duplicate store, or a new capability.

## What this changes in Process's text

Read now as: persistence stays in the owning context, and Learning owns retrieval and practices. The same section's "no decision is made here" is superseded by this record.
- 03/02 open questions 1 to 3 are answered here.
