# RATIFICATION

RATIFICATION is a mnemonic for disciplined change:

```
R  Requirements
A  Architecture
T  Test
I  Intend
F  Formalized

I  Implement
C  Code
A  And
T  Test
I  Its
O  Outcome
N  Neat
```

It distinguishes what is established before implementation from implementation and the observation of its outcome. The first Test is the outer one: it is defined before implementation, not run repeatedly during it.
