# Learning from an experience — Engine adapter

This file carries this Engine's concerns — the discovery path, the routing
metadata, and a pointer — which is what an adapter is for. What it must not carry
is the KAAL learning capability as its only home, because KAAL's knowledge may
not depend on one supplier's discovery path.

**The capability is defined at [`skills/learning/SKILL.md`](../../../skills/learning/SKILL.md). Read it and follow it.**

A different Engine needs a different adapter, or none. Neither holds the
capability; both point at the same file. See
`learning/0017-a-failure-does-not-name-the-next-rung.md` and
`learning/0018-use-what-is-already-there.md`.
