# Learning from an experience — Engine adapter

This file carries nothing. It exists because this Engine discovers skills at
`.claude/skills/`, and KAAL's knowledge must not depend on one supplier's
discovery path.

**The capability is defined at [`skills/learning/SKILL.md`](../../../skills/learning/SKILL.md). Read it and follow it.**

A different Engine needs a different adapter, or none. Neither carries the
capability; both point at the same file. See `learning/0017-a-failure-does-not-name-the-next-rung.md`.
