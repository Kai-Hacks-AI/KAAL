# testing/C81 the runner runs the export form of a Case

`kaal-testing run` executes a Case file that exports a callable `run` as one test, attributed to its own file, so a Case in the export form reads GREEN, RED or UNKNOWN from what ran and not `empty-inventory`. Requested by the release capability for hold Act evidence (`release/C135`); the Owner chose advisory first for that Change, and this is the Testing side of it. Nothing is wired and no check is required.
