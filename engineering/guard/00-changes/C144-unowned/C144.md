# guard/C144 unowned

Once a repository has adopted `kaal-guard.json`, a changed file that no registration covers is a Guard failure, not a silent pass. A root `kaal-guard.json` is how repo-level files are owned. First slice only: it judges and reports; it wires no hook, workflow or ruleset.
