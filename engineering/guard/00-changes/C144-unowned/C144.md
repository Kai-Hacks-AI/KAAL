# guard/C144 unowned

Once a repository has adopted `kaal-guard.json`, a changed Solution or Change file that no registration covers is a Guard failure, not a silent pass. Delivery, as the repository declares it (KAAL: `.github`, `.githooks`, `.kaal` and root files), is not judged and is never owned through Guard, and Guard names none of it; engineering areas are Solution and register like products; the WIRE protects the engine. First slice only: it judges and reports; it wires no hook, workflow or ruleset.

Decided by the Owner on 2026-11-18, option C of the three offered (run everything, run only the base, refuse). The root-file fallback of the first draft is replaced by the Delivery rule after the Owner set out the three layers the same day.
