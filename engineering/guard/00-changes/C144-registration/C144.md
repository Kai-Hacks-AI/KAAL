# guard/C144 registration

**kaal-guard is opt-in.** It guards only what declares itself with a `kaal-guard.json`.

Guard guards only folders that have a declaration. Inside a declared folder, a changed file that none of the folder's checks cover is a Guard failure, not a silent pass, and an empty `kaal-guard.json` is a failure too. A changed file with no `kaal-guard.json` above it is not Guard's business. Registration says what Guard executes, never where, and Guard knows no Delivery location. First slice only: it judges and reports, and wires no hook, workflow or ruleset.

Decided by the Owner on 2026-11-18 (the Owner's correction of 15:21 narrowed option C to declared folders); reviewed by the CPO on #1949.
