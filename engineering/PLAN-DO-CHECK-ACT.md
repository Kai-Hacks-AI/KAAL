# PLAN DO CHECK ACT

Priorities Lead Agents Next Development, Optimising Code Health, Enabling Clear Knowledge About Collected Testing.

The initials spell the cycle: P-L-A-N, D-O, C-H-E-C-K, A-C-T. Each phase of the operating cycle is one part of the sentence:

- **PLAN**: Priorities Lead Agents Next. Priorities determine what agents work on next.
- **DO**: Development Optimising. Development focuses on optimisation.
- **CHECK**: Code Health Enabling Clear. Testing establishes clarity about code health.
- **ACT**: Knowledge About Collected Testing. Knowledge is derived from collected testing evidence and feeds subsequent planning.

PLAN DO CHECK ACT is a mnemonic for the operating cycle. It owns no document, no capability and no control. The responsibilities stay where they are: create Plan is a directive control, verify Plan is a detective control, Testing owns execution and evidence, and ACT uses collected evidence to support learning and improvement.
