# BAND

Bare Agents Need Direction.

An agent working Bare, with no standing instructions, needs direction to work well. Bare echoes the first level of BASS ([BASS](../packages/kaal-engineer-skill/payload/BASS.md)).

BAND is a mnemonic. It owns no instruction and no level.
