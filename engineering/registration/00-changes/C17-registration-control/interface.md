# engineering/C17 Intent, Requirements, Architecture (drafts)

The numbers are the next free ones found on `main` on 18 Nov 2026 (no `engineering/I`, `A`, `G` or `CTL` exists; the highest `F` is `engineering/F35`, the highest Change `engineering/C16`). Cases T1022 to T1031 were reserved by the release thread.

- **engineering/I1** Everything that KAAL's Solution consists of says what Guard is to run for it. A capability, an Engineering area and a Change is never silently outside Guard: each has a `kaal-guard.json` with at least one executable check.
- **engineering/F36** (serves I1). A *place* is one of: a capability root `packages/<name>/`, an Engineering area root `engineering/<name>/`, and a Change folder `<place>/00-changes/C<n>-<slug>/` of either. Anything else is not a place. No Delivery location (`.github`, `.githooks`, `.kaal`) and no root file is a place, and no list of them is kept: places are named by what they are, never by what they are not.
- **engineering/F37** (serves I1). A place registers through one `kaal-guard.json` at its own root: JSON with a `checks` array of at least one check, each with a non-empty `id` and a non-empty `run` command, ids unique in the file. A check may be RED by design; registration declares what Guard executes, never where or at which stage. A violation names the place, the file and the rule: `missing`, `unreadable`, `no-checks`, `check-without-id`, `check-without-run`, `duplicate-id`.
- **engineering/F38** (serves I1). Two scopes. For a pull request, the places judged are those that hold a changed file; a place no changed file touches is not judged, and a change that touches only Delivery assets or root files judges no place. The inventory scope judges every place and reports. A Change folder and the area or capability that holds it are both places of a file inside the folder.
- **engineering/F39** (serves I1). The control is detective. It reads files, never runs a registered check, writes nothing and needs no network. It exits non-zero when there is a violation and zero otherwise; what to do with that is a decision of the integration controls.
- **engineering/A1** (addresses F36 to F39). `engineering/registration/check.mjs` exports `places`, `verify` and `inventory` and has a command line (`--changed <file-list>`, `--all`). The control `engineering/CTL1 verify Registration` is declared in `engineering/registration/04-controls/CTL1-verify-registration/`. The area and each Change folder register themselves.
- **engineering/CTL1** `verify Registration`, detective, status designed on this PLAN, `has: [engineering/I1]`.
