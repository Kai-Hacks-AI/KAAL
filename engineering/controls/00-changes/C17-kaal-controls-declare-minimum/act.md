# C17 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C17 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

The brief's "CTL1 to CTL21" met the repository in the PLAN, not in the DO: only ten controls were registered, and saying so first kept the Change honest and small. The throwaway worktree paid for itself twice, by showing that a corrective control with one real run broke the shape the PLAN asked for, and by naming the ten release Cases that would go RED before anyone met them in CI.

## Learned

A front matter line is a contract with every Case that pins the finder's listing or compares a control file with its draft. Adding `evidence` to a control meant touching ten Cases of another capability, and six of them strip `status` while four compare the whole file, so the first count was wrong until it was run. The converter is small because it copies: a record is the runner's outcome plus what it ran against, and `base` appears only for a test RED on the base report and GREEN on the head.

## Lacked

Records and owners. No control has a recorded run, so every minimum shows 0 of N and none claims `tested`; the numbers are a starting point that each control's owner has not yet confirmed. A control that claims `running` today, release/CTL1, has no real-run record to show it.

## Longed For

The first real records, from runs that already happen (the hotfix exercises, a refused SYNC), written with the converter and linked from the ACT of the Change that made them. Then the flag and the WIRE rule that points a flip at Tested evidence, and the Dispatcher's go-hot gate as its own control's minimum, each in the capability that owns it. With the controls package's state line (controls/C16) the report then shows how far each control has come.

## Closed

The Gap of this Change, G94, is closed by Cases T1094 to T1097 and T778, green in the collector with the ten release Cases repaired. The engineering suite fails the same 16 Cases as `main` and no other.
