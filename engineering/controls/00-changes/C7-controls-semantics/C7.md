# controls/C7 control semantics

Introduces the semantics of directive, preventive, detective and corrective controls as a candidate Agent Skill authored in Engineering, with the scenarios that demonstrate that an agent given only the Skill distinguishes and combines the four types. It is an incubation: no package, no Capability Node, no Control Definition, no deployment of the Skill.
