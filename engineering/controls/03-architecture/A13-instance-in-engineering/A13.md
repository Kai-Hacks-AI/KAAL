# controls/A13 instance-in-engineering

`engineering/controls/stations.json` is read by whoever installs the workflow and the rulesets, and by `verify Stages` (release/C70) when it compares the registry with the rulesets. Its branches equal the branch patterns of the ruleset source of the station in `engineering/release-management/05-src/wiring/rulesets/`, which stays release's. Engineering supersedes `.kaal/controls` until the package is published and deployed there.
