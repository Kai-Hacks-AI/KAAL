# controls/F27 kaal-instance-map

Engineering keeps KAAL's instance of the Control Enforcement Unit in code in `engineering/controls/stations.json`: the name of the App, "KAAL Inspector", its App ID, and for each station the ruleset that enforces it and the branches it covers. The first slice has one station, Integrating, with the branches of `integrating.json`. The App ID is `null` until the App exists, and is then a positive integer. It is not a secret. The private key is the only secret and is a GitHub secret that no file names the value of. A switch such as `KAAL_SYNC_APPROVE` stays a variable that its control declares.
