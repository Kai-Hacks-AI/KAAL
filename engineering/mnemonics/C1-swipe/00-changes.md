# SWIPE mnemonic: Change (A to B)

This is `mnemonics/C1`, a PLAN Change. It ships no definition yet. It adds one mnemonic, SWIPE, in the shape of DISCO, BAND and GUITAR. The mnemonic was set by the CPO on pull request 1476 as the memorable name of what the capability `Show WIP` does. The capability keeps its name.

## A: the present

The mnemonic exists only in a draft. `engineering/` holds no `SWIPE.md`, so the sentence cannot be found through the KAAL Definition type.

## B: the target

`engineering/SWIPE.md` is a KAAL Definition: Show Work In Progress Expectations. We swipe through the open pull requests to see the expected next move of each. It states that it is a mnemonic for the capability `Show WIP`, which keeps its name, and that it owns no instruction, no capability and no control. See [requirements.md](requirements.md) and [testing.md](testing.md).

## Order and constraints

This Change travels alone, in its own collector `kaal/mnemonics/swipe`, and not with pull request 1476. It changes no architecture, no Show WIP behavior and no vocabulary of the flow board. The expected moves named in the definition are the ones the CPO named; the board's own move set is not decided here.
