# VIVA AQUA mnemonic: Change (A to B)

This is `mnemonics/C2`, a PLAN Change. It ships no definition yet. It adds one mnemonic, VIVA AQUA, in the shape of DISCO. It is owned by `engineering` because it names the boundary between the packages `kaal-testing` and `kaal-review`, which keep their names and neither of which may rely on the other.

## A: the present

The mnemonic exists only in a draft. `engineering/` holds no `VIVA-AQUA.md`, so the sentence cannot be found through the KAAL Definition type.

## B: the target

`engineering/VIVA-AQUA.md` is a KAAL Definition: Verification Improves Validation After Agents Qualify Unproven Assumptions (the approved expansion, verbatim). Testing serves verification: it objectively establishes whether defined criteria are satisfied. Review serves validation: it judges whether criteria, decisions and outcomes are sound and fit for purpose. Validation is not merely the fallback when verification is impossible, and Review may use objective test evidence. Quality assurance needs both. Neither approves: the Owner decides. The definition owns no instruction, no capability and no control. See [requirements.md](requirements.md) and [testing.md](testing.md).

## Order and constraints

This Change travels alone, in the collector `kaal/engineering-viva-aqua` (the name `kaal/engineering/viva-aqua` is impossible while the branch `kaal/engineering` exists). It changes no behavior of `kaal-testing` or `kaal-review`.
