# release/A45 wiring-install

The installation of a source workflow into `.github/workflows/release-<control>-<target>.yml`, unchanged, in a `.github` collector that travels alone. The new ruleset is applied from its source only on the Owner's go and by no Change. The install adds no logic: a Case compares the installed copy with its source byte for byte, so the installation cannot drift from what was proven.
