# release/A48 release-scope-manifest

The manifest lives at `engineering/release-management/05-src/scope/<package>-<version>.json`, for example `kaal-release-0.0.1.json`, in the shape drafted in `interface.md`. The judge is `05-src/scope/scope-judge.mjs`, a pure function from the manifest and the set of Change ids found on `main` to a readiness report. It reads files and changes nothing, and it is not a new workflow or a required check. It is tested in the collector on known good and bad manifests (T330); readiness of a real manifest is a separate Case that stays RED until the scope is delivered (T331). The first real manifest, for kaal-release 0.0.1, is a later DO and needs the owners' agreement on what is `required`.
