# release/A34 sync template

A directive control applied at Development OUT. It guides how a SYNC is presented so that the pull request has the structure of release/F14. It enforces nothing. Its text is `sync-template.md` in this folder, complete and usable by hand: an author copies it into a pull request body. Installing the text in GitHub is a separate Change, which installs it unchanged.
