# release/A37 github

The deployment target of the sync template: the pull request template of a SYNC, `.github/PULL_REQUEST_TEMPLATE/sync.md`. It is the text of `03-architecture/A34-sync-template/sync-template.md`, installed unchanged. GitHub offers it to an author who opens a pull request with `?template=sync.md`; a pull request opened through the API gets no template.
