# release/A46 githooks-dispatch

The dispatcher `.githooks/pre-push`, the legacy hook `.githooks/old/pre-push` and the directory `.githooks/new/pre-push.d/` of installed new hooks. The dispatcher buffers the pushed refs, finds its siblings from its own path, runs the legacy hook first and then each executable file of the directory in name order, gives each the same arguments and the same refs, and ends with a failure if any run failed. A missing or non-executable legacy hook, and an installed new hook that is not executable, each end with a failure and a message; the other hooks still run. The directory may be absent or empty, and its `README.md` is not a hook. The sources of the new hooks live in the Engineering wiring source area (`05-src/wiring/hooks/<control>-development`) and are tested before they are installed.
