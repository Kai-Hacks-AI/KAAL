# release/A47 wire-install

A WIRE pull request goes from a `.github`-only or `.githooks`-only collector into `main`, one at a time through the promotion seat, with a squash. Its template is the one in `interface.md`, installed in `.github/PULL_REQUEST_TEMPLATE/wire.md`. The check of a WIRE is a judge, `05-src/wiring/wire-judge.mjs`, not a new workflow. It is tested in the collector on known good and bad installs, and it runs at WIRE on the installed tree: each target equals its source byte for byte, the source is on `main`, a moved file matches its declared sha256 preimage on `main`, and no other file changed. The first install of the WIRE template is an ordinary `.github` DO, verified by T211. Existing installs, the `.github` ones included, use the same path. The title type `WIRE`, its Branching and merge-method classification and the template registration change existing delivery contracts, so they are a separate DO with its own review and the Owner's authorization.
