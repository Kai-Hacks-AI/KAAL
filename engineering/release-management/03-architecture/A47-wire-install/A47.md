# release/A47 wire-install

A WIRE pull request goes from a `.github`-only or `.githooks`-only collector into `main`, one at a time through the promotion seat, with a squash. Its template is the one in `interface.md`, installed in `.github/PULL_REQUEST_TEMPLATE/wire.md`. The check of a WIRE is a Case, not a new workflow: for each pair of source and target it judges that the target equals the source byte for byte (a legacy file moved unchanged is the one other allowed change), that the source is on `main` and that no other file changed. The Case is judged on known good and bad installs before it judges the real tree. Existing installs, the `.github` ones included, use the same path. The title type `WIRE`, its Branching and merge-method classification and the template registration change existing delivery contracts, so they are a separate DO with its own review and the Owner's authorization.
