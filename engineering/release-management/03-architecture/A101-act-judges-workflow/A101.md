# release/A101 act-judges-workflow

`05-src/wiring/workflows/controls-act.yml` (event `pull_request`, branches `kaal/**`, `permissions: {}` beyond `contents: read`) checks out the default branch and the merge result of the pull request into a second folder, and runs `05-src/phase/run-controls-act.mjs <judge>` once per job. The runner reads the two folders through `05-src/phase/lib/tree-facts.mjs`, asks the judge of `05-src/phase/` and prints its verdict; the flag `KAAL_RELEASE_<CONTROL>` set by the Owner as a repository variable decides only the exit code.
