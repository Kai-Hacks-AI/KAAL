# release/A33 check-pr-envelope

The first check of verify Plan. It judges the envelope of a pull request, given its title, its body, its base and head names and its commits, and reports findings. The judgment holds no git or GitHub term beyond those facts, and a thin adapter is what gathers them. It runs by hand: `05-src/plan-body/verify.mjs <body file>` judges a PLAN body alone (release/F13), and `05-src/plan-body/envelope.mjs <facts file>` judges the whole envelope (release/F17). Both print the findings and exit 1 when there are any. The envelope judge holds the shared body rule and one contract row per TYPE, and it reports the chapters of a TYPE whose row is absent as not judged.
