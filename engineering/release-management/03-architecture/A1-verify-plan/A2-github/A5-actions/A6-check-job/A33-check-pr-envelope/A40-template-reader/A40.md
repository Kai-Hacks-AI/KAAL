# release/A40 template-reader

The adapter that reads the PR templates of the base, the files under `.github/PULL_REQUEST_TEMPLATE/`, and turns them into the registry of types that the envelope judge of release/A33 takes as input (release/F17, layer 2). It is at `05-src/plan-body/templates.mjs`. It reads declarations and level-2 headings and nothing else, and it reports undeclared, malformed, duplicate and ambiguous templates. The judge holds no git or GitHub term, and this adapter is where the directory is named.
