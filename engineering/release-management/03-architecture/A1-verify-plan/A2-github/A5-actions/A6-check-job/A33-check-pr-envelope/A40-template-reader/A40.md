# release/A40 declaration-reader

The reader of the owners' declarations of the pull request types (release/C138), the registry that the envelope judge of release/A33 takes as input (release/F17, layer 2). It is at `05-src/plan-body/declarations.mjs`, replacing `templates.mjs` (`readTemplates`), and reads no template, no comment syntax, no directory name and no path: the adapter that hands it files is Hosting's. It takes Engineering's type list (engineering/C37: the seven TYPEs, their owners, `invalid`) and each owner's declaration (hosting/C113's form), both read at the base revision, and returns `{ registry, unknown, invalid, findings }`: the chapters of each declared TYPE in the order declared (no first chapter is required), the TYPEs nobody declared as UNKNOWN (never registered, never a pass), the invalid routes, and findings for a malformed, duplicate, chapterless or foreign declaration (one by a capability that does not own the TYPE), none of which registers. DEFAULT is invalid: a declaration of it, or a type list that names it a TYPE or does not name it invalid, is a finding with its own reason. The judge takes `invalid` and `unknown` as options and holds no git or GitHub term.
