# release/A40 template-reader

The adapter that reads the PR templates of the base, from the places GitHub reads them from, and turns them into the registry of types that the envelope judge of release/A33 takes as input (release/F17, layer 2). It is at `05-src/plan-body/templates.mjs`. It reads declarations, level-2 headings and file paths and nothing else. It sorts the templates it finds into declared KAAL templates, other templates, a default file without a declaration among them, and registers DEFAULT as a TYPE when the single default file declares it on its first line and starts with `Change` (release/F19), reports malformed, duplicate and ambiguous declarations as findings, and reports the other templates as a decision point for the Owner, with their paths and facts, without judging them. The judge holds no git or GitHub term, and this adapter is where the directory is named.
