# release/A33 check-pr-body

The first check of verify Plan. It reads a PLAN pull request body, applies the body contract of release/A16 and adds the contamination rules of release/F13, and reports findings. It runs by hand on a body file with `05-src/plan-body/verify.mjs`, which prints the findings and exits 1 when there are any.
