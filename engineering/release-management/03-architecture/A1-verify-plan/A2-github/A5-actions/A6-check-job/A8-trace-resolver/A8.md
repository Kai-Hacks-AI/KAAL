# A8 trace-resolver

A component. It resolves every id and every `implements`, `serves`, `fulfills`, `addresses`, `parent` and `tests` link to an artefact, and requires each `parent` to name an element of the same kind. It treats `parent` as decomposition only and never derives fulfillment from it.
