# release/A8 trace-resolver

A component. It resolves every id and every `implements`, `resolves`, `closes`, `serves`, `addresses`, `tests` and `parent` link, checks the type of each link target, and checks that every Case identity is unique. For `parent` it checks existence, same kind and absence of cycles. It treats `parent` as decomposition only and derives no coverage from it.
