# release/A1 verify Plan

A detective control applied at Integration. It judges whether a PLAN is valid and returns PASS, FAIL or UNKNOWN with findings and an actionable Recovery. UNKNOWN never passes. Its deployment target is GitHub (release/A2). It consumes the shared relationship, Testing and control-contract models and owns none of them.
