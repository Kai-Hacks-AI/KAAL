# release/A28 merge-group

Applies Dependency Review to the merge group the queue forms for a promotion, so that the name is reported there too and a required rule cannot hold a promotion forever. Whether the mechanism judges a merge group is observed once on a scratch target before anything is bound, and is not claimed before.
