# release/A26 github

The deployment target that applies Dependency Review at Integration IN and at Promotion IN. It derives the dependency changes and the advisories from GitHub, hands them to the judge, and reports the verdict as one check result named under the convention of `naming.md`, once picked. It is bound by the aggregate of the place, never by a ruleset line of its own. The existing pinned third-party action is retained as the mechanism of the judge here and moves with the job, not alone. It reports for pull requests and for merge groups, and fails closed.
