# release/A26 github

The deployment target that applies Dependency Review at Integration IN and at Promotion IN. It derives the dependency changes and the advisories from GitHub, hands them to the interpreter, and reports the outcome as one check result named under the convention of `naming.md`, once picked. One check per target, `analyze Dependencies (<target>)`, is what a ruleset requires, on the Owner's go. The existing pinned third-party action is retained as the mechanism of the interpreter here and moves with the job, not alone. It reports for pull requests and for merge groups, and fails closed.
