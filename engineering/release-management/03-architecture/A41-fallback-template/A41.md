# release/A41 fallback template

A directive control for a pull request that no specialized template covers. It guides how such a pull request is presented so that it has the structure of release/F18. It declares itself as the reserved identity DEFAULT (release/F18), enforces nothing and does not select a template. Its deployment target is GitHub (release/A42).
