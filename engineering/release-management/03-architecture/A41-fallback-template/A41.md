# release/A41 fallback template

A directive control for a pull request that no specialized template covers. It holds the fallback template, `fallback-template.md`, the text of the interface of release/F18. The control is independently executable by hand: an author copies the text into the body of a pull request that no specialized template covers. It needs no host. It declares itself as the reserved identity DEFAULT (release/F18), enforces nothing and does not select a template.

Installing the text where a host offers it automatically is a separate Change, which comes after this one and must install this text unchanged.
