# release/A16 body-contract

Checks the body of a PLAN pull request against release/F3: exactly the four chapters Change, From, To and Because in that order, and a Change chapter that holds an id, a name and a short description that repeats none of the other chapters. It is a module of create Plan on GitHub, at `05-src/plan-body/check.mjs`. It also finds contamination of the body (release/F13) and runs by hand on a body file with `05-src/plan-body/verify.mjs`, which prints the findings and exits 1 when there are any.
