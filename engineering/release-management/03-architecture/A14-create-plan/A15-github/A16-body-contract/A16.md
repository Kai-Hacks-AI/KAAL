# release/A16 body-contract

Checks the body of a PLAN pull request against release/F3: exactly the four chapters Change, From, To and Because in that order, and a Change chapter that holds an id, a name and a short description that repeats none of the other chapters. It is a module of create Plan on GitHub, at `05-src/plan-body/check.mjs`.
