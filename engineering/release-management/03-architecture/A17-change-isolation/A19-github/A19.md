# release/A19 github

The deployment target that applies Change Isolation at Integration IN and at Promotion IN. It derives the paths of a Change from Git, hands them to the judge, and reports the record as the check result named Change Isolation. The attestation that admits a ledger entry carried by a promotion is derived by this target from reviews and is outside the judge.
