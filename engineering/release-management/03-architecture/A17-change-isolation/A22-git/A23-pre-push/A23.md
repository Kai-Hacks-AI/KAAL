# release/A23 pre-push

The Git pre-push hook. For each pushed ref it runs the declared Guard check Change-Isolation against the pull request target named for the branch, with the same judge and the same ledger as release/A20, so that the same Change receives the same verdict. It reports the verdict and the paths that must move into a Change of their own.
