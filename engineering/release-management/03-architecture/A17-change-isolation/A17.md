# release/A17 change-isolation

The control Change Isolation. It consumes the common relationship model, the Testing model and the common control contract, and owns none of them. Its judge (release/A18) holds the rules and the verdicts. It is applied through two deployment targets, GitHub (release/A19) and local Git (release/A22). Guard is the concept that connects a control's declared check to the places where it runs, and this control consumes it: each place runs the check through Guard's declaration and Guard owns the requirement that a verdict is a condition of admission (`guard Integration`), which this control only feeds. The control restates no part of Guard.
