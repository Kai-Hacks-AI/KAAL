# release/A17 change-isolation

The control Change Isolation. It consumes the common relationship model, the Testing model and the common control contract, and owns none of them. Its judge (release/A18) holds the rules and the verdicts. It is applied through two deployment targets, GitHub (release/A19) and local Git (release/A22). The requirement that a verdict is a condition of admission belongs to `guard Integration`, which Guard owns and which this control only feeds.
