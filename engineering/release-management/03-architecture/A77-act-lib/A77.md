# release/A77 act-lib

The component is the folder `05-src/phase/lib/` with one module for each layer: `tree.mjs` (`walk`, `frontmatter`), `collector.mjs` (`elementsOf`, `justifiedBy`, `applicableCases`, `changeIdOf`, `retrosOf`, `carriedChanges`), `cases-green.mjs` (`casesAreGreen` over the Cases of one set, `applicableCasesAreGreen` over the Cases of all the carried Changes together; the answer is `{ verdict, progress, findings, message }` as `judgeAct` gave it) and `write-map.mjs` (`inFolder`, `isFile`, `relativeToRoot`, `inRoute`; the data stays in `write-map.json`, and the matching is handed the roots, relative to the repository). The judges `judge-act.mjs`, `judge-demand-act.mjs` and `judge-limit-act.mjs` keep their exported judge and their command line, import from the library, and no judge imports another judge. `judge-act.mjs` keeps exporting the facts it exported before, as re-exports of the library, so that the Cases written against it stay valid. The library is the layer the next judge, the flag `applies` and the Dispatcher are built on.
