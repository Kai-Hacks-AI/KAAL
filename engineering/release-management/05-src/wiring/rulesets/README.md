# Rulesets (Engineering)

Engineering's source for the repository's rulesets: one JSON file per ruleset (GitHub's import format) and one table of controls (`controls.md`) that says what every setting is for. The source lands on `main` first and is tested there; installing it into the live repository is a separate step done by the Owner (and later by WIRE). Nothing here creates, changes or retires a live ruleset. See `../../../00-changes/C34-ruleset-set-1/change.md`.
