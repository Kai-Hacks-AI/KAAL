## Learned
- subject: moving a baseline from derived to a file is a change of what a judge needs on both sides
  source: seven older Cases built two trees of workflows and had no baseline file in them. A fixture that writes the file an honest author would write (the base's findings, and the base's findings the head still has) kept their assertions intact, and one case, a removed use that forgets the file, now fails on purpose.
- subject: a pre-existing remote branch cannot be pushed to under the wiring ruleset
  source: I created a `wire/` branch through the API before pushing, and the ruleset then rejected my push because the branch already existed without the required checks. Pushing a new branch name created it with its content in one step.
