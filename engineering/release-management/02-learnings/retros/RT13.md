Account of: I am the release thread. I renamed the control that tells a pull request's own changes from what main holds, from `attribute Changes` to `isolate Changes` (C128), after Kai named it: the PLAN, then the DO. This is my account only: the CPO and the Owner have not been asked what they lacked, and I wrote the retro of my own collector.

## Liked
- subject: the rename was made before anything was installed
  keeps: no WIRE, ruleset or variable carried the old name, so the rename cost one small Change and no second WIRE or change of a check name.
- subject: T1360 fails on the old name, not only on the new one
  keeps: a leftover of the old spelling in the record, the library, the runner or the workflow source, or the old paths, is a red Case, so the rename cannot be left half done.

## Learned
- subject: a text rename has more spellings than the name
  source: the full Cases run after my replacement, which showed T1360 red; its pattern had an escaped dot, `run-controls-act\.mjs attribute`, that my substitution of the plain spelling did not reach.

## Lacked
- subject: nothing listed the spellings of a name before it was replaced
  decision-point: running the substitution over the Cases, when the name appears plain, camel case, kebab case, upper case, as a file name and inside an escaped pattern.
  cost: one red Case in the full run and one more commit.
  findable: yes
  address: script

## Longed For
- subject: a listing of every spelling of a name in the source, before a rename starts
  worked-anyway: I searched the old name in each spelling after the substitution and read the one red Case.
