# release/F19 fallback-type

The fallback is a pull request TYPE. Its name is DEFAULT, exact and upper-case. DEFAULT is a TYPE: it is the TYPE of a pull request that none of the specialized TYPEs fits. Its title is `DEFAULT: <meaningful description>`, its template declares `<!-- KAAL-PR-template: DEFAULT -->` on the first line, and its two chapters, Change and Because, are the interface of release/F18. The registry of TYPEs holds DEFAULT beside the specialized TYPEs.

By policy DEFAULT applies only when no specialized TYPE fits. It never judges, and never outranks, a pull request whose title names a specialized TYPE. This supersedes the statement of release/F18 that DEFAULT is not a TYPE.
