# release/F19 fallback-type

DEFAULT is not a TYPE. It is an invalid route (release/C138): a pull request that falls to the fallback, a default template in the repository, or a declaration named DEFAULT is a finding with its own reason, never registered and never a pass. Engineering's `pull-request-types.json` (engineering/C37) names it under `invalid`, and no owner declares it. A title `DEFAULT: <description>` is a finding whatever its body. The fallback template (release/F18) holds no declaration; it is where a human author who found no specialized template is told to stop and use one. This supersedes the earlier statement of this requirement that DEFAULT is a TYPE and that its template declares `DEFAULT`.
