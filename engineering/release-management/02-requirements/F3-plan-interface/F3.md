# release/F3 plan-interface

The interface through which a PLAN is produced is one sentence: it plans a Change, from A to B, because of X. A is the current state and B the target state, each in a few words, and X is what started the work. The Change, its Intent, Requirements, Architecture and Cases are held by the files of the Change and are not repeated in the interface. It is written once and not changed afterwards. The interface of a deployment target is an adapter of create Plan. It carries no rule of the control.
