# release/F3 plan-interface

The body of a PLAN pull request is a controlled, concise interface. It has exactly four level-2 chapters in this order, Change, From, To and Because, and nothing else: no other headings, commentary, test transcripts, status reports, implementation details or traceability inventories. Those live in the files of the Change, or in comments.

- Change: one line, `<id> <name>: <short description>`, with the stable id, the name and what the Change is about. The description does not repeat the current state, the target state or the value stated by the chapters that follow.
- From: the current state (A), briefly.
- To: the target state (B), briefly.
- Because: the value delivered (X), briefly, not merely who asked for it.

The contents of the chapters may be corrected while the PLAN evolves. The structure is fixed. The interface of a deployment target is an adapter of create Plan. It carries no rule of the control.
