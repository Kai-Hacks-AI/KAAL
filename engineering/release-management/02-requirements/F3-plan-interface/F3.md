# release/F3 plan-interface

The interface through which a PLAN is produced is four short chapters, each answered in a phrase: the Change by id and name, From (A, the current state), To (B, the target state) and Because (X, what started the work). Each chapter carries just enough guidance for the author to know what to write. The Change, its Intent, Requirements, Architecture and Cases are held by the files of the Change and are not repeated in the interface. It is written once and not changed afterwards. The interface of a deployment target is an adapter of create Plan. It carries no rule of the control.
