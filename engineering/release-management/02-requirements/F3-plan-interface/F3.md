# release/F3 plan-interface

The interface through which a PLAN is produced is minimal and reads from the outside in. It names the origin, what started the work, and points to the Change. The Change, its Intent, Requirements, Architecture and Cases are held by the files of the Change and are not repeated in the interface. It is written once and not changed afterwards. The interface of a deployment target is an adapter of create Plan. It carries no rule of the control.
