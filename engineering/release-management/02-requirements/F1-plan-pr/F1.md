# F1 plan-pr

A PLAN is accepted only when it satisfies all of these rules.

1. Every Change implements an Intent. (F1/T1)
2. Every Requirement serves an Intent. (F1/T2)
3. Every Architecture node traces to a Requirement and to a Defect, directly or through its parent. (F1/T3)
4. Every Intent, Requirement, Architecture node and Defect has at least one Case beside it. (F1/T4)
5. Every Case names exactly its own artefact in `tests:`. (F1/T5)
6. Every Case is red and wired into no lane. (F1/T6)
7. Every id resolves and every template heading is parsed. (F1/T7)
8. Unreadable input is a failure, never a pass, and every failure carries a Recovery line. (F1/T8)
