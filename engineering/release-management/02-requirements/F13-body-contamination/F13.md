# release/F13 body-contamination

A PLAN pull request body is contaminated when it holds anything beyond the chapters of release/F3. The check finds it and says what it found:

- text before the first chapter, such as attribution or a link to the conversation;
- text after the chapter content, such as a separator, a generated footer or a session link;
- an HTML comment that carries attribution or metadata, wherever it sits, or any HTML comment before the first chapter.

A clean body passes. A contaminated body is rejected with one finding for each kind of contamination. HTML comments that are hints of the template stay allowed inside a chapter.
