# release/F17 envelope-rules

The envelope of a pull request is its title and its body, read together with the route it takes and its commits. It is judged by these rules, and each breach is one finding:

- Title shape: `<TYPE>: <description>`, with TYPE one of PLAN, DO, ACT, SYNC, PROMOTION or HOTFIX and a description that is not empty.
- Title contamination: the title holds no Change id, link, emoji or attribution wording.
- Route fit: PLAN, DO, ACT and SYNC take a base under `kaal/`, never `main`. PROMOTION takes `main` as base and a head under `kaal/`. HOTFIX is part of this rule: its route is the one create Hotfix defines, and this requirement states it once that route is known, before this Change goes to `main`.
- Id agreement, for PLAN, DO and ACT: the id in the `## Change` chapter of the body equals the single `Driven-by:` trailer of every commit, and each commit has exactly one.
- Body: the body is judged as release/F13 states.

A clean envelope passes. SYNC, PROMOTION and HOTFIX are not judged for id agreement.
