# release/F18 fallback-interface

The default pull request template is the fallback. By policy it is used only when no specialized KAAL template applies. Its body is a short interface of exactly two level-2 chapters in this order, Change and Because, and nothing else: no other headings, commentary, test results, CI status, execution logs, links or attribution.

- Change: one line saying what the pull request changes. It names `<id> <name>` when the pull request belongs to a Change and otherwise says plainly what changes.
- Because: the value, not the requester.

Each chapter is short and carries a hint. The first hint tells the author to use a specialized template where one applies, and points to the directory `.github/PULL_REQUEST_TEMPLATE/` without naming a template in it. Design, test results and review belong to the files of the Change, the checks and the reviews, and are not repeated in the body.

The fallback is not a TYPE. It carries no `KAAL-PR-template` declaration, its chapters are not those of any specialized template, and it never validates a pull request that a specialized template covers. It names no specialized template and no TYPE, so a new specialized template changes nothing in it.
