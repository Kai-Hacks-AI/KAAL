# C125 baseline

The baseline is `main` after the PROMOTIONs of release/C128 and of testing hold-adapter (`testing/C74`, `packages/kaal-testing/lib/observe.mjs`). The judge `judge-act.mjs` takes `observed` (a map of Case id to GREEN, RED or UNKNOWN) and has no input for the evidence that `observeCases` returns beside it (`evidence.catalog.complete`, `findings`, `unobservable`, `revision`, `expectedRevision`). The runner `run-controls-act.mjs` answers UNKNOWN for `hold` unconditionally. `applicableCases` in `lib/collector.mjs` reads `export const id = '...'` in single quotes only; 36 Case files on main use double quotes and are not seen, among them every Case of the open `kaal/testing/multi-loop-sensitivity` collector (testing evidence, `plan/hold-adapter/evidence.md`). The pilot of `testing/C79` (`plan/act-library-sensitivity/pilot.md`) killed 18 of 23 mutants by assertion, found one detected by exception only (M16) and four survivors (M12, M20, M21, M23); it hands release the Cases J1 to J3 as text (release thread, 21 Nov).
