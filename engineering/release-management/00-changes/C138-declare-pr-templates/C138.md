# release/C138 verify Envelope reads the owners' declarations of the pull request types

The judge of the envelope derives its rules from templates that declare themselves with `<!-- KAAL-PR-template: <TYPE> -->` (release/F17, release/A40 `readTemplates`). No template of this repository declares anything, so the registry is empty and release/CTL11 `verify Envelope` can only say UNKNOWN on every real pull request (release/C137). This PLAN makes the engineering sources declare their TYPE, so that the registry is the one the templates hold. It is a PLAN: it changes no source, installs nothing and touches no `.github` file. The WIRE that installs the sources needs the Owner's go.
