# release/C138 verify Envelope reads the owners' declarations of the pull request types

`verify Envelope` derives its rules from templates that declare themselves with `<!-- KAAL-PR-template: <TYPE> -->` (release/F17, release/A40 `readTemplates`), and no template of this repository declares anything, so release/CTL11 can only say UNKNOWN on every real pull request (release/C137). The Owner ruled that Hosting owns GitHub and therefore the template generator, and that each capability declares the chapters of the TYPEs it owns; Engineering holds the type list, owners and eligible routes (hosting/C113, engineering/C37). This PLAN has `verify Envelope` read those declarations in place of the templates, declares release's SYNC, PROMOTION and WIRE, treats DEFAULT as an invalid route and a TYPE nobody declared as UNKNOWN, and writes every affected Case expectation here. It is a PLAN: it changes no source, installs nothing and touches no `.github` file.
