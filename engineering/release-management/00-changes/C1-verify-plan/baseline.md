# C1 baseline

The baseline is `main`, at 1263be7. Work that exists only on a collector or in an open pull request is not delivered functionality, and this Change depends on none of it.

- `main` holds create Plan (release/C3): the PLAN structure F2, the PLAN interface F3, the elements A14 to A16, the Cases that go with them and the PLAN pull request template with the four chapters Change, From, To and Because.
- `main` holds the first check of verify Plan (release/C8): the contamination requirement F13, the element A33 and the module `05-src/plan-body/verify.mjs`, which a person runs by hand on a body file.
- `main` holds no judgment of a PLAN, no reader of a pull request or of a tree, no check that covers a PLAN pull request, no `verify Plan` workflow and no status named `verify Plan`.
- `main` holds no Intent I1, no Requirement F1, no Defect D1 and no elements A1 to A13 as documents. An untraced PLAN is accepted, and when a PLAN is untraced no failure names the missing link or the way to recover.
- Nothing on `main` requires a PLAN pull request to pass a check before it merges.
