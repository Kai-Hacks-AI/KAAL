# C1 baseline

The baseline states the current state in domain terms.

- A PLAN is submitted as a set of artefacts with a description.
- Nothing requires the set to contain a Change, an Intent, Requirements, Architecture or Cases.
- Nothing requires the artefacts to be traced to each other.
- A PLAN is accepted with no red Case.
- When a PLAN is untraced, no failure names the missing link or the way to recover.
- The release-management folder holds no numbered layout and no Cases.
