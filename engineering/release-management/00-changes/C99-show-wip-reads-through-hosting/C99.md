# release/C99 Show WIP reads GitHub through Hosting and runs in a cloud session

Show WIP (`05-src/show-wip`) is the command that shows where every open piece of work stands. An agent in a cloud session cannot run it: the command starts `gh` itself and asks GitHub GraphQL, which that session refuses (HTTP 403). This Change carries the Defect and the Test Cases that prove it, and moves the command's GitHub reading to Hosting over REST.

Provisional ids: C99 and T1200–T1204 were checked against `main` and the `kaal/release/*` branches on 19 November 2026 (highest release Change C98, highest Case T924); they are confirmed again at the DO.
