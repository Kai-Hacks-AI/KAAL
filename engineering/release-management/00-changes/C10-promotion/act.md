# C10 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

Reading the observed promotions before drawing any chapter made the CPO's challenge answerable: each chapter either matched an observation or was dropped, and the three-chapter candidate became two on evidence, not on taste. The other two template threads agreed their id ranges in one exchange, so the three Changes never touched the same file.

## Learned

The chapters I proposed first, Collector, Delivers and Order, carried facts the pull request and the checks already show, so the interface shrank each time it was tested against what a reviewer actually decides. A pull request created by the tool carried a generated footer in its body even though the text I wrote had none, and it did so again on both DO pull requests, so a body that is clean when written is not clean when opened. The title convention arrived after the PLAN was open, and a retitle plus one more Case was cheaper than it would have been after promotion. While the collector waited for review, `main` took three promotions, so the collector is behind and will need a synchronization of its own before it can go up.

## Lacked

A copy of the shared formatting contract on `main` to cite, so F15 restates its parts. A way to open a pull request without the footer, and a way to see, on the pull request itself, whether a body has any. A view of the promotion queue and of how far a collector is behind `main`, short of reading Branching's output.

## Longed For

The template shown to the author at the moment the pull request is opened, so the body starts from the two chapters instead of from a blank box. The shared checker running on a body before a reviewer opens it, which the CPO has named as the later wiring Change. A promotion that states its own reason for going now without anyone asking for it.
