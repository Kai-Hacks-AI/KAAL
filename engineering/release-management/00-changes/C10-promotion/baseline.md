# C10 baseline

The baseline is `main`. Work that is not on `main` is not delivered functionality, and this Change depends on nothing that is not on `main`.

- `main` holds one pull request template for a PLAN, `.github/PULL_REQUEST_TEMPLATE/plan.md`, and none for a promotion.
- Nothing on `main` states what the body of a promotion pull request contains.
- `engineering/github/branching.md` states how a collector is promoted and landed, and holds no word on how a promotion is presented.
