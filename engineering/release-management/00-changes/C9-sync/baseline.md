# C9 baseline

The baseline is `main`. Work that is not on `main` is not delivered functionality, and this Change depends on nothing that is not on `main`.

- `main` holds one pull request template, `.github/PULL_REQUEST_TEMPLATE/plan.md`, and none for a SYNC.
- `engineering/github/branching.md` states how a synchronization is made and judged: a merge commit of `main` into a collector, no Change Record claimed, conflict paths as its explicit resolutions. It states nothing about what the body of its pull request says.
- Nothing on `main` states what the body of a SYNC pull request contains.
