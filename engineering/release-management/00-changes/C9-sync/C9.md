# release/C9 sync

The capability: the Intent, the interface, the control and the template text of a SYNC pull request template, with the Cases that prove its contract. It is complete and usable by hand without any host: an author copies the text into a pull request body. It installs nothing in GitHub. The wiring of the text into GitHub is release/C16, which comes after this Change is delivered and installs the text unchanged. It defines no other element of SYNC and changes no control.
