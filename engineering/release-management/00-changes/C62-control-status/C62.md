# release/C62 Main's finder reads the status of a control

A control declares how far it has come: `status` is one of designed, implemented, running and tested. Main's finder (`find-controls.mjs` of the controls package) refuses a control that holds a `status` line. This Change puts the finder that reads the status on main, with the Skill pointers and the old controls Cases that read the finder, and declares the status of the release controls: release/CTL1 running, release/CTL2, CTL5, CTL7, CTL8 and CTL9 implemented.

It is the precursor of controls/C12. That Change keeps its own Cases and records on its collector; the files of this Change are byte-identical to the ones it holds, so its later SYNC is a pure merge. Nothing under `.github` changes in this Change.
