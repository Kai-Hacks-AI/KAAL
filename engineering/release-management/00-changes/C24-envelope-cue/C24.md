# release/C24 envelope cue

The capability texts of the pull request templates open their body with one fixed line that says the body is the Change envelope and that the evidence is in the repository files of the Change(s) named below, at the revision under review. The line is visible text, written once in the template, and carries nothing specific to a pull request, so the envelope repeats no content. One line serves a pull request with one Change and a promotion with several. The envelope check accepts exactly that line before the first chapter and still rejects any other text there.

Installing the cue in the templates under `.github/` is release/C25, because `.github` travels alone.
