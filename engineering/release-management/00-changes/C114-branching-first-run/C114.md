# release/C114 the Branching workflow is corrected at a source of its own

The first Branching run of every new pull request into a collector fails, and a stale failure can be the verdict that stays: release/D12 (`D12-branching-first-run.md`). The workflow `.github/workflows/lineage-synchronization.yml` was installed by hand and has no source under `05-src/wiring/workflows`, so it cannot be corrected where workflows are made. This Change gives it that source, with the correction in it: one Branching run decides at a time, the newest event's, and the auto-merge it judges is read from the pull request when the run judges, not taken from the event. The installed copy changes in the WIRE that follows (the Owner's wiring step, from the source). The gate itself (`engineering/github/lineage.ts`, `branching.sh`) and every verdict stay as they are.
