# release/C120 the stage declares the name of its ruleset and verify Stages judges the source against it

`verify Stages` holds the names of the ruleset sources in its code (the lowercase name of the stage, and `publishing`). Release/C106 renames the six sources by their stage number, but a pull request that renames them cannot pass the check: the check runs the judge of the default branch (trusted), which still expects the lowercase names, so the renamed sources fail until the judge on `main` has changed. The judge has to land on `main` first, and the rename after it. This Change is that first half: the judge compares each source with the name its stage declares, and `stages.json` declares the names the sources have today. Nothing is renamed.
