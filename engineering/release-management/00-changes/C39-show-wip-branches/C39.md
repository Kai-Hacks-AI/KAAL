# release/C39 Show WIP by branch

Show WIP (SWIPE) gains a branch-first inventory beside its PR observations: one entry per branch with the PRs that transport work out of it, and per package whether main holds stock beyond what npmjs and the release tags say. Branches hold stock, a PR transports it. It observes and shows only.
