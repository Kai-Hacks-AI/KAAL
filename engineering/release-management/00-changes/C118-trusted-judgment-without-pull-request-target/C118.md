# release/C118 a pull request cannot change the judge that judges it

Five workflows use `pull_request_target` (release/D13 to D17), because that trigger runs the default branch's copy of the workflow, so a pull request cannot edit the judge that judges it. It has to go (release/I50). The replacements run on triggers that start from the pull request, where the workflow file is the pull request's own. This Change decides how a gate keeps its judgment trusted without the trigger, and applies it to the smallest workflow first, merge-group-admission (D13).

It is a PLAN: the Intent, the Requirement and the Architecture element as drafts, the options compared, a recommendation and the questions for Kai. It adds no source, no workflow and no Case. The Case of each fix ships as a plain `.test.mjs` with its source.
