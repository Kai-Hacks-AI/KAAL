# release/C57 scan Vulnerabilities on main, daily

Declares a scheduled scan of the whole dependency tree of `main` as the detective control `release/CTL6` with the new Intent `release/I31`, and builds its source: a workflow source `scan-vulnerabilities.yml` and an interpreter that reads `npm audit`.

`analyze Vulnerabilities` (release/CTL2) compares base and head of a change, so it cannot see an advisory published today against a package that is already on `main`. The scan reads the lockfile of `main`, not a diff. Settings match CTL2: severity low and above, runtime scope, no exemptions.

It is a source in Engineering. Installing it under `.github` is a later WIRE with its own Owner decision, and `.github` is not touched here. Nothing requires the scan: it is detective, and a finding surfaces as a red run.
