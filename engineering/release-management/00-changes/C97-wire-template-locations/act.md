# C97 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

The CPO's review of the WIRE caught the one thing that mattered: the source of the template still carried the list C95 had removed from the consumers, so installing it would have copied the duplication into `.github`. Fixing the source first, as its own small Change, kept the WIRE a pure copy.

## Learned

A Case that compares a source with the draft of a historic Change (T281) ties the source to the past: the first correction would have been refused for the wrong reason. Judging the source's contract, and pinning the new wording in a Requirement, keeps the old Case and the new rule apart. A template that says where to install must read the declaration, like the consumers do, or it becomes the fifth place that lists the roots.

## Lacked

A Case for "any template" that would have flagged the hard-coded roots without a reviewer: it is the Owner's concept for templates and still its own Change.

## Longed For

The corrected source installed by the WIRE (#2046), which then counts as the second wire for the go-live gate. The classifier's ACT recognition that takes an ACT to be exactly two chapters, before the templates are wired.
