# release/C18 wire analyze Vulnerabilities

The wiring of the capability `analyze Vulnerabilities` of release/C5 into GitHub and Guard: a workflow per target (Integration on pull requests into `kaal/**`, Promotion on pull requests into `main` and on the merge group), and the Guard declaration `Analyze-Vulnerabilities` that runs the adapter in ci. It comes after release/C5 is delivered. The workflow and the ruleset are Engineering-owned source artifacts, proven by Cases on `main` before they are installed (release/F20, A44, A45). It changes neither the interpreter nor the adapter, and it applies no ruleset: a ruleset is applied only on the Owner's go.
