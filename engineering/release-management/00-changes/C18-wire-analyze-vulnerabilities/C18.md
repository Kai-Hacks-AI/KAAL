# release/C18 wire analyze Vulnerabilities

The wiring of the capability `analyze Vulnerabilities` of release/C5 into GitHub and Guard: a workflow per target (Integration on pull requests into `kaal/**`, Promotion on pull requests into `main` and on the merge group), and the Guard declaration `Analyze-Vulnerabilities` that runs the adapter in ci. It comes after release/C5 is delivered. It changes neither the interpreter nor the adapter, and it requires no check in any ruleset.
