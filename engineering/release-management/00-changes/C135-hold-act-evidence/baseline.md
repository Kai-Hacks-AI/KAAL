# C135 baseline

The baseline is `main` with release/C125 and release/C127 merged. `run-controls-act.mjs` reads an evidence file only when it gets `--evidence <file>` (`readEvidenceFile`), and `judgeHoldWithEvidence` answers UNKNOWN for no file, an unreadable file, `catalog.complete` not exactly `true`, or a `revision` that is not `expectedRevision`. Testing's `kaal-testing run` produces a run report as JSON and `kaal-testing observe` turns a run report (and a form report) into the `observed` map and the `evidence` file (testing/F162). Nothing runs either of them in a workflow. The workflow source `05-src/wiring/workflows/controls-act.yml`, installed as `.github/workflows/controls-act.yml`, has five jobs and none passes `--evidence`. The evidence of the first real run is run 45663579656 on #2503: `hold Act` UNKNOWN, `applies` true, attribution complete.
