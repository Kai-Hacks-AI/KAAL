# release/C135 hold Act is given Testing's observation of the Cases at the revision it judges

The judge `hold Act` (release/C125) reads Testing's observation as a file handed in with `--evidence`, and answers UNKNOWN when there is none. The installed `controls-act.yml` hands none and runs no producer, so on the first real ACT pull request with the flag on (#2503) `hold Act` read UNKNOWN. This PLAN makes the observation exist for the revision under judgment. It is a PLAN: it builds nothing, installs nothing, sets no flag and changes no ruleset. The WIRE that installs the result needs the Owner's go.
