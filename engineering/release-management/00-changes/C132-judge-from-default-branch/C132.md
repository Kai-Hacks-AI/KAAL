# release/C132 the ratchet checks run the judge of the default branch

`verify Triggers` and `verify Workflow names` run the judge of the **base** of the pull request. A pull request whose base is a collector that has not received the judge yet (a SYNC into a stale collector, found on #2414 into `kaal/backlog/item`) has no judge there, so both checks answer UNKNOWN, "the judge is absent on the base". They do not block today because no ruleset requires them. It would recur on every SYNC into a stale collector, and it would block once they are preventive. This Change makes the judge the default branch's and keeps the pull request as data, as the Act judges and the CodeQL gate (engineering C33) already do. It installs nothing, changes no ruleset and sets no flag.
