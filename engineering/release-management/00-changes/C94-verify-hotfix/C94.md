# release/C94 verify Hotfix

Gives the Hotfix a control. release/CTL21 `verify Hotfix` is a detective control that has the Intent release/I10 (create Hotfix). It reads a Hotfix pull request as Git data and judges apart the trace from the Hotfix to one recorded Defect and its reproducing Case, and the revision-bound evidence of the correction (the Case RED against the baseline, GREEN against the corrected revision). It finds a broken link or a not-verified correction, reads missing or stale evidence as UNKNOWN, flags a diff over several capability roots for justification and never answers PASS.

It replaces release/C31, which built the same judge as a bare module with no control identity, no classification and no registration. C31 is retired, not finished: its judge, its Cases and its F16 text are carried here, and this Change adds what C31 lacked, the control, its Requirement and Architecture, the reader that gets the facts from the base as Git data, and the workflow source. It is Engineering source: nothing is installed, wired or required here.
