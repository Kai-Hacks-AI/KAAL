# release/C94 verify Hotfix

Gives the Hotfix a control. release/CTL21 `verify Hotfix` is a detective control that has the Intent release/I10 (create Hotfix). A Hotfix brings its own Defect and its own reproducing Case. The control reads the Hotfix pull request as Git data, judges the trace (one Defect, its record on the head names reproducing Cases, each exists on the head), and proves the correction by comparison: the same Case, the head's own file, is run by the Run of Cases on the default branch and on the Hotfix's head, and must be RED on the first and GREEN on the second, for every reproducing Case. It finds a broken link or a not-verified correction, reads a missing or unusable run as UNKNOWN, flags a diff over several capability roots for justification and never answers PASS.

It replaces release/C31, which built a judge as a bare module with no control identity, no classification and no registration, and which read the Defect and its Case from the base. C31 is retired. This Change adds the control, its Requirement and Architecture, the reader of the facts as Git data, the reader of the Run of Cases and the workflow source. It is Engineering source: nothing is installed, wired or required here.
