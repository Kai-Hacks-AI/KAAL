# release/C92 the dry run of the Dispatcher gives an honest verdict for every collector

Today the dry run of the Dispatcher (release/C72, release/C73) lets the first qualifying collector take the seat and reports every other one as `seat-taken` without a verdict; it judges readiness from the title of the newest merged pull request, and its skips do not name the collector. The Owner asked for the opposite: each ready collector named in every decision, an honest verdict apart from the seat, facts shown as data, and readiness judged from test evidence and not from a merge or a pull request, which are transport and not KAAL.

This Change replaces the decision and the seat marking of the dry run with release/I51, release/F69 and release/A64. `KAAL_DISPATCH_RAISE` stays unset and no variable changes: the live raise stays off.
