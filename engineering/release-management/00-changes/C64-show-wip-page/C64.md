# release/C64 Show WIP page

A daily scheduled job runs Show WIP (the command in `05-src/show-wip`) and publishes the result as one plain static page on GitHub Pages, so Kai and the CPO can read where work stands without running anything. The page is styled after the Corporate Visual Identity (colours, type families, use of the mark). It sits beside the daily scan (release/C57) as an Operations job: it reads and shows, and changes no branch, piece or setting.
