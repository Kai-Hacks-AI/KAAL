# release/C139 release delivers the verify Adapter check, reading each delivered entry from files

Controls built `verify Adapter` (controls/F206, `findUnadapted`) and its observation (controls/F212, `observeAdapted`, controls/C148). Both are pure and know no repository. Release owns what they leave to the adopter: the delivery map (which file is the delivered entry of each control), the runner that reads each entry at the merge result and calls them through the adapter, and the workflow behind the flag `KAAL_CONTROLS_VERIFY_ADAPTER`, detective and advisory. This is a PLAN: it builds nothing, installs nothing, sets no flag, requires no check and changes no ruleset. The WIRE that installs the workflow needs the Owner's go.
