# release/C127 the ACT judges' evidence is recorded per run and summed per judge

The four ACT judges (`hold Act`, `demand Act`, `verify Act`, `limit Act`) run on real pull requests in detective state. Whether a judge may go advisory is decided by evidence: no false FAIL, every RED and UNKNOWN handled, a recorder named. Today that evidence is counted by hand from workflow runs, and the count has already been wrong once (D18 SYNC pull requests were judged as ACTs and produced false FAILs; the installed workflow still answers UNKNOWN for want of attribution). This Change closes the loop: each run leaves one record, each judge has one summary computed from its records, and the advisory bar is a stated test the summary answers.
