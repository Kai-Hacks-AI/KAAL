# C8 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

The existing checker already caught most of the contamination. Running it on the observed shapes first showed that the real gap was one hidden comment, so the Change stayed one small file. Kai's naming and placement corrections arrived while the PLAN was still cheap to move.

## Learned

The tool that opens a PR adds a generated footer to the body, so the first body of C8 was itself contaminated, and the CPO found it. Removing it needed a second write after creation. The three observed bodies had been corrected by then, so their shapes are rebuilt from descriptions, not taken from the originals.

## Lacked

A recording of a contaminated body as it was opened. Any way to open a PR without the tool adding its footer. A way to see whether a failed first Branching run is the known first-run trap or a real failure without reading the run.

## Longed For

The check at the moment a PLAN PR is opened, so the footer is found before a reviewer sees it. The same check for the DO and ACT bodies. A footer-free way to open a PR.

## Sentence

Priorities Lead Agents Next Development, Optimising Code Health, Enabling Clear Knowledge About Collected Testing.
