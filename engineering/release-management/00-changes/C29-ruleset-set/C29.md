# release/C29 ruleset set

Records the target set of rulesets of the delivery architecture, as decided by the Owner on 14 Nov: five rulesets, one per delivery path or step, `hotfixing`, `wiring`, `integration`, `promotion` and `publishing`. Development is the hooks and is not a ruleset. The names can still be discussed.

Outcome status: a record only. This PLAN creates, renames and activates no ruleset, and the existing live rulesets stay as they are.
