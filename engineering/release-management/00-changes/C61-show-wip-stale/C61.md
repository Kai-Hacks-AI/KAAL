# release/C61 Show WIP lists empty and done branches

Show WIP (release/C39) lists every branch in its place. It now also marks a branch that is empty or done, counts them in the overview, and has one view that lists only those, so they are an easy pick to delete. It observes and shows only: deleting a branch stays with someone who has delete rights.

- **Empty**: the branch has no commit beyond main and no pull request of it merged into main.
- **Done**: the branch's work reached main. A pull request from this branch into main merged and the branch holds nothing beyond that pull request's head, which is how a collector looks once its promotion has landed (a squash promotion leaves the commits unmerged by ancestry).
- A branch with an open piece is never listed as a candidate for deletion. The default branch is never a candidate.
