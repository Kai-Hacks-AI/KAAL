# release/C55 verify Source, migrated

Migrates the second control of `engineering/release/` (engineering/F30, the source tests run first) into release-management as `release/CTL4`, a detective control, verify Source, with the new Intent `release/I29` (source tested before release). It is rebuilt clean, not wrapped: a pure judge under `05-src/publishing/verify-source/` whose test command comes from a declaration, with a result in KAAL's vocabulary (verified, failed, unknown). The old engine, its tests and its workflow are not touched: they leave when every control of `engineering/release/` has moved.
