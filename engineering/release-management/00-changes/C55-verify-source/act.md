# C55 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

The source tests before release are now a control of release-management that decides from a record and runs nothing. The judge is pure, so its five Cases need no package and no process. The result has three values, and a run that left no record or whose status is not a whole number is `unknown`, never a pass. The old step knew only pass or stop. The command comes from a declaration, so the judge names no command, repository or scope. T720 to T724 went RED in the PLAN and green in the DO.

## Learned

Naming a Case after the thing it tests matters: a Case that lists a control is found from that control by the finder, and the control test of that control must stay the only one. The first Changes after it use the Change id for behaviour Cases.

## Lacked

A run in release-management that calls the judge. Today engineering/release does it through the old workflow, so the control reveals nothing yet and claims no operation.

## Longed For

The next legacy controls of engineering/release in order: pack once, installed verification, publish gate, registry acceptance. After them, `engineering/release/` can go.

## Follow-ups

- Wiring CTL4 into a release run or a ruleset is a separate preventive control and an explicit decision of the Owner.
- Promote C55 in the CPO's order, one at a time.
