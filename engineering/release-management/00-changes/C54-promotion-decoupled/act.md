# C54 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

The PROMOTION template now argues from the branch it enters: step 0 says that main requires the branch quality of the source branch, step 1 checks freshness without naming a SYNC, and the last row says that main requires the approved exact head and that nothing starts automatically. ## Learned

The entry criterion of a promotion is the quality of its source branch, however the branch got there. The template therefore lists no branch kinds and no routes into main. T711 first came out green because it read the new draft; pointing it at the old expanded table in the C46 interface made the PLAN red as it must be.
