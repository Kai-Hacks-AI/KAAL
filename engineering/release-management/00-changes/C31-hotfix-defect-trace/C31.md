# release/C31 hotfix defect trace

One HOTFIX corrects one identified defect. This Change gives the HOTFIX a structural judge of the trace HOTFIX, Defect, reproducing Case, verified correction. It finds a missing or broken link and flags a diff that spans several capability roots for justification. It never answers PASS: that the correction is minimal, that it contains no unrelated work and that it genuinely repairs the reproduced behaviour stay unjudged. It is not wired and decides nothing about the Hotfix delivery path, the base, admission or any ruleset.
