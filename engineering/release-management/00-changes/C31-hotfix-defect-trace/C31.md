# release/C31 hotfix defect trace

One HOTFIX corrects one identified defect. This Change gives the HOTFIX a judge of the trace HOTFIX, Defect, reproducing Case and, separately, of the revision-bound evidence of a correction: the Case RED against the baseline and GREEN against the corrected revision. It finds a broken link or a not-verified correction, reads missing or stale evidence as UNKNOWN, and flags a diff that spans several capability roots for justification. It never answers PASS: even RED then GREEN does not show that the Case corresponds to the Defect, that the correction is minimal, that it contains no unrelated work and that it genuinely repairs the reproduced behaviour stay unjudged. It is not wired and decides nothing about the Hotfix delivery path, the base, admission or any ruleset.
