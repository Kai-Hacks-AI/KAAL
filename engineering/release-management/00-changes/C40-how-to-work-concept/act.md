# C40 ACT: retrospective (4L)

Written by the agent that carried the Change.

## Liked

- One small Definition that is a mnemonic and prescribes no step. T561 asserts it names no template, chapter or trailer, so the concept cannot grow into a procedure by accident.
- The draft in `interface.md` is the expected text of T560 and T561, so the Definition and its Cases cannot drift apart.

## Learned

- Splitting the old C33 into a concept and one Change per template made each review short: the CPO's single point on the concept was the Owner wording, and it was fixed by one sentence.
- "The Owner stays out of the stroke" was too restrictive. The Owner gives direction without being the default escalation point, and a plan may require Owner alignment where it is needed. The same correction reached the format rule (C41), which allows Owner as an optional interior step.
- The first Branching run on a new or toggled PR fails before auto-merge registers; a later run passes, so it is not a verdict.

## Lacked

- Nothing yet reads the Definition: no template names it and no check refers to it.
- The Resolution rule (paths under `engineering/` or a Node name) is stated once and is not tested against a second Definition.

## Longed For

- The per-template Changes (release/C42 to C47) that give each PR template its HOW TO WORK table.
- A place where the sentence is shown to the Worker and the Reviewer, so the mnemonic is met in the work.
