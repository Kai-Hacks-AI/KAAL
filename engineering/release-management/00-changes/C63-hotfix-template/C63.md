# release/C63 HOTFIX template with HOW TO WORK

Rebuilds the HOTFIX pull request template in release-management with the `HOW TO WORK` chapter of the concept (release/C40), as a source file under `05-src/wiring/templates/hotfix.md`. The chapter is the last of the template and its table keeps the format that release/C41 judges. Its rows are argued from the branch the pull request comes from, a `hotfix/*` branch, and from what that branch requires: the correction from a RED Case to GREEN, on the exact head, and nothing else. They name no other process. Nothing under `.github` changes in this Change: the template reaches `.github` only through a WIRE, which travels alone.
