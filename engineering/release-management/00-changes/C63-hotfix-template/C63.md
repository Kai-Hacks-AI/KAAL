# release/C63 HOTFIX template with HOW TO WORK

Rebuilds the HOTFIX pull request template in release-management with the `HOW TO WORK` chapter of the concept (release/C40), as a source file under `05-src/wiring/templates/hotfix.md`. The chapter is the last of the template and its table keeps the format that release/C41 judges. A HOTFIX pull request goes into a `hotfix/*` branch, a Development pull request that carries the correction. Its rows are argued from that branch and from what it requires to accept the pull request: the correction from a RED Case to GREEN, on the exact head, and nothing else. They name no other process. Nothing under `.github` changes in this Change: the template reaches `.github` only through a WIRE, which travels alone.
