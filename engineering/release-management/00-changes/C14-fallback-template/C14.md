# release/C14 fallback template

The capability: the Intent, the interface, the control and the template text of a fallback pull request template, with the Cases that prove its contract. It is complete and executable by hand without any host: an author copies the text into a pull request body. It installs nothing in GitHub. The wiring of the text into GitHub is release/C15, which comes after this Change is delivered and must install the text unchanged. It defines no specialized type, changes no other template and no control.
