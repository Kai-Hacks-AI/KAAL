# C14 baseline

The baseline is `main`. Work that is not on `main` is not delivered functionality, and this Change depends on nothing that is not on `main`.

- `main` holds a default template, `.github/pull_request_template.md`, with the chapters Intent, Design, Verified by and Validated by. It predates the specialized templates.
- Nothing on `main` states what the default template is for or what it contains.
