# release/C28 analyze Code

The control `analyze Code` is the static analysis of our own code by CodeQL. It is a sibling of `analyze Vulnerabilities` (release/C18): that control checks the dependencies we add, this one checks the code we write. It is its own Change and does not reopen release/C18.

Outcome status: the control is detective. It becomes preventive at a target only when the ruleset of that target requires its contexts, on the Owner's go. This PLAN prevents nothing and changes no workflow, ruleset or declaration.
