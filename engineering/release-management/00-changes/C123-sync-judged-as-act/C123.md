# release/C123 attribution of a pull request's changes: what is the collector's own and what is inherited from main

Controls judge contributions, not reconciliation. A SYNC brings work already on main into a collector; it is not new collector work. Today `controls ACT` reads the diff of the merge result against its first parent as the pull request's own change, so a SYNC is judged as an ACT: limit Act FAILs and demand and verify go UNKNOWN on SYNC #2279 and #2280 (release/D18), and the false FAILs would contaminate the C20 evidence that qualifies the judges for advisory. This Change adds one bounded control that every judge consumes, which says for each changed path whether it is the collector's own, inherited from main, or not established. It does not decide ACT validity and it is not an ACT-specific exemption.
