# release/C123 attribute Changes: a pull request's own changes are told from what main already holds

Controls judge contributions, not reconciliation. A SYNC brings work already on main into a collector; it is not new collector work. Today the runner of `controls ACT` asks Git for the changed paths (the diff of the merge result against its first parent), so a SYNC is judged as an ACT: limit Act FAILs and demand and verify go UNKNOWN on SYNC #2279 and #2280 (release/D18), and the false FAILs would contaminate the C20 evidence that qualifies the judges for advisory. This Change adds a bounded control, **attribute Changes**, that says for each path a pull request changes whether it is the collector's own, inherited from main, or not established. The judges of the ACT consume it; it does not decide ACT validity, and any other control may consume it later.
