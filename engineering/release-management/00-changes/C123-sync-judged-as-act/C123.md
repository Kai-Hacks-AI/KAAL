# release/C123 a SYNC is judged "not an ACT" by the judges of the ACT

`controls ACT` reads the changed paths of a pull request as the diff of its merge result against its first parent. On a SYNC (main merged into a collector) that diff holds everything main brought, so limit Act answers FAIL ("these paths are outside") and demand and verify answer UNKNOWN on SYNC #2279 and #2280. The flags are unset, so no check is red; the false FAILs would count against the judges in the C20 evidence. This Change makes what arrives from main no part of a pull request's own change.
