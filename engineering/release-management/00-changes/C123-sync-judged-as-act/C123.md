# release/C123 the judges of the ACT read a pull request's own changes from files, not from Git

Controls judge contributions, not reconciliation. A SYNC brings work already on main into a collector; it is not new collector work. Today the runner of `controls ACT` asks Git for the changed paths (the diff of the merge result against its first parent), so a SYNC is judged as an ACT: limit Act FAILs and demand and verify go UNKNOWN on SYNC #2279 and #2280 (release/D18), and the false FAILs would contaminate the C20 evidence that qualifies the judges for advisory. This Change gives the judges one shared input, the pull request's own changes, read from three folders of files. Git and GitHub only bring the folders; no judgement reads a commit, a parent or a history. It is an input of the judges, not a new control, and it does not decide ACT validity.
