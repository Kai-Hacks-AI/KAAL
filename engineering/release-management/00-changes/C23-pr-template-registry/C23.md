# release/C23 pr template registry

One authoritative home in Engineering for every pull request template, and one shared mechanism that installs a template into its GitHub location and verifies that the installed copy is the source byte for byte. This Change establishes the registry and the mechanism with SYNC as its only entry. It changes no template text, installs nothing new into `.github`, and adds no hook, workflow, required check, ruleset or publication.
