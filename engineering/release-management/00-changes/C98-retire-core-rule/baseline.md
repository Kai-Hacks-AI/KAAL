# C98 baseline

The baseline is `main`. `check()` in `engineering/change-isolation/check.mjs` fails every path of a change that holds a Core path (`^packages/kaal-core/` or the `.kaal` Engine files) unless the path is Core, one of `CORE_SUPPORT` (the root `package.json`, the root lockfile, `engineering/acceptance/embed.test.mjs`) or a ledger entry admits the exact change. The rule is preventive: the workflow `.github/workflows/change-isolation.yml` (job "Change Isolation") runs it on pull requests and the old rulesets 24952357 (`kaal/**`) and 24951062 (default branch) require that check, so a change that mixes Core with anything else cannot merge today. The new rulesets (27567865, 27596975) do not require it. `.github travels alone` is the second rule, in the same function.
