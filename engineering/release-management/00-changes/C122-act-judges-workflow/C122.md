# release/C122 the four judges of the ACT run on every pull request into a collector, as a report

The four judges of the ACT (hold Act, demand Act, verify Act, limit Act) exist as code with Cases, and nothing runs them on a pull request: the controls are `designed` and report nothing. This Change makes them run where an ACT is made, on every pull request into a collector, first as a plain report (detective), then as a red check behind a flag (advisory), and nothing that blocks. It is the second milestone of the ACT: the ACT governs. The Dispatcher already asks three of them from the tree (release/C116); this is the same question asked at the pull request.
