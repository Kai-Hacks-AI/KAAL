# C32 baseline

The baseline is `main`. Work that is not on `main` is not delivered functionality.

- `main` has PROMOTION, HOTFIX and the Change folders of delivered work. It has no declared contract or delivery scope for any planned package version.
- Change to Intent traceability exists. This Change reuses it and adds none.
- Release Changes in flight (C25 envelope cue, C26 githooks split, C28 analyze Code, C29 rulesets and others) are owned by their threads. This Change does not take over, edit or order any of them.
