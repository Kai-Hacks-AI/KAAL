# release/C137 verify Envelope runs on the pull request, advisory behind its flag

The control release/CTL11 `verify Envelope` is declared and its judge exists (`05-src/plan-body/envelope.mjs`, release/C12, C22, C24, C41), but nothing runs it on a pull request: it is `designed`. This PLAN brings its CI instance up, read only, detective by default and advisory behind the flag `KAAL_RELEASE_VERIFY_ENVELOPE`. It is a PLAN: it builds nothing, installs nothing, sets no flag and changes no ruleset. The WIRE that installs the workflow, and the flag, need the Owner's go.
