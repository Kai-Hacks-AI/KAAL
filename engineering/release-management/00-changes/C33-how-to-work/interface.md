# C33 interface

## F23 draft: the shared final chapter

Every KAAL pull request template ends with one chapter titled `HOW TO WORK`, after the chapters of its type. It is a fixed trailer, not a chapter of the type: its visible text is the same in the template and in every body of that type, it holds only paths (no link, no step, no mnemonic expansion) and the envelope check requires the body to end with it verbatim. The type's own chapter list stays what F3, F10, F11, F14, F15, F16, F18 and F22 say; each adds one sentence that the shared final chapter of F23 follows.
