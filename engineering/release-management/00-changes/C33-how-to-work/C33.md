# release/C33 how to work

Every KAAL pull request template ends with one final chapter, `HOW TO WORK`, that is an entry point and not a copy: it names, for the type of the pull request, where its work and its review are documented. The guidance is written once, per type, in the release capability; the mnemonics HOW, TO and WORK are defined once in an Engineering definition; the envelope check treats the chapter as one shared fixed trailer. This Change is a PLAN only. It installs, promotes and deploys nothing.
