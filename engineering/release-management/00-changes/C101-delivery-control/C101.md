# release/C101 delivery rule is a control that can judge

Two parts, one Intent. First, the rule that delivery travels apart from solution (release/F73), today a function of the Change Isolation checker with no control behind it, is registered as a detective control, release/CTL23 `verify Delivery`, with its classification and its declared minimum evidence. Second, the rule is made able to judge where Change Isolation runs: the wrapper scripts run the checker as a lone copy in a temporary directory, where the delivery reader is not beside it, so on every run that targets `main` the rule printed `cannot judge: the delivery reader is not reachable from the checker` and passed.

The rule stays detective and gates nothing. Making it preventive is the Owner's later decision, after real runs.
