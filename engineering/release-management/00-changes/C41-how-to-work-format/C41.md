# release/C41 HOW TO WORK format rule

The envelope check learns the format of the `HOW TO WORK` chapter: one table of five columns with a Predecessor first and a Successor last. It judges the format only, never the wording of a step. The rule fires only on a body that holds the chapter, so no template and no body changes in this Change.
