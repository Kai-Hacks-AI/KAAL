# C23 baseline

The baseline is `main`.

- release/F16 states that the Defect chapter says what is broken and which state is defective, by package and published version for production. It names no Defect identity.
- The template draft in `00-changes/C11-hotfix/interface.md` has the same Defect hint. The installed `.github/PULL_REQUEST_TEMPLATE/hotfix.md` is not on `main`: its installation, release/C17, is held.
- KAAL Defects exist with the identity `<capability>/D<n>` (for example `hosting/D10`, in `packages/kaal-hosting/06-defects/`).
