# release/C23 hotfix defect reference

The Owner decided on 13 Nov that the Defect chapter of a Hotfix references an identifiable KAAL Defect by its KAAL identity, `<capability>/D<n>` such as `hosting/D10`. A GitHub issue or a URL is not that identity. This Change amends release/F16 and the draft of the Hotfix template of release/C11, and keeps the reference distinct from the Urgency and Approach chapters. It decides nothing about the Hotfix delivery path or the envelope check.
