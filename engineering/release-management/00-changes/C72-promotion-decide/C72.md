# release/C72 the PROMOTION of a collector is decided from its ACT, in a dry run

First slice of the Dispatcher (the Worker that releases work to the next station when the work is ready and the seat is free). Today a person or an agent raises each PROMOTION by hand after the ACT of a collector merged. This Change adds only the decision: a script that reads facts about a collector and says whether its PROMOTION is to be raised, and why not when it is not, and the title and body it would have.

It is a dry run. Nothing is raised, no App exists yet, and no token that can write is involved: the decision is a pure function of data, and the command that wraps it has no network code at all. The live raise (the GitHub App KAAL Dispatcher), the SYNC a behind PROMOTION raises for itself, and the seat with its priority are the next slices (release/C73 to C75).

It is a source in Engineering. Nothing here changes `.github`, a ruleset or a setting.
