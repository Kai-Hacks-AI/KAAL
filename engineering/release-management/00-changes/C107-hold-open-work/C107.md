# release/C107 a promotion leaves no open work behind

On 20 Nov 2026 engineering's C26 PLAN (#2132) was based on the collector `kaal/engineering/setup`. The collector was promoted and deleted, and GitHub silently retargeted the pull request to `main`. Work written for a collector's stations could then have reached `main` without them. The Owner (20 Nov 2026): the promotion of a branch should be blocked while anything still points at it as its base; "plan the control".

This Change is the first slice: the Intent release/I57, the Requirement release/F83, the Architecture element release/A73 (the judge), the preventive control release/CTL27 `hold Open work`, and the judge itself with its command line. The judge is pure: it is given the promoted branch, the promotion's own number and the open pull requests, and says PASS, FAIL naming each pull request, or UNKNOWN. It reads nothing from Git or GitHub. The control is preventive because its purpose is to stop a promotion; it can be so only once the `30 - promoting` station requires its detection, which is the next slice and the Owner's step to load. Until then the judge only reveals.
