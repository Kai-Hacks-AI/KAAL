# release/C42 analyze Vulnerabilities in the stages

Migrates the control `analyze Vulnerabilities` (capability release/C5, on `main`) into ruleset set 1 as its first control: one required check in `integrating` and one in `promoting`, named by the stage, `analyze Vulnerabilities (Integrating)` and `analyze Vulnerabilities (Promoting)`. It supersedes the stale release/C18 collectors, whose targets (Integration, Promotion) and naming predate set 1.

Outcome status: `analyze Vulnerabilities` is detective, always. It reports; whether a ruleset consumes its result does not change that. Any enforcement is a separate preventive control and needs its own explicit Owner decision, outside this Change. This PLAN prevents nothing, changes no workflow, no live ruleset and no declaration. The old `Dependency Review` job and the old rulesets stay until the parallel run has shown equivalence.
