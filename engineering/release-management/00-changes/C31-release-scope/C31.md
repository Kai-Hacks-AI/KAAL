# release/C31 release scope

A planned package version gets a declared scope: a manifest of the Changes it consists of, and a judge that says which are delivered on `main` and which are missing. It makes "what is left for 0.0.1" a Case instead of a conversation, and it keeps many PDCA cycles on `main` from being mistaken for a release.
