# C3 baseline

The baseline is `main`, not the collector of C1 or any open pull request. Work that is not on `main` is not delivered functionality.

- `main` holds no PLAN pull request template and no release-management layout, so no interface guides how a PLAN is produced.
- Nothing on `main` separates the control that guides the production of a PLAN from the control that judges one.
- The requirements of what a PLAN contains sit in the requirement of the judgment, release/F1, of the open C1 work, and the template (release/A4) sits under the GitHub target of verify Plan (release/A2).
