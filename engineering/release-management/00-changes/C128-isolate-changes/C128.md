# release/C128 the control attribute Changes is renamed isolate Changes

Kai named the control that tells a pull request's own changes from what main already holds `isolate Changes` (it works for any synced branch and any judge, so the name is stage-neutral). The control (release/CTL33, release/C123) is on main and installed nowhere: no workflow carries its check, no variable is set. Renaming it now costs no second WIRE; renaming it after the WIRE would cost one and a change of the check name that a ruleset may later require. This Change renames it and changes nothing else.
