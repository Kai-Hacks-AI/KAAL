# release/C21 hotfix route

The envelope check judges the route of a HOTFIX as far as the CPO decided it: the head sits under `hotfix/`. The base is not judged, because the Hotfix delivery path that fixes it is a separate Change, and the result says so. The check also names its verdict: a result with findings is FAIL, a result without findings that left something unjudged is UNKNOWN and never passes, and only a result that judged everything it was given is PASS. It amends the unpromoted release/C12 and decides nothing about the delivery path.
