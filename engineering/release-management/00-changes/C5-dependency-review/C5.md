# release/C5 Dependency Review

Outcome status: the control is detective. It becomes preventive at a target only when the ruleset of that target requires its check, on the Owner's go; this PLAN alone prevents nothing.

Migrates the existing Dependency Review check into the control architecture of release management as the control analyze Dependencies: the old workflow goes, the new realization is declared per target and bound by one required context per target, on the Owner's go, and no protection is reduced at any step.

Semantics: the control is named analyze Dependencies. It analyzes and classifies a result as PASS, FAIL or UNKNOWN. PASS is the only clean go. FAIL and UNKNOWN need a subsequent judgment, which belongs to a separate future agent Skill and an authorized decision process, not to this Change. The S0 component is a deterministic result interpreter, not an agent judge.
