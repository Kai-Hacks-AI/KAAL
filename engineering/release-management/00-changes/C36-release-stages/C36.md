# release/C36 release stages

The abstract concept by which a consumer of `kaal-release` wires release management up through `.kaal/`: a pipeline of Stages that the Skill teaches, the consumer declares and configures as plain files, and a later binding realizes on a platform. This Change defines the vocabulary, the declaration shape and a pure judge of a declaration. It wires nothing.
