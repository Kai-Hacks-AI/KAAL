# release/I7 check PR Body

A reviewer reads a PLAN pull request body that holds only the PLAN's four chapters. Anything an agent or a tool adds around them, such as attribution, hidden metadata or a generated footer, is found by a check before review, so that nobody corrects a body by hand. It is the first check of verify Plan; this Intent stands on its own until verify Plan is on `main`.
