# release/I70 workflow-names-tell-apart

Contract: each workflow of the repository carries a display name that says what it runs, and no two workflows share one, so the Actions list and the checks panel can tell them apart (the intent of the promoted collector `kaal/ci-names`, #328). A workflow named only with the repository's own name says nothing about what it runs. A workflow that conforms stays conforming; the ones that do not are reported and block nothing, and their number only goes down until none is left.

Owner: release management.
