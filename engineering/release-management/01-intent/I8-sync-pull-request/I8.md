# release/I8 sync pull request

A SYNC pull request is understood at a glance as the movement of state that `main` already accepted, driven by a Change: which Change needs it, and why. Source and target are known from Git and the pull request. A reviewer tells a synchronization from new functionality because the body gives a reason and no content of its own. Owner: release management.
