# release/I8 sync pull request

A SYNC pull request is understood at a glance as the movement of state that `main` already accepted: which `main` commit enters which collector, what waits on it, and whether any decision in it is new. A reviewer tells a synchronization from new functionality by one statement, that the synchronization decides nothing of its own. Its body states that and nothing more. The diff, the checks and Git show the rest. Owner: release management.
