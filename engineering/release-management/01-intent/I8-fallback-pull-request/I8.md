# release/I8 fallback pull request

A pull request that belongs to no specialized KAAL type is still understood at a glance: what it changes and why. The default template is the fallback for it and never competes with a specialized template. GitHub does not choose between the two, so the fallback is used by policy and not by enforcement. Owner: release management.
