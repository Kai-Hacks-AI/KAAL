# release/I7 check PR Envelope

A reviewer reads a pull request whose envelope, its title and its body, holds only what the PR convention allows: a title of the form `<TYPE>: <description>`, a body that follows the formatting rule shared by all types and the contract of its own type, and a Change id that agrees with the commits where that is defined. Anything an agent or a tool adds around them, or a title that does not fit the route, is found by a check before review, so that nobody corrects an envelope by hand. It is the first check of verify Plan; this Intent stands on its own until verify Plan is on `main`.
