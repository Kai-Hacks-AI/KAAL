# release/I4 analyze Vulnerabilities

Scope: the control evaluates the dependencies a Change newly adds or changes. It does not report the vulnerability state of every dependency already present in a collector or in a promotion; that is Dependabot's concern and is not changed.

A Change never brings a dependency with a known vulnerability into a collector or into `main` unnoticed, so that the people who admit it decide knowingly, and so that an advisory published after the Change was reviewed is still seen before the Change is promoted. Owner: release management.
