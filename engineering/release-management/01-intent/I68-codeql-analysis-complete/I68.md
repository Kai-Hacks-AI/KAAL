# release/I68 codeql-analysis-complete

Contract: a change reaches integration only when the CodeQL analysis of its merge result is complete, and a check that cannot tell says so and does not pass. Complete means every configuration the workflow declares has an analysis for the merge-result sha, without an error. Missing, errored, late beyond a bounded wait, or unreadable is never a pass. The judge of this Intent reports findings by name and decides nothing: the verdict is the generic preventive judgment. It reads the sha and ref of the run it is in, never the head of the pull request. It says nothing about what the analysis found: that is release/I69.

Owner: release management. SECURITY.md states the requirement ("missing or failed analysis ... must prevent integration"); this Intent is the contract the check keeps.
