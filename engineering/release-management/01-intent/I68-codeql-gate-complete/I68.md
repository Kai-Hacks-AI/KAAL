# release/I68 codeql-gate-complete

Contract: a change reaches integration only when the CodeQL analysis of its merge result is complete and clean, and a check that cannot tell says so and does not pass. Complete means every configuration the workflow declares has an analysis for the merge-result sha without an error. Clean means no open alert at or above the declared threshold. Missing, errored, late beyond a bounded wait, or unreadable is never a pass. The judge reports findings by name and decides nothing: the verdict is the generic preventive judgment. It reads the sha and ref of the run it is in, never the pull request's head.

Owner: release management. SECURITY.md states the requirement; this Intent is the contract the check keeps.
