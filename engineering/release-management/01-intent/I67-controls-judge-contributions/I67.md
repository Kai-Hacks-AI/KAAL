# release/I67 controls-judge-contributions

Controls judge contributions, not reconciliation. What a pull request brings from main is work that is already on main, and it is not the collector's own work: a control that judges a pull request judges what the collector contributed, and says so openly when it cannot tell. The attribution of each changed path to the collector or to main is a control of its own, which other controls consume.
