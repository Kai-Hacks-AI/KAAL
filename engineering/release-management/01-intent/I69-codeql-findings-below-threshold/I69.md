# release/I69 codeql-findings-below-threshold

Contract: a change reaches integration only when no open CodeQL alert on its merge ref is at or above the declared threshold, and a check that cannot tell says so and does not pass. The threshold is data with two dimensions, security severity and rule severity, declared in the workflow source. An alert set that cannot be trusted, because the analyses of that sha are not all there or the alerts cannot be read, is UNKNOWN, never clean. The judge of this Intent reports the alerts by name and decides nothing: the verdict is the generic preventive judgment. It does not name a missing or errored analysis: that is release/I68.

Owner: release management. SECURITY.md states the requirement ("findings exceeding the established security threshold ... must prevent integration"); this Intent is the contract the check keeps.
