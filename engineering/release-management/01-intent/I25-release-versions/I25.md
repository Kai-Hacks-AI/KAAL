# release/I25 release versions

The owner can tell, for a planned package version, two different things that the word Release covers: what the version is (the Intents that make up its product contract) and what is still to be delivered for it (the Changes of its delivery). Many small PDCA cycles reach `main` before a version is published, so neither can be read from the order of merges. Owner: release management.
