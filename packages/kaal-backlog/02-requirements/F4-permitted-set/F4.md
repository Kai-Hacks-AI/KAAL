# backlog/F4 permitted-set

`qualify(diff, { roots, existing })` returns `qualified` only when every entry of the effective diff adds or modifies a Backlog item file: a regular file named `B<n>.md` or `B<n>-<slug>.md` (lowercase slug) directly in one of the roots. Any other path, a deletion, a rename, a symlink, a submodule or a mode change refuses the whole change with one finding per entry.
