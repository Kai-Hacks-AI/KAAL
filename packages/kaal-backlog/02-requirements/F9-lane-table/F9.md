# backlog/F9 lane-table

`qualify(diff, { lanes, existing })` judges a diff against a table of lane entries. An entry is `{ kind, roots, name, allow }`: the payload kind, the roots the routing declares for it, the pattern of a file name directly in a root (capture group 1, when present, is the uniqueness key, otherwise the whole file name), and the pattern every root of that kind must match. Permission is positive: a file qualifies only when its status is `A` or `M`, its path is directly in a root of one entry and its name matches that entry. Any other file refuses the whole change.
