# backlog/F1 shape

An item has an `id` of the form `<namespace>/B<n>` (namespace: lowercase letters, digits and hyphens, with `/` between segments; `n` a positive integer without leading zeros), a non-empty `title` and a `body`. `owner` and `tests` are optional. `check(items)` returns `{ verdict, findings }`. A set with any malformed item, a missing or empty title, or a repeated id is refused whole, with one finding per fault.
