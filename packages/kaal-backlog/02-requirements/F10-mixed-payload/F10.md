# backlog/F10 mixed-payload

A change may carry files of one kind or of several. Each file is judged by the entry it matches and every file must match some entry. Uniqueness is judged per kind on the resulting set (`existing` is given per kind): the same key in two kinds is not a collision, a second file with a key of its own kind is `duplicate-number`, and editing the same file is not a collision. One refused file refuses the whole change, whatever its kind.
