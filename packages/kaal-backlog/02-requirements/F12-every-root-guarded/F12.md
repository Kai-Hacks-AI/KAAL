# backlog/F12 every-root-guarded

F6 holds for every entry: a table with no entry, an entry with no roots, a root that does not match its entry's `allow` pattern, or a root that covers a path of Backlog's own rules is refused whole with `roots-cover-rules`, and nothing in any lane can change Backlog's rules.
