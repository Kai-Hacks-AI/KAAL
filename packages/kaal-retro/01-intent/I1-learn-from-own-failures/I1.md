# retro/I1 an agent learns from its own failures

When an agent acts wrongly or slowly because it did not know how to operate in a place, the agent that acted records what it lacked, in a form the owner of that place can act on. The record is the agent's own account, written right after the correction, and it is built so that each statement has one home: what held up, what it found outside, what blocked it, and what it merely noticed. A fix is proposed once, where it belongs, and the owner decides. One such record is written for each collector that has landed, and it says which Changes it looks back on.
