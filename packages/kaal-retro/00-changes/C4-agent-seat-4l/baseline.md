# C4 baseline

The baseline is `main` at `993d9f0`. There is no `packages/kaal-retro/`. Finished 4L records exist in other packages (for example `packages/kaal-change/00-changes/act.md`) with the four headings and no shared form, and the ACT pull request template says only that the records today are the 4L retrospective.

- The closed collector `kaal/retro/skill` (Changes retro/C1 to C3) holds `skills/kaal-retro/SKILL.md` and `references/4l.md`, written for someone running a retrospective for others. Its content is the starting point for the DO, not the target.
- Kai's direction (20 Nov 2026): the Skill is for the agent's own failures ("what did I lack to act right here?"). The four Ls are four different viewpoints that do not mirror each other. Liked is a concept to keep and protect. Learned is something from outside the consumer, found by looking. Lacked is an observed blocker. Longed For is a nice-to-have that never blocked. A retro is written for a landed collector, not for a Change.
