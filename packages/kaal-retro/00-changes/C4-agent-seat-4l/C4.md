# retro/C4 agent-seat 4L retro

Retro gets its own object, the retro, written by the agent that acted and judged for form by a script. It has one Skill with four distinct lenses (Liked, Learned, Lacked, Longed For) read from the agent's seat, a finder for retros and their `reflects`, and a form-only judgement. It stands alone: a consumer that has only Retro can use all of it. Ids retro/C1 to C3 belong to the closed collector `kaal/retro/skill` and are not reused.
