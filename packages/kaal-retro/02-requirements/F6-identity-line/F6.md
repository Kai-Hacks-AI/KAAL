# retro/F6 identity-line

A retro opens, before its first lens, with one line that begins `Account of:` followed by text that is not empty. In that line I say who I am and what I did with respect to what the retro looks back on, in my own words: how an agent identifies itself is its choice, so no wording is prescribed. The form check judges only that the line is present, first, and not empty; it never reads what it says, and a retro without it is `malformed` with a rule that names it.
