# retro/F4 agent-seat

The Skill is written for the acting agent, not for someone running a retrospective for others. It tells the agent to write the retro itself, right after the correction, while the decision point is in its context, and not to reconstruct it later. It states the four lenses and the rules of F2 in the agent's own words ("what did I lack to act right here?"), tells it to take each Lacked outside the consumer before filling Learned, and says what to do when it has no way to search. Its description states the need in plain words, so an agent finds it through the consumer's own routing and never through a path or a name written into a template.
