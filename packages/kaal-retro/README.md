# @kaihacksai/kaal-retro

KAAL Retro: a retro is the account an agent writes of what it lacked to act right, with four lenses that do not mirror each other. This slice is an Agent Skill, a finder and a form check. It is not published, not deployed where agents discover skills, and not part of the workspaces.

```
skills/kaal-retro/SKILL.md          the Agent Skill, written for the acting agent
skills/kaal-retro/references/4l.md  the four lenses and the result shape
skills/kaal-retro/scripts/          find-retros.mjs and judge-retro.mjs, Node built-ins only
00-changes/ 01-intent/ 02-requirements/ 03-architecture/   the Change that introduces it, traced Intent to Cases
```

It works with nothing else installed. A retro lives in the consumer's `<capability>/02-learnings/retros/`; what a consumer does with a found retro is its own.
