# kaal-retro

A Skill that lets an agent run a retrospective on any subject: finished or ongoing work, a decision, an event, an experience, a process or a product. It needs nothing else installed.

Install the folder `skills/kaal-retro/` (`SKILL.md` and `references/4l.md`). 4L is the first method; others can be added as further references.

`npm test` challenges the written contract and 4L records. Whether an agent follows the Skill is nondeterministic and is judged from trials, not from the tests: see `plan/skill/do.md`.
