# classify/F1 two-questions

Every requirement is classified by two independent questions.

- **Concern.** Solution: what capability or behavior must exist. Delivery: how the solution is made available, integrated, executed or operated. Change: the bounded transition from the baseline toward the target.
- **Semantics.** Target-state: an enduring property, behavior or architectural constraint. Change-oriented: a transition, migration, gap closure or implementation step.

Solution and Delivery are stated in target-state semantics, and Change in change-oriented semantics. Any other pair is a finding: a change-oriented statement inside a Solution or Delivery element, or a target-state statement that exists only in a Change. A Change is not a substitute for a target-state element. It refers to target elements by id and never restates them.
