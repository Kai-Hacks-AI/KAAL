# classify/A1 classify-package

The package `packages/kaal-classify/`, shaped like `packages/kaal-controls/`, owned by Architecture and independent of the older `kaal-architecture` collector. It holds the Skill (classify/A2), `scenarios.json` and a minimal shell. The key is ten statements without a platform: where each is written, the concern and semantics of each part, and its finding (none, mixed, misplaced, weakens-solution, ambiguous or dependency). It is written before the Skill, so that the Skill cannot be tuned to it.
