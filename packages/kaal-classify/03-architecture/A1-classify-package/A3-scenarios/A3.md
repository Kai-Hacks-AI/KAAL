# classify/A3 scenarios

`scenarios.json`: ten statements written without a platform, each with where it is written, the concern and semantics of each of its parts, and its finding (none, mixed, misplaced, weakens-solution, ambiguous or dependency). It is the key that an agent's answers are compared with. An agent given only the Skill answers each statement and its recorded answers are the behavioral evidence that the Skill teaches the distinctions. The key is written before the Skill, so that the Skill cannot be tuned to it.
