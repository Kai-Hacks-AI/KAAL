# classify/C1 classification

Introduces the classification of requirements by concern and semantics as a candidate Agent Skill in the package `kaal-classify`, with the key that shows that an agent given only the Skill classifies, splits and challenges requirements. It is a first slice: no Capability Node, no gate, no deployment of the Skill, no publication.
