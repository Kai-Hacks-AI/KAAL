# engineering/C46 the callers of the controls pass the stations of the repository

Controls C161 makes the station names the adopter's input: `findControls(files, { stations })` and `registryAt(files, station, stations)`. Without the list no station is valid. The stations are Release's routes, and release/C175 (#2999) exports the one list, `STATIONS`, from a module of its own. This Change only makes Engineering's callers import that list and pass it, additive and safe against today's finder, which ignores the extra argument. It defines no second list.
