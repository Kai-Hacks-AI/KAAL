# C23 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C23 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

One Skill, and nothing else, was a good size. Every statement in it could be set against a Case, and the pointers to the owning capabilities kept it from explaining what they explain. Putting the ratchet with Engineering, as its own enduring concept, gave the Skill a clear centre.

## Learned

Core reads any `.md` that starts with `name:` outside a `skills` path as a Node, so a draft must live under a `skills` path. A YAML description cannot hold a colon followed by a space. The Skill uses "Case", the word of kaal-testing, and the owned terms are pointed to their owners by T1176. A Case that spawns the Engineer Skill's checker needs the hosting package linked, which a fresh container lacks.

## Lacked

The root package is already named `kaal-engineering` while the new one is `@kaihacksai/kaal-engineering`, so a rename or a decision is still owed.

## Longed For

The first ratchet, a control on engineering, as its own Change. A WIRE that places the Skill into the skill location, on the Owner's go. A first publication, only if the Skill ever needs one.

## Closed

The Gap of this Change, G113, is closed by Cases T1171 to T1179, all GREEN in the collector where the dependencies are installed. Nothing was published and no delivery was changed.
