# engineering/C31 review-items folder in the layout

Review C5 (kaal-review, PR #2327) introduces Review items `V<n>`, which sit beside the subject they review the way a Case sits in `test-cases`. The package layout has no folder for them, so the layout check could not count them as in spec. This Change adds the folder `review-items` to the layout template and says so in `package-layout.md`. Nothing else in the layout moves, no package is migrated, and the check itself does not change.
