# engineering/C42 the KAAL workflow runs each change once and drops runs a newer push replaces

Promoting found about 30 queued runs, most on macOS: every push to a Change branch starts a run on `push` and another on `pull_request`, and nothing cancels a run a newer push has replaced. This Change cuts that load without changing what is checked. It plans the source of `ci.yml`; the WIRE is separate and needs the Owner's go.
