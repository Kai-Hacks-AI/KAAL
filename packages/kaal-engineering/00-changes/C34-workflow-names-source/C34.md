# engineering/C34 workflow source of verify Workflow names

Release's control CTL36 `verify Workflow names` (release/C124) has a judge and a baseline on `main` but no job that runs them, because the workflow sources go to engineering first. This Change is that source: `13-source/workflows/verify-workflow-names.yml`, a job on plain `pull_request` and `merge_group` with no token and no secret, whose judge code comes from the base and never from the pull request. It installs nothing; the release WIRE does, on the Owner's go, and no ruleset names the check.
