# engineering/C37 the one envelope definition of the pull request types

Release's C138 (#2586) was returned to PLAN: `verify Envelope` must cover all seven types including WIRE, treat DEFAULT as an invalid route, and use one envelope definition shared by the template generator and the verifier. No such definition exists. Kai ruled (26 Nov) that Engineering owns it for now, and warned that parts may already be owned by other capabilities. This Change inventories what already defines the types, chapters and recognition, decides what the one definition holds and what it only references, and plans it as one data file. It changes no template, workflow or check; no WIRE.
