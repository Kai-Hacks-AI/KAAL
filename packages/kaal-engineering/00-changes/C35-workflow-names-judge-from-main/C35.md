# engineering/C35 verify Workflow names runs the judge of the default branch

`verify Workflow names` (engineering C34, installed by #2408) checks out the base commit of the pull request and runs the judge from it. For a pull request into `main` that is `main`'s judge. For a pull request into a collector it is the collector's, which holds the judge only after a SYNC, so a SYNC into a stale collector answers UNKNOWN, "the judge is absent on the base" (found on SYNC #2414). Release C132 (#2415) changes its own `verify-triggers.yml` the same way and asked for the matching Change here. This Change makes the workflow check out the default branch for the judge and `judge-mode`, and read the base and the head only as Git data, as engineering C33 does for the CodeQL gate. No ruleset change and no WIRE.
