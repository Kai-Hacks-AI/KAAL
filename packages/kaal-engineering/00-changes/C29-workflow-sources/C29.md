# engineering/C29 workflow sources

Gives the source of every workflow under `.github/workflows` a home in Engineering, in the capability that owns it: `13-source/workflows/`. This is the `.githooks` answer (release/C26) for workflows: the source lives in Engineering first, the WIRE installs an unchanged copy, and the old and the new place coexist until each old one is moved. This PLAN adds the layout home (F62), names the owner of each of the 21 workflows, and fixes the order and the shape of the moves. It moves no file, installs nothing and wires nothing. The detective control that names a workflow with no source is release's (see "The control").
