# engineering/C39 the embed Acceptance Case reads the Engine through catalog

Core plans to remove the deprecated `capabilities()` before 0.0.1 (core C156, on Kai's go). The embed Acceptance Case (`engineering/acceptance/embed.test.mjs`) is the one place in this repository that calls it, from the installed `kaal-core`. This Change moves that call to `catalog(dir)`, which Core already exports and which returns the same Skills. The Case pins the same thing, that the installed package lists the registered Skill, so this PLAN carries the edited Case and the DO has no source to write.
