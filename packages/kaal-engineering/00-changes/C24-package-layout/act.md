# C24 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C24 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

Making the layout data and testing the data was the right move. After the first review the Cases checked wording, and the Owner called that brittle. Once the layout was a JSON template, a rule broken in the data turned one Case RED and a reworded role sentence turned none. Each element saying what verifies it done gave every Case a clear target. The reviews also changed the content for the better three times: machinery against content, controls as the consumer's, and four `AGENTS.md`.

## Learned

A Case on a document's wording breaks when the document improves, so put the rule in data and test the data. A Case that holds a rule can still be shown to fail for the right reason by a mutant: seven edits to the template each turned the Case that names them RED, and a rewording turned none. A shipped file does not activate itself in a consumer context. The Dispatcher reads the step of a Change from the shape of its PR body, so an ACT body needs a `Change` chapter and a `Records` chapter, and nothing else.

## Lacked

A way to run the package's Cases where the dependencies are not linked: T1228 needs the Engineer Skill's checker and its packages. A check of the layout against a real capability folder: the Cases test the template, not any folder. The source file of the generated `dist/AGENTS.md` is not chosen. Where `AGENTS.md` goes in `engineering/` and `.kaal/` after delivery is for WIRE to say.

## Longed For

The control that tests a correct setup (GREEN) and a bad setup (RED), before any package migrates, so the ratchet has a clean concept to tighten against. That is the next Change. Then migration, package by package, with Hosting first since it already follows a numbered layout, and its "Packaging" pointer moved to kaal-engineering.

## Closed

The Gap of this Change, G114, is closed by Cases T1220 to T1229 and the reference in the Skill. All 19 Cases of the package are GREEN where the dependencies are installed. No package was moved, nothing was published, and no control was added.
