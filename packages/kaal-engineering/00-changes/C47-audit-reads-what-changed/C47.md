# engineering/C47 the Branching audit of a push reads what the push changed

`branching-audit.sh` reads every activity record and every pull request of the repository to its last page on each push to `main` and `kaal/**`, then judges one landing. The shared workflow token's budget (about 1000 calls an hour per repository) is spent by our own CI, and this audit is one of the biggest spenders. This Change makes a push read only what the push changed (two or three calls), makes a branch deletion read nothing, and keeps the full read where it is needed: the daily run. No verdict of the audit gets weaker.
