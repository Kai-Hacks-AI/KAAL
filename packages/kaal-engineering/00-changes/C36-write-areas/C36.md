# engineering/C36 the write areas of PLAN, DO and ACT as data in the layout reference

Release found (C136 #2552, C138 #2558) that the contract saying which paths each phase may write is Engineering's, in the newest layout (`10-intent` to `15-defects`), and asked Engineering to take it.
