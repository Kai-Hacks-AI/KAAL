# engineering/C33 CodeQL gate judges run from the default branch

The two CodeQL gate jobs (engineering C32) check out the merge result and run the judge and `judge-mode` from it, so a pull request that edits the judge runs its own edited version. The CPO's approval of C32 says this self-judging gap must be resolved before the checks are required, and the Owner has said go. This Change makes each gate job check out the judge and `judge-mode` from the default branch and read only the pull request's data, which the judges read from the API by sha. No ruleset change and no WIRE.
