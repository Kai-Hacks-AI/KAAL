# engineering/F94 gate judge from the default branch

The CodeQL gate jobs run the judge and `judge-mode` from the default branch and not from the pull request. Each gate job has exactly one checkout, of the default branch, without persisted credentials, and checks out nothing of the pull request. The job environment does not set `GITHUB_SHA` or `GITHUB_REF`, so the judge asks about the event's own sha and ref. The same rule holds for every trigger of the workflow.

**Done when** in `13-source/workflows/codeql.yml` each of the two gate jobs has one `actions/checkout` with `ref: ${{ github.event.repository.default_branch }}` and `persist-credentials: false`, no checkout of the head or merge result, and no `GITHUB_SHA` or `GITHUB_REF` in its environment.

This does not stop a pull request from editing the workflow file itself; that is the Inspector's, as the PLAN says.
