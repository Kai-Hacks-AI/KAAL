# engineering/F58 learnings home

The steering folders before the numbered concerns are `00-backlog`, `01-changes` and `02-learnings`. `02-learnings` holds what the capability learned: its `retros` folder holds the retrospective of each collector, kept with the capability, each with front matter `reflects: [C…]` that names the Changes it looks back on. The retrospective itself is kaal-retro's object, and so is the rule for what verifies one; the layout only gives it a place and leaves any other child out. A package with no `02-learnings` is not judged for it, as for any absent folder.

**Done when** the template names `02-learnings` between `01-changes` and `10-intent`, with `retros` as its only child, and the check says PASS for a folder with `02-learnings/retros` and FAIL, naming it, for any other folder inside `02-learnings`.
