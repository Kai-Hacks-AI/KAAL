# engineering/F40 stages

The Skill names the four stages one source passes through and the role of each: `packages/<cap>` is where the capability is developed; `engineering/<cap>` uses the unpublished version N+1; npmjs publishes N; `.kaal/<cap>` uses the published N. It says `engineering/<cap>` is optional: a capability that uses only `.kaal` needs no folder there.
