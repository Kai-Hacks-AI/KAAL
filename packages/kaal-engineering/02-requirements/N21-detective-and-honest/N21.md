# engineering/N21 detective and honest

The check reveals and gates nothing. It reads and writes nothing in the folder. When it cannot judge, because the template or the folder cannot be read, it says UNKNOWN and exits with a code that is not a pass. It never turns UNKNOWN into PASS.

**Done when** an unreadable template or an empty folder is UNKNOWN with a non-zero exit code, and a run leaves the folder as it found it.
