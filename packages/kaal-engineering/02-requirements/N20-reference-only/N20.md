# engineering/N20 reference-only

The layout is a reference in the existing Skill and nothing more: a page and its data under `references/`, no script of its own (the layout check of C25 is the one script, A4), no control, no new package file outside the Skill, and no existing package moved. Migration comes later, package by package.

**Done when** the package still ships `payload` and `skills` only, the Skill has no script, and the reference is inside the Skill.
