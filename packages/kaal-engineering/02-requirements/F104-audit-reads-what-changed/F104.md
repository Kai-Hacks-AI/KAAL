# engineering/F104 the Branching audit of a push reads what the push changed

A push is judged from the facts of that push. The full read of the repository stays with the daily run.

**Done when** a push that lands makes at most three GitHub calls and reads no list to its last page, a branch deletion makes none, the creation of a collector reads the default branch's activity only, every audit says how many calls it made, and the daily run still reads everything and still fails a merge no pull request accounts for.
