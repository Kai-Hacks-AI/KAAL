# engineering/F45 layout

The Skill carries one layout, as data and as an explanation, for `packages/<cap>`, `engineering/<cap>` and `.kaal/<cap>`: the root files and the folders `00-backlog`, `01-changes`, `02-controls`, `10-intent`, `11-requirements`, `12-architecture`, `13-source`, `14-defects` and `dist`, in number order.
