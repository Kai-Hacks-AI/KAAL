# engineering/F61 review home

A targeted review that we deem worth keeping is persisted in the reviewed capability's `02-learnings/reviews/`, beside `retros`, `research` and `rehearsals`, with the id `RV<n>`. Not every review is kept: a review is persisted only when it is deemed worthy, and that decision, with the rule for what makes one worthy and for what verifies one, belongs to the review capability. The layout only gives the place. `14-operations` does not hold reviews. A package with no `reviews` is not judged for it, as for any absent folder.

**Done when** the template names `reviews` among the children of `02-learnings`, and the check says PASS for a folder with `02-learnings/reviews`, with or without the other three, FAIL naming it for any other folder inside `02-learnings`, and FAIL naming it for a `reviews` folder inside `14-operations`.
