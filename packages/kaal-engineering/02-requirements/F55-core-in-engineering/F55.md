# engineering/F55 core in engineering

While kaal-core has no release tag it has no N, so `.kaal/` holds no Core and the repository's own copy of Core, its Kernel, its `AGENTS.md` and its Nodes, sits in `engineering/core/` as the source of the untagged state. The repository's entry point `AGENTS.md` at the root names that folder and its `AGENTS.md`, so an agent still finds its way to the Engine. Content under `.kaal/` that is not Core (`config/`, `changes/`) is not touched.

**Done when** the Kernel, the `AGENTS.md` and the nine Core Nodes are in `engineering/core/` and not in `.kaal/`, and the root `AGENTS.md` names `engineering/core` and `engineering/core/AGENTS.md`.
