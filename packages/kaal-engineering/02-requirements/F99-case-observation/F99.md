# engineering/F99 the job that observes the Cases for hold Act

`13-source/workflows/observe-cases.yml` is a reusable workflow with two jobs on a pull request's own CI and read-only access: `run-cases` runs the Case files Release lists for the carried Changes with Testing's `run` and uploads only the report, and `observe-cases` (no candidate code) runs `observe-at --report` over the same files and uploads artifact `observation` holding `observation.json`, the file hold Act reads. The tool and the judge come from the default branch, the pull request only as data. It decides no verdict.
