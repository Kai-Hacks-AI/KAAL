# engineering/F99 the job that observes the Cases for hold Act

`13-source/workflows/observe-cases.yml` is a reusable workflow that, on a pull request's own CI and with read-only access, runs Testing's `observe-at` over the Case files Release lists for the carried Changes, and uploads artifact `case-observation` holding `observation.json`, the file hold Act reads. The tool and the judge come from the default branch, the pull request only as data. It decides no verdict.

**Done when** the file exists as described and T1570 to T1572 are GREEN.
