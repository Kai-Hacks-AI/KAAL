# engineering/F57 check follows the template

The layout check judges a folder against the template and nothing else, so the new numbering needs no change to its rules. A folder the template marks closed may hold only the children it names, which today is `13-source` and `14-operations`. A folder with the earlier numbering (`02-controls`, `14-defects`) is a numbered folder the template does not have, and is named.

**Done when** a folder with `14-operations/controls` and `15-defects` is PASS, with or without `14-operations/runs`; a folder with `02-controls` or `14-defects` is FAIL and names it; a stray folder in `14-operations` or in `13-source` is FAIL and names it; a folder with `14-operations` but no `controls` is FAIL; a folder with no `14-operations` is FAIL and says it is missing (F91 marks it required).
