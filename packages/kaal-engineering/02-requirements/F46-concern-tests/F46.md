# engineering/F46 verified by

Intent, requirements, architecture and defects each say what verifies that they are done, and the layout gives that verification a place: `test-cases/` in their folder. The source is verified by `unit-tests/`. A defect's test-cases are the ones that prove it.

**Done when** each element folder of the template names a verifying child folder that the folder itself holds, and so does the source folder.
