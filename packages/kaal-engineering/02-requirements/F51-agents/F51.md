# engineering/F51 agents

The layout has four `AGENTS.md`, each serving a different thing, with the repository root on top: `AGENTS.md` at the root for work across the repository, `packages/AGENTS.md` for work across packages, `packages/<cap>/AGENTS.md` for work on that package (not shipped), and `packages/<cap>/dist/AGENTS.md` for consumers using the capability (shipped, built from `13-source`, never edited). The shipped one sits above the Skill: it points to the Skill's `SKILL.md` and does not repeat it. The Skill and its references guide use; the package's own `AGENTS.md` guides work.

**Done when** the template lists the four, each with what it serves and what verifies it (review for the three that guide work, the build for the shipped one), exactly one of them ships, the shipped one is under `dist`, is built from the source and points to a Skill without repeating it.
