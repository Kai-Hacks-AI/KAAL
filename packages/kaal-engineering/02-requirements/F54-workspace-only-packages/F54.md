# engineering/F54 workspace holds only packages

`packages/` is special because of the workspace: it holds packages, and beside them only `AGENTS.md` and `README.md`. Any other file, or a numbered steering folder, is a fault. The check names it.

**Done when** `--workspace` on a folder of packages with `AGENTS.md` and `README.md` is PASS, and on one that also holds another file or a numbered folder is FAIL and names it.
