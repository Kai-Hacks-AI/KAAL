# engineering/F98 the KAAL adaptation of the pull request types

`skills/kaal-engineering/references/pull-request-types.json` lists the seven TYPEs this consumer uses (PLAN, DO, ACT, SYNC, PROMOTION, HOTFIX, WIRE), the capability that owns each one's content (`kaal-change` or `kaal-release`), and names DEFAULT as an invalid route, never as a TYPE. It holds no chapter, text or recognition rule: owners declare those through Hosting, which owns the template generator. The areas of a TYPE stay in `write-areas.json`.
