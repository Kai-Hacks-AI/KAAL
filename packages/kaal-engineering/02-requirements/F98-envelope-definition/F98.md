# engineering/F98 one envelope definition

`skills/kaal-engineering/references/pull-request-types.json` is the one definition of the pull request types. It holds the seven TYPEs (PLAN, DO, ACT, SYNC, PROMOTION, HOTFIX, WIRE), for each the chapters in order and how it is recognised by base and head branch, and names DEFAULT as an invalid route, never as a TYPE. It references and does not copy the areas a type may carry (`write-areas.json`), the branch patterns of the rulesets, the delivery locations of a WIRE and the judge's own rules. `write-areas.json` holds no recognition.
