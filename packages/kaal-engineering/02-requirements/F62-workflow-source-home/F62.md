# engineering/F62 workflow source home

The source of a workflow installed under `.github/workflows` lives in the capability that owns it, in `13-source/workflows/<name>.yml`, as a file the WIRE copies without change. A workflow is machinery, written in the capability and deployed elsewhere, as `13-source` already says of the Skill and the scripts. A package with no `workflows` is not judged for it, as for any absent folder.

**Done when** the template names `workflows` among the children of the closed folder `13-source`, and the layout check says PASS for a folder with `13-source/workflows/<name>.yml`, with or without `skill`, `scripts` and `unit-tests`, and FAIL naming it for any other folder in `13-source`.
