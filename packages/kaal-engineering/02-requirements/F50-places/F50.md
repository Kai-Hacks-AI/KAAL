# engineering/F50 places

The package is deployed: its machinery is written only in `packages/<cap>`, deployed as N+1 to `engineering/<cap>` and as N through npmjs to `.kaal/<cap>`, and a deployed copy matches its source, so a hand edit there is waste. Content is local: the capability's own in a package, the consumer's data, produced by the capability, in `engineering/` and `.kaal/`. It is never deployed and never compared. A repository with no KAAL packages has only `.kaal/<cap>`.

**Done when** the template gives each of the three places a machinery rule and a content rule, writes machinery in the package only, and states that content is local, never deployed and never compared.
