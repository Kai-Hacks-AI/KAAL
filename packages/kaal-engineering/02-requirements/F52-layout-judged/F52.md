# engineering/F52 layout judged

The check judges one capability folder against the layout template of the kaal-engineering Skill, from the tracked files of the folder alone. It names each numbered folder the template does not have, each element folder or the source that lacks the folder that verifies it, and each folder inside `13-source` the template does not have. A folder that holds none of the layout's numbered folders is also a fault. A folder with none of these faults is PASS.

**Done when** a folder that follows the template is PASS, and a folder with one such fault is FAIL and names that fault and nothing else.
