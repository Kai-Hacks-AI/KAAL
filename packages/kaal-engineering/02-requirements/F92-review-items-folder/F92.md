# engineering/F92 review-items folder

The layout names a folder `review-items` as a child, beside `test-cases`, of each element folder `10-intent`, `11-requirements`, `12-architecture` and `15-defects`. It holds the Review items `V<n>.md` of that element's subjects. It is optional: a package with none is not faulted. It is not a child of `13-source`, `14-operations` or `02-learnings`, and it is not the `verifiedBy` of anything. `package-layout.md` says what it holds and that the results `RV<n>` sit in `02-learnings/reviews`.

**Done when** the template lists `review-items` among the children of those four folders and of no other folder; a package that holds `review-items/V1.md` in each of them and none elsewhere is PASS, and so is one with none; and `package-layout.md` names `review-items`, the Review item and `02-learnings/reviews`.
