# engineering/I4 layout kept

A capability folder follows the layout that engineering settled, and a folder that does not is noticed, so the ratchet has a clean setup to tighten against. A correct setup and a bad setup can each be told from the other by a deterministic check.

**Done when** the check says PASS on a folder that follows the layout and FAIL, naming what is wrong, on a folder that does not.
