# engineering/I3 package layout settled

A person or an Agent starting a capability, or cleaning one up, knows which folder holds what, in which order the folders read, which parts are deployed and which are local content, and what verifies that each is done. The layout is settled once, by the capability that owns engineering alignment, and the same layout holds in `packages/`, `engineering/` and `.kaal/`.

**Done when** a reader can take the Skill's template and, for any folder of a capability in any of the three places, say whether it is machinery or content and what verifies it.
