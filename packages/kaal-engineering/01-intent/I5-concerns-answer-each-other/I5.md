# engineering/I5 concerns answer each other

The numbered concerns of a capability follow one order, and each answers the one before it: Intent says why, Requirements say what, Architecture gives the shape, Source is what is built, Operations is how it is run and observed, and Defects are what that operation and observation can reveal. Source has to be run to deliver behaviour, and Controls need execution to produce evidence, so Controls sit with Operations and not early. The numbers only order the folders. Who reads or writes a folder is told its location and never looks it up by number or by name.

**Done when** the layout lists the concerns in that order, with Controls inside Operations and nowhere else.
