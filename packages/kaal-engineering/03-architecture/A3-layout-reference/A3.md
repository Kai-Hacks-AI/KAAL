# engineering/A3 layout reference

The layout is two files, `skills/kaal-engineering/references/package-layout.md` and `package-layout.json`. The data is the template, the page explains it. `SKILL.md` links the page by one line under a heading of its own. They stay inside the Skill (N19): no script is added, the package ships `payload` and `skills` only, and `check-skill` still passes. The reference owns the layout and points to no other capability's concept. Hosting's numbered folders and its `AGENTS.md` pointer to "Packaging" are not changed here; moving that pointer to kaal-engineering is a later Change.

**Done when** the Skill links a page that exists, the page sits beside its data, and the package still passes the Engineer Skill's checker.
