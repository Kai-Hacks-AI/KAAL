# Pull Promotion v1 capability: Requirements (target)

Scoped `pull/` (ids are global). Its input is its own small contract, stated here; it names no other capability's contract. `pull/C1`'s requirements stay as the record of what shipped; the DO retires those that this target drops.

**Input.** `facts`: `collectors` (`name`, `at` the head version, `checks` as `name` and `conclusion` success, failure or pending, on the head); `pieces` (`ref`, `type`, `change`, `into`, `state` landed or open or dropped, `landedAt`); `deliveries` (`collector`, `delivered`, `landedAt`). `declaration`: `collectors` (`name`, in their promotion order), `lifecycle` (the piece types of PDCA, for KAAL PLAN, DO, ACT), `checks` (the names of the checks that are the Check phase).

- **pull/F21. Walk the declared collectors.** `walkCollectors(facts, declaration)` returns one entry per collector the declaration lists, in the declared order, once each. A declared collector the host does not have is not judged, naming the missing collector. A host collector the declaration does not list is named in `undeclared` and not judged. A declaration that lists no collectors yields no entries and a problem saying so. The same facts in any order give byte-identical output.
- **pull/F22. PDCA, from evidence.** A collector qualifies when every Change in it that has not been delivered has every `lifecycle` type landed in that collector (landed in another collector, or open, does not count) and every declared check is a success on its head. It does not qualify when a phase is missing or a check failed, naming which, for which Change. It is not judged, naming the missing fact, when a check has no run or is not finished, when the collector has no check evidence, when a piece names no Change, or when a delivery has no landing time. A piece belongs to the undelivered Change only if it landed after the collector's last delivery. A collector with no undelivered Change does not qualify, saying so. Unknown never qualifies.
- **pull/F23. Prioritize, from the declaration.** The qualifiers are listed in the declared order and the first is named as `next`. When none qualifies, `next` names no collector and gives a reason, and every collector says what is missing. The order is the declaration's alone; the Script invents none.
- **pull/F24. Advisory, nothing more.** The output never says ready or blocked, never authorizes a promotion and never recommends an action. The Script reads no review, no distance to the target and nothing of Show WIP. It imports only a file reader, is read-only, and its command line reads two files, prints the result as JSON and exits 0 whenever it printed one, non-zero naming an unreadable file.
