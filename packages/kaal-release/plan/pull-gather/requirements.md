# Pull Promotion: the delivery candidates are gathered, not written by hand (target)

Scoped `pull/` (ids are global). Nothing of pull/F25 to F49 is relaxed. Everything is advisory and read-only.

- **pull/F50. Every head ref of a delivery class is a candidate, and nothing else is.** `gatherDeliveries(facts)` returns `deliveries`, a list of `{class, source, name, sha, out, in}`. A head whose ref starts with `hotfix/`, `wire/` or `kaal/` becomes a candidate of the class `HOTFIX`, `WIRE` or `KAAL`, with `source` the ref, `name` the ref without the prefix and `sha` the head. Any other ref, or a ref with an empty name, is ignored and never appears as a candidate. The result has the shape `laneStep` takes in `state.deliveries`.
- **pull/F51. A side is PASS only on evidence at the exact head.** For each candidate, `out` and `in` are computed from the contexts the class declares for that side (`facts.classes[CLASS].out`, `.in`) and the check runs of `facts.checks`.
  - `PASS`: every declared context has a completed check run with conclusion `success` on the candidate's own `sha`.
  - `FAIL`: not PASS, and at least one declared context has a completed run on that `sha` with a failing conclusion.
  - `UNKNOWN`: everything else, including a missing context, a run still pending, a neutral or skipped run, a run on another SHA, a conclusion `held` or any unrecognised value, and a class that declares no contexts for the side. UNKNOWN never becomes PASS.
- **pull/F52. Nothing is invented.** The gatherer does not run a check, compute a qualification, or record a value, size or unit. For `KAAL`, `out` is the verdict of the supplied Pull Promotion report for the same collector at the same `sha`: `PASS` when the report names it as qualifying at that `sha`, `FAIL` when it names it as not qualifying at that `sha`, `UNKNOWN` when there is no report for it or the report is for another `sha`. Facts that are missing or not lists give no candidates and a finding, never a guess. The result is a function of its input and does not change it.
- **pull/F53. Facts are read by GET calls only.** The reader that fetches `facts` from the host uses only read requests (method GET) to list refs, pull requests and check runs. It sends no request that creates, updates, merges, approves, comments or dispatches, and a request that fails or is paged out gives `UNKNOWN` for what it could not read, never `PASS`.
