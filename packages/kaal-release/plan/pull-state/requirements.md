# Pull Promotion from file state: Requirements (target)

Scoped `pull/` (ids are global). Replaces the input and the judgments of pull/F21 to F24 for the capability; those stay as the record of what shipped.

**Input.** `facts.collectors[]`: `name`, `at` (the head), `delta` (the files that differ from `main`: `path`, `status` added, modified or removed, `changedAt` the time it was last changed on the collector), `texts` (the text of the files the judgment reads, by path), `executions` (one per run of a Test Case: `case`, `head`, `conclusion` success, failure or pending, `at`). `declaration`: `collectors` (`name`, in their promotion order) and `evidence`: `plan` and `do` (lists of path patterns (regular expressions)), `cases` (`files`, a path pattern whose first group is the Case id), `act` (`files` a path pattern and `headings` the four 4L headings).

- **pull/F25. Walk the declared collectors.** One entry per collector the declaration lists, in the declared order, once each; a collector the host lacks is not judged naming it; a host collector the declaration does not list is named in `undeclared`; an empty declaration is a problem. The same facts in any order give byte-identical output. (Carried over from pull/F21.)
- **pull/F26. PLAN and DO from the delta.** A collector has PLAN when at least one file of its delta that is not removed matches a `plan` pattern, and DO when at least one matches a `do` pattern. No PLAN or no DO means it does not qualify, naming which. An empty delta does not qualify, saying so. The judgment reads paths only, never a pull request, a title or a trailer.
- **pull/F27. CHECK from the latest execution of each expected Case.** The expected Cases are the ids of the delta files that match `cases.files`. Each needs an execution at the current head of the collector; the latest one (by `at`) counts and must be a success. A failure means it does not qualify, naming the Case. An expected Case with no execution at the current head, or whose latest is pending, means not judged naming it. A delta with no expected Case is not judged naming "an expected Test Case". An execution at an older head never counts.
- **pull/F28. Exactly one concluding ACT, after PLAN and DO.** The ACT files are the delta files that match `act.files` and whose text holds all four headings. None means it does not qualify, naming the ACT; two or more mean it does not qualify, naming them (one conclusion only). The one ACT must have been changed no earlier than any PLAN or DO file; otherwise it does not qualify, naming the file that came after it. A candidate whose text was not read is not judged.
- **pull/F29. Declared evidence, not a default.** A declaration with no `evidence`, or with an empty `plan`, `do`, `cases` or `act` entry, makes every collector not judged naming the missing declaration, never a vacuous pass. (Carried over from pull/T25.)
- **pull/F30. Provenance is not evidence.** The capability reads no pull request, title, trailer or review. Facts that carry pieces or pull-request fields yield the same result as facts without them.
- **pull/F31. Prioritize and stay advisory.** The qualifiers are listed in the declared order and the first is named as `next`; none qualifying gives the reason and what is missing per collector. The output never says ready or blocked, never authorizes a promotion, never recommends an action. Read-only, imports only a file reader. (Carried over from pull/F23 and F24.)
