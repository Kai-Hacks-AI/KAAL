# Consumer Agent instructions

An Embed consumer may propose this concise instruction through its governed installation Change:

> Use the installed kaal-branching Skill for branch establishment, Change integration, synchronization, promotion and audit. Resolve the governed repository, mode and trusted target-policy source first; report unsupported or unverifiable operations.

Point to the consumer's actual installed Skill location. Keep branch names, transaction methods and policy in the consumer declaration and product implementation.

An External controller keeps its instructions and runtime in the controlling environment. It does not install or write Agent instructions, .kaal, Skills or KAAL CI inside the target repository.
