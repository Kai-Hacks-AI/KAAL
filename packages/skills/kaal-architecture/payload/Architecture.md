# Architecture

Architecture is the capability for architectural decisions in KAAL. Its scope is the decision and its grounds. It holds Enterprise Architecture, which decides how required capability is made available for use and how the parts compose, by the principle `URBAN`, and Solution Architecture, which places required function within a solution.

Architecture plans the city; it does not build every building. Realizing a chosen solution is Engineering's, including whatever Adapt or New the decision calls for, and the target that solution is born on is set by Engineering's BACCHUS once the choice is made. Whether a capability respects the boundaries it declares is Testing's. Keeping what was chosen current is the concern of whoever maintains it.

Architecture keeps no sourcing engine, catalogue of options or vendor registry. Each decision states its own grounds, and an architectural decision grants no authority to make the Change that realizes it.
