# Learning

Learning is the capability for knowledge in KAAL: retaining what has been understood from work done in KAAL, improving that understanding, and letting later work start from it. Its scope is that alone. How Nodes are identified, related and navigated is Graph's, and what a test demonstrates is Testing's. Observing and reviewing work, the course of a Change, and what any capability decides from what it knows stay with the capabilities that own them.

Knowledge informs work. It grants no authority, and it is not approval.
