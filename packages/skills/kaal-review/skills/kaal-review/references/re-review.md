# Re-review

Set `prior` to the earlier record id and raise `round`. For each earlier finding, observe the current work and set `status` to `fixed` or `not fixed`, with evidence. Add new findings as new ids.

Convergence is an observation: `collect` reports whether no finding at or above the floor is open. It is not acceptance. Whether to accept the work, and whether another round is needed, is the scope holder's decision, not Review's.
