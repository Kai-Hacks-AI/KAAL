# Packaging readiness (LOVE): Requirements

- **intent/F15. Installation Contract** [intent/I8]. `kaal-intent` states what an installation of it is in one Installation Contract instance, in the format Core owns, so Core's installer or any other can install, upgrade and remove the result. The instance lists the Skill Node, the three Definitions and the Agent Skill with their targets, and nothing Intent does not own. Intent states it, Core judges it, and Intent defines no installer.
- **intent/F16. Claim follows the package** [intent/I8]. The ownership claim names the package's actual location and the Skill Node by name and id, and the claim and the location move together when the package does. The flat-layout move itself is a separate Change.
- **intent/F17. Boundary stated where a consumer reads it** [intent/I8]. The README names every Node a consumer may rely on, and what Intent does not decide: where Intents are kept, their relation to Requirements, Changes or each other (`intent/F8`), and any trigger or Defect boundary the CPO has not settled (`intent/C8`).
- **intent/F18. Verification from the installed copy** [intent/I8]. A consumer can run documented commands, shipped inside the package, that check the installed Nodes against the contract and say plainly which cases ran. The consumer set is told apart from the publisher's cases, which stay in the repository. No case is claimed to have run in an installation where it did not, and an empty run is never GREEN.
- **intent/F19. Packed contents are exactly declared** [intent/I8]. The packed package holds the declared files and no others, observed from the packed artifact in a clean install and not from the repository.
- **intent/N4. No new owner** [intent/I9]. None of this adds a registry, index or store of Intents, a runtime dependency, or a rule about another capability's Intents (`intent/F3`).
- **intent/N5. Honest limits** [intent/I8]. The README says what is not covered while a gap remains. In particular, until Core offers a path to upgrade or remove a registered contribution, lifecycle is documented as partial.
