# kaal-roles

KAAL Roles: a provisional home for the CTO Advisor and CPO Advisor definitions, until their owners take them. It is not part of Core. Core provides the `KAAL Capability` and `KAAL Definition` types and admission, and this capability joins through them.

```
capability/Roles.md          the Capability Node, typed by Core's KAAL Capability
capability/CTO-Advisor.md    the CTO Advisor Definition, typed by KAAL Definition; eventual owner Engineering
capability/CPO-Advisor.md    the CPO Advisor Definition, typed by KAAL Definition; eventual owner Product
ownership.kaal.json          Roles' own ownership claim (repository data, not delivered)
```

## Provisional

Each Capability defines and owns the Roles it needs; Roles is an incubation arrangement, not a precedent. Engineering and Product each take their definition into their own Capability by their own Change, and this package is then removed. It is private and not published. See the PLAN in `.kaal/changes/roles/26/11/02/01/README.md`.
