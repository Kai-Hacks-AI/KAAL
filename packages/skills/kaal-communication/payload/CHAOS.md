# CHAOS

Changes Helping Agent Orders Systematically.

Discussion goes to the highest appropriate destination among those relevant to it: (1) an open Change; (2) otherwise an open conversation; (3) otherwise a new shared conversation; (4) only as a last resort, a direct chat with an Agent, which is transient. Not every message belongs with a Change: the order exists to avoid random routing and needless fragmentation. Anything worth keeping from a direct chat is routed to a suitable shared home and not left in a session. CHAOS governs only where discussion takes place, not how intentions are captured or managed.
