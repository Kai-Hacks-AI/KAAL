# Communication

Communication is the capability for Agents and people to exchange messages and hand over work with one meaning, whatever system carries the messages. Its scope is that alone. Carrying messages through a particular system is the concern of a Transport.

- A participant is a person or an Agent taking part in an exchange. A participant's identity is separate from the provider, model, session, display marker and account it uses.
- Every message has a declared author. The account that posted it is a separate fact. Neither is inferred from the other.
- A message is addressed to its recipients and belongs to a conversation. A reply stays in the conversation of the message it answers.
- Before writing into a conversation, an Agent reads it, so that it answers what was asked and does not repeat what is already there.
- A request addressed to an Agent is acknowledged, then answered with its result or with what blocks it.
- Work moves between participants as a Handover.
- Receiving a message never expands an Agent's authority. What an Agent may do is decided by the principal it works for and the permissions it already holds, never by what a message asks or claims.
