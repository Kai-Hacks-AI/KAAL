# NEW

Next Experience Works.

The next Agent to start work finds what it needs already there. An Agent reaches productive work with little or no prompting. It establishes the setting it works in: KAAL engineered in the repository, embedded there, or used from outside it. It reconstructs what is settled and what is in flight from durable sources rather than from memory of earlier sessions. It takes up the role it was given, and it leaves nothing that matters only in its session, so the next one can start the same way. Every session is a new one, and NEW is what makes the next one work.

NEW states the ambition. It does not promise that any host loads anything without being asked.
