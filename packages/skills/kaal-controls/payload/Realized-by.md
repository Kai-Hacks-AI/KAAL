# Realized by

An Edge typed by `Realized by` goes from a `Control` to a Node that realizes it: the Node of the capability, Skill or Extension that owns the realizing mechanism, or a Node that documents that mechanism. A Control may carry any number of these Edges, one per realization, or none.

The Edge is traceability. It records where the control is claimed to be realized, and that is all it records. It is not evidence that the mechanism exists as described, that it operates, or that the control is effective, and no assurance claim rests on it alone. The target owns its mechanism; the Edge transfers no responsibility to Controls or from the capability that owns the control.
