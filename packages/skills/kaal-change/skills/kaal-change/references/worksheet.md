# Change isolation worksheet

Use this as an agent's report outline. Fill evidence gaps with named unknowns,
not invented references, successful statuses or template defaults.

1. **Proposal:** intended outcome; exact proposed alterations; selected owners;
   versions of the Change and supplied evidence.
2. **Trace:** Intent, functional/nonfunctional Requirements, relevant Defects,
   Architecture, interfaces, Cases and realizations; missing links and sources.
3. **Scope and surroundings:** selected work; potential impact outside it;
   dependencies; why the boundary is reasonable or unresolved.
4. **Interfaces:** direction, owned endpoints and contract; incoming driver;
   outgoing controlled collaborator; real subject kept under test.
5. **Testing work:** architecture-conformance, capability-acceptance and
   implementation Cases; discriminating RED/GREEN evidence; Defect regressions;
   separate contract and real-integration evidence. Mark work not yet executed.
6. **Findings and decisions:** model assessment with its coverage; repository
   authority limitations; actual observed execution; independent validation and
   Owner decisions; next evidence or decision required.

If execution is unavailable, report useful reasoning and unknowns without
claiming that the API or a Test Case ran. Reassess after referenced inputs change.
