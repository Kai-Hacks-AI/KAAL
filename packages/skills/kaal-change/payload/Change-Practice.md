# Change Practice

Change Practice guides an agent in proposing a bounded alteration, tracing the concerns it affects, identifying crossing interfaces and coordinating evidence across testing loops. Its initial scope is semantic isolation over explicitly supplied owner evidence. It keeps the selected scope distinct from potential impact and preserves missing evidence as unknown.

The Change capability owns isolation and coordination. Concern owners define Intent, Requirements, Defects, Architecture and interfaces. Graph owns traversal; Testing owns tests, doubles and execution evidence. This Skill grants no repository, integration or release authority and establishes no outcome from integration alone.
