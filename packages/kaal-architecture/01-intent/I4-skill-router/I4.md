# architecture/I4 skill-router

An agent that needs the Architecture Skill finds the rule it needs without reading everything: `SKILL.md` is a short router that says what Architecture is, gives the test and points to the detail, and the detail lives in references the router names. The Skill meets the Skill standard of Core (one entry point, `references/` for the detail, three size levels) and keeps the content that is Architecture's own. Restructuring a Skill moves its content and removes no rule. Owner: Architecture, for what the Skill says; Core owns the standard it is measured against.
