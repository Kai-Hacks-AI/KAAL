# architecture/I2 record-mechanics

Every Architecture record in KAAL, an A-record such as `controls/A5` or `foundation/A7`, is a checked record: it has one form, it says which Requirements it addresses, and its id is allocated by Architecture and never counted by hand. So that where a solution is placed can be read from records and judged, not from prose. Owner: Architecture.
