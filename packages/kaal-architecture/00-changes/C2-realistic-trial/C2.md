# architecture/C2 realistic-trial

Records a trial of the Skill on five realistic requests of this project, with and without the Skill, as evidence for the independent Review and the Owner. It decides nothing about the Skill. A first slice: no gate, no deployment, no publication.

## Baseline

`kaal/architecture/classify` holds the Skill, the key and the runs 1 to 4, whose scenarios are remote from this project's decisions (the CPO finding on #1585). This Change cites nothing that is not there or on `main`.

## Gaps

| Gap | Target | Gap |
| --- | --- | --- |
| architecture/G3 | F5, recorded trial | no comparison of an agent with the Skill and one without it on realistic requests of this project is recorded |

## PLAN

Adds F5, the five requests (two also speak of the architecture description itself) (`requests.json`, frozen by its hash before any run), the Cases T10 and T11, and `evidence.md`. No trial.

## What this Change does not do

It has no answer key. The outputs are free lists, and nobody scores them against an expected classification. The Cases verify the evidence: the requests, the same questions in both arms, provenance, the shipped Skill, raw outputs unedited. Whether the Skill helps, and whether any classification is right, is left to the independent Review and the Owner.
