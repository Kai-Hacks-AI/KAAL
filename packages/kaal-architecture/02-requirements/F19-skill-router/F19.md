# architecture/F19 skill-router

`SKILL.md` is a router: it says in a line each what Architecture describes (the target state of a plateau) and the test that tells Solution from Delivery, and it names every reference it points to by its relative path. This Change targets a body of at most 200 words, the frontmatter not counted, so that the router stays below the first warning level of Core's Skill standard. The target is this Change's, not a second standard: Core owns the levels, the count and the common layout, and where its check exists it decides and this requirement follows it. Architecture sets no limit of its own on lines.
