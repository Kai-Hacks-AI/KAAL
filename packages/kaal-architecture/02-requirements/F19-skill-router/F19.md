# architecture/F19 skill-router

`SKILL.md` is a router. Its body, the text after the frontmatter, has at most 200 words and at most 120 lines, so that it stays below the first warning level of the Skill standard. It says in one line each what Architecture describes (the target state of a plateau) and the test that tells Solution from Delivery, and it names every reference it points to by its relative path. The frontmatter is not counted. Where Core's check exists, its count decides, and this requirement follows it.
