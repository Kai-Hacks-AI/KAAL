# architecture/F19 unestablished-origin-is-unknown

When the origin of a Defect is not established, Architecture does not guess a destination. A placement with `origin: unknown` names no `fixOwner`; it reports UNKNOWN, unresolved evidence, and the Defect stays where it was found. A placement with `origin: unknown` that names a `fixOwner` is INVALID, because it is a guess. UNKNOWN is a result, not an error.
