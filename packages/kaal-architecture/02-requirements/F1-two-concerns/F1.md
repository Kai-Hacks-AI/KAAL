# architecture/F1 two-concerns

Architecture has two distinct concerns.

- **Solution:** what the intended solution is and must do.
- **Delivery:** how that solution is realized, operated or made available.

A statement is Solution if it would still hold when the means that realize, operate or provide the solution were replaced by others. It is Delivery if it names those means or how they are used.
