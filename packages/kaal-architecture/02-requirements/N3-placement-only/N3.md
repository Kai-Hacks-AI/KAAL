# architecture/N3 placement-only

Architecture places a correction and nothing before or after it. It does not accept a finding, prove it (Testing does), or judge whether the problem is valid and where it was born (Review does). It records no Born and no Fixed. It does not register, rate, fix, close or change the status of a Defect, and does no fixing, execution, CI or workflow orchestration. It reuses the existing `addresses` model: no special placement field, no new library, no Control, no gate and no dependency.
