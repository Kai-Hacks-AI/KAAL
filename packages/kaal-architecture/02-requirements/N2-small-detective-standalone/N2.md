# architecture/N2 small-detective-standalone

The first version of the record mechanics is detective only: no gate, no preventive control, no workflow, no hook. It depends on Hosting for files and on Foundation for shared semantics and on nothing else, so installing the package is enough. It does not restate what Requirements, Testing or Graph own, and it registers no Control: that is a later, separate decision once the check has been observed.
