# architecture/F14 record-form

An Architecture record is one Markdown file `A<n>.md` in a folder `03-architecture/A<n>-<slug>/`, with frontmatter `id: <capability>/A<n>`, `title` and `addresses`, a nonempty list of Requirement ids. The id's number equals the file's and the folder's. Architecture reads this form; it does not read what the prose places where.
