# architecture/F15 addresses-a-requirement

Every Architecture record addresses at least one Requirement (an F or an N), and every id it lists resolves to a Requirement record in the same repository. Architecture reports each record that addresses nothing, and each listed id that resolves to no Requirement, by the record's id. The check is detective: it reports and does not block. It judges form, not whether a placement is a good one; whether a Requirement is met by the placement is Testing's conformance loop and Review's judgement, not repeated here.
