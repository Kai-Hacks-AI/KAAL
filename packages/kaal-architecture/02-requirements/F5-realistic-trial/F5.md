# architecture/F5 realistic-trial

The Skill is tried on five realistic requests of this project, on agent hosting, Review installation, Pull Promotion, incident reporting and Testing and Review integration, at least two of which deliberately mix an architecture concern with an instruction to move from one state to another. An agent with the Skill and an independent agent without it are asked the same questions: which parts are Solution, which are Delivery, which are mixed, which decisions are unresolved, and which work belongs to Change. The architecture boundary is stated to both arms in the same words. Raw outputs and provenance are preserved. There is no answer key, and the author does not change the requests after the run. Evidence integrity and observable behavior are verified by Cases; fitness for purpose and the comparison are left to independent Review.
