# architecture/F13 enduring-target

The Target of the Skill holds only enduring Requirements and Cases. Trial scenarios, keys, runs, experimental Cases, findings and retrospectives live under the Change that owns the trial, and learning from a trial flows to the Target through a Change that amends its Requirements and Cases. Every active Target Case is green, none reads a trial record or the key, and none depends on a file under `00-changes`. A trial result that was red stays on record as history, unrewritten. No identifier in the package is one that the parked Architecture package defined and other capabilities cite.
