# architecture/F20 skill-references

The detail of the Skill is in `references/`, one Markdown file for each question the router names: the two concerns and the test, the statement that does not sort cleanly, what to report, and the scope and the rules. Every reference exists and is named by the router with its relative path. The Skill directory holds `SKILL.md` and `references/` and nothing else, which is the floor of the Skill standard.
