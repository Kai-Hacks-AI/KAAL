# architecture/F20 skill-references

The detail of the Skill is in `references/`, one Markdown file for each question the router names: the two concerns and the test, the statement that does not sort cleanly, what to report, and the scope and the rules. Every reference exists and is named by the router with its relative path. The layout of the Skill directory beyond that, which top-level folders are permitted and how they are navigated, is Core's standard (core/C52): this requirement neither adds to it nor forbids what it permits.
