# architecture/F17 addresses-a-defect

An Architecture record may address an accepted Defect, `<capability>/D<n>`, exactly as it addresses a functional or non-functional Requirement: in `addresses`, with the same form (architecture/F14) and the same verdicts inside the observation boundary (architecture/F15). A Defect id whose namespace is observed and holds no such Defect is INVALID; one whose namespace is not observed is UNKNOWN and is never reported as invalid. A finding is not a Defect and is not addressable: only an id that names a Defect record can be addressed. There is no other placement contract: no new field, no new record kind.
