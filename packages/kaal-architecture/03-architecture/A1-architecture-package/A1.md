# architecture/A1 architecture-package

The package `packages/kaal-architecture/`, shaped like `packages/kaal-controls/`, owned by Architecture, with the Skill (architecture/A2) and a minimal shell. It is independent of the earlier URBAN package parked on `kaal/old/architecture`. The key of the first trials, ten statements from eight domains, belongs to the Change that ran them (`00-changes/C1-classification/trial/key/`), not to the package. It tests no classification of Changes.
