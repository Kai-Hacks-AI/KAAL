# architecture/A1 architecture-package

The package `packages/kaal-architecture/`, shaped like `packages/kaal-controls/`, owned by Architecture and independent of the earlier URBAN package parked on `kaal/old/architecture`. It holds the Skill (architecture/A2), `scenarios.json` and a minimal shell. The key is ten statements without a platform: where each is written, the concern and semantics of each part, and its finding (none, mixed, misplaced, weakens-solution, ambiguous or dependency). It is written before the Skill, so that the Skill cannot be tuned to it.
