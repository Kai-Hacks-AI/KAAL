# architecture/A1 architecture-package

The package `packages/kaal-architecture/`, shaped like `packages/kaal-controls/`, owned by Architecture, with the Skill (architecture/A2), `scenarios.json` and a minimal shell. It is independent of the earlier URBAN package parked on `kaal/old/architecture`. The key is ten statements from eight domains: where each is written, whether each part is Solution or Delivery, and its finding (none, mixed or ambiguous). It is written before the Skill, so that the Skill cannot be tuned to it. It tests no classification of Changes.
