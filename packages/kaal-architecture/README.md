# kaal-architecture

KAAL Architecture: telling Solution, what an intended solution is and must do, from Delivery, how it is realized, operated or made available, in statements about the target state of a plateau. This first slice is an Agent Skill and the scenarios and trial that show an agent using it. It is not published, not deployed where agents discover skills, and not part of the workspaces.

```
skills/kaal-architecture/SKILL.md   the Agent Skill
00-changes/ 01-intent/ 02-requirements/ 03-architecture/   the Change that introduces it, traced Intent to Cases
```

Identifiers of this package (`architecture/F13`, `T14` to `T22` and so on) are new. The parked package's identifiers are not carried over, and a citation of `architecture/T2`, `T3`, `F5` or `C7` elsewhere is a citation of that parked package.

The Target holds the enduring Requirements and Cases. Trials, their key, experimental Cases, findings and retrospectives are kept under the Change that ran them in `00-changes/`.

The earlier package of this name, the Skill for URBAN, is parked on `kaal/old/architecture`.
