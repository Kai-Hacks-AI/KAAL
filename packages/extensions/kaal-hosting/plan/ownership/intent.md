# Ownership Claim: Intent

This is `hosting/C24`, a PLAN. It plans the ownership claim for Hosting's location, which engineering/C11 names as its prerequisite P3 (`engineering/change-isolation/traceability.md`, "Prerequisites, each its owner's"). It ships no product code. It authorizes no DO, sync, promotion or publication. Hosting 0.0.1 does not wait for it.

Today every other Capability, Skill and Extension that Testing's attribution reads claims its own tree in an `ownership.kaal.json`. Hosting has none, so Hosting's files are unassigned: Change Isolation cannot tell which owner a Hosting path belongs to, and coverage cannot attribute Hosting's lines.

- **hosting/I13.** Every file in Hosting's tree, `packages/extensions/kaal-hosting/`, is attributed to Hosting, and only to Hosting, by a claim that Hosting itself holds in that tree. The claim names Hosting by its own Extension Node, so it resolves only while it names the Node Hosting actually carries. It is a mechanically maintained record of ownership decided elsewhere, in the format #609 settled, and never itself the place ownership is negotiated.
