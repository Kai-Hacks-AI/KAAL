# defect/F1 inventory

A recorded Defect is a record in the context where it was born, and that record is authoritative. The mechanic discovers the Defect records of the places the caller hands over and derives the inventory from them; it keeps and reads no second list of Defect ids, so membership is not a second source of truth or a second decision on what is recorded. A recorded Defect persists unresolved across Changes and releases until its derived state is `answered`. The caller hands over where the Defect records, the Architecture elements and the Test Cases are; the package knows no folder name or number.

A location the caller handed over is either discovered or unavailable. A folder that exists and holds no Defect is a verified empty inventory; a location that is missing, not a folder or unreadable is incomplete discovery, which is reported with the location named and is never read as empty. Incomplete discovery never silently omits an unresolved Defect: what was found is still reported, beside the unavailable location, and the run does not exit as a complete discovery. A scope the caller did not hand over (a place with no Cases location, say) is the caller's own and is not a failure. The caller owns the scope, and no list of ids or locations is kept by the package.
