# defect/F3 to-fix list

A Defect carries `found`, where it was found, and may carry `placed`, the functional placement that Architecture sets. The Defect stays at `found` until Architecture sets `placed`. The register can be listed grouped by `placed`, or by `found` while there is none, so each owner sees what it has to fix. Defect reads `placed` and never sets it.
