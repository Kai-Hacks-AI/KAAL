# defect/F3 defect is verified

A check reads Defects and Test Cases in a tree. A Defect that no Test Case names is reported `unproven`, and an id that does not fit `<capability>/D<n>` is reported `invalid`; either makes the check exit 1. The check reads the Test Case side only: a `tests` list on a Defect is not read.
