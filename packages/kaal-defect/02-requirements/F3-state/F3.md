# defect/F3 state

The state of a Defect is derived from the records of the Cases that point at it, at one revision, and never stored on the Defect. A record is `{case, run, revision, outcome}`, and outcome is `GREEN`, `RED` or `UNKNOWN` as a Case runner reports it. A record of another revision is stale and does not count. A missing record, or any outcome other than `GREEN` or `RED`, is `UNKNOWN`. A Case is `RED` if any applicable run is `RED`, `GREEN` if every applicable run is `GREEN`, otherwise `UNKNOWN`. A Defect is `confirmed` when some Case is `RED`, `answered` when it has Cases and every one is `GREEN`, and `unknown` otherwise, including when no Case points at it. `UNKNOWN` is never read as `RED` or `GREEN`. The state is evidence: whether it allows a merge is the consumer's policy.
