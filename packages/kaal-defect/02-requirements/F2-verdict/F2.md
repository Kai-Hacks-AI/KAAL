# defect/F2 verdict

Given the registers and run results as a list `{case, outcome}`, each Test Case gets a verdict that states what the evidence shows. Outcomes are `pass`, `fail` and `unknown`; any other value is read as `unknown`. A registered Case that fails is `known`. A registered Case that passes is `fixed`. A registered Case that is unknown, otherwise reported or missing is `unknown`, never a proven known failure. A failing Case that no register lists is `unregistered`. An entry with no Defect is `invalid`. A verdict is evidence and not permission to merge: the consumer or integration gate owns that policy.
