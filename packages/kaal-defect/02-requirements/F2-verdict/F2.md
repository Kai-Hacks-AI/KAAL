# defect/F2 verdict

Given the register and run results as a list `{case, outcome}`, each Test Case gets a verdict. A registered Case that fails is `known`. A registered Case that passes is `fixed`. An unregistered Case that fails is `blocking`. A registered Case with no result is `unknown`. Only `known` does not block.
