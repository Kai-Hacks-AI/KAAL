# defect/F1 register

A context keeps its own register, `known.json`, in its `defects` folder, beside its Defect records: a list of Defect ids. `known` is only membership of a register and a Defect record holds no state. An id with no Defect record in the same folder is `invalid`. There is no central register: the mechanic reads every register in a tree.
