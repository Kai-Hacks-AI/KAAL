# defect/F1 register

A context keeps its own register, beside its Defect records: a list of Defect ids. The caller hands over where the Defect records, the register and the Test Cases are; the package knows no folder name or number. `known` is only membership of a register and a Defect record holds no state. An id with no Defect record in the same folder is `invalid`. There is no central register: the mechanic reads every register in a tree.
