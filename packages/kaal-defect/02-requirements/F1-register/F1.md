# defect/F1 register

A context keeps its own register, `known.json`, in its `14-defects` folder, beside its Defect records. An entry is `{defect, case}`, where `case` is an opaque Test Case id. An entry whose Defect is not in the same folder is `invalid`. There is no central register: the mechanic reads every register in a tree.
