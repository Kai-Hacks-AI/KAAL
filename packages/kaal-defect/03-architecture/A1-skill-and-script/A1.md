# defect/A1 skill and script

`packages/kaal-defect/` holds `package.json` (name `@kaihacksai/kaal-defect`), one Skill `skills/kaal-defect/SKILL.md` that states the rules, and one script `skills/kaal-defect/scripts/known-defects.mjs` that reads every `14-defects/known.json` in a tree and gives the links and the placement. The package ships no register: every register and Defect is content of the context that holds it. Bare is a person or Agent working unguided; the Skill is the first step up and fixes what Bare gets wrong (a Defect treated as having a status, a list nobody owns, reproduction judged by the wrong capability); the script is the step above, for the judgement a reader should not repeat.
