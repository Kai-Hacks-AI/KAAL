# defect/A1 skill and script

`packages/kaal-defect/` holds `package.json` (name `@kaihacksai/kaal-defect`), one Skill `skills/kaal-defect/SKILL.md` that states the rules, and one script `skills/kaal-defect/scripts/known-defects.mjs` that reads the Defect records, the registers and the Case headers of a tree and judges them against the records it is given, in the way `kaal-controls` judges a status. The package ships no register: every register and Defect is content of the context that holds it. Bare is a person or Agent working unguided; the Skill is the first step up and fixes what Bare gets wrong (a Defect carrying a status that nothing derives, a list nobody owns, stale or unknown evidence read as current); the script is the step above, for the judgement a reader should not repeat.
