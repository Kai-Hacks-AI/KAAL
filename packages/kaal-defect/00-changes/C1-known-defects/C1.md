# defect/C1 known defects

A Defect that a Test Case proves is RED would block every merge. A register lists such Defects as known, so their Test Case is expected RED and does not block, while an unexpected GREEN fails, so a fixed Defect must leave the register. The register is the to-fix list per owner. kaal-defect owns the register form and the verdict; it takes the run results as a plain list and imports no Testing. No Defect is moved and nothing is wired to CI.
