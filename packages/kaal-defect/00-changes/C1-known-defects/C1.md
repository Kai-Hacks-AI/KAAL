# defect/C1 known defects

A Defect that a Test Case proves is RED would block every merge. Each context keeps a register of such Defects as known, beside its Defect records, so their Test Case is expected RED and does not block, while an unexpected GREEN fails, so a fixed Defect must leave the register. kaal-defect ships no register, only the mechanic that reads every register in a tree and gives the verdict; it takes the run results as a plain list and imports no Testing. No Defect is moved and nothing is wired to CI.
