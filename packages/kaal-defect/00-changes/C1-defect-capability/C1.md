# defect/C1 Defect has an owner

Adds a capability, kaal-defect, that owns the Defect: its definition, its identity and one detective check that a Defect is verified by a Test Case. A Defect is a negative Requirement that sits beside Intent. It is proven by a Test Case that verifies it, the same edge as Test Case verifies Requirement. No Defect is moved, no Hosting record is edited and no control is registered.
