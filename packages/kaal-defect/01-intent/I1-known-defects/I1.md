# defect/I1 defect inventory

A Defect is a passive description of an undesirable condition, usually in free text, and its state is derived from the Test Cases that point at it, as a Control's is. An accepted Defect is recorded in the context where it was born, and its record is authoritative: the inventory is discovered from those records, not kept in a second list. A Defect claims where its condition can manifest, and what no Case covers there stays unknown. The inventory of unresolved Defects is an input to planning, not an order to fix and not a release veto; what a Defect allows is for the gate that consumes the state to decide.
