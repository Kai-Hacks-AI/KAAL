# research/F1 rehearsal record

A rehearsal is one record with id `<capability>/RH<n>`, `kind: rehearsal`, a `question` and a `verdict` of `favourable`, `unfavourable` or `inconclusive`, and the sections `Design`, `Evidence`, `Runs`, `Claims` and `Limits`. The finder is handed `{ path, text }` files and returns `{ rehearsals, refused }`, each rehearsal with `id`, `verdict`, `question` and `path`; it searches no folder and exits 0, or 2 when anything is refused. A file that does not say it is a rehearsal is ignored; one that says so and has a bad id, a verdict outside the three or no question is refused.

**Done when** the finder lists a well-formed record, ignores a file that is no rehearsal, and refuses each of those four misfits.
