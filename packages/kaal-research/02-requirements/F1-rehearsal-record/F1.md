# research/F1 rehearsal record

A rehearsal is one record with id `<capability>/RH<n>`, `kind: rehearsal`, a `question`, a `verdict` of `favourable`, `unfavourable` or `inconclusive`, what the verdict is about and rests on (F4), and the sections `Design`, `Evidence`, `Runs`, `Claims` and `Limits`. It is plain text, `key: value` lines, written by the agent or person who ran the trial. Only the essentials are required; what is optional stays optional (F2, F3). The finder is handed `{ path, text }` files and returns `{ rehearsals, refused }`, each rehearsal with `id`, `verdict`, `about` and `question` and `path`; it searches no folder and exits 0, or 2 when anything is refused. A file that does not say it is a rehearsal is ignored; one that says so and has a bad id, a verdict outside the three or no question is refused.

**Done when** the finder lists a well-formed record, ignores a file that is no rehearsal, and refuses each of those four misfits; and a record authored for a real earlier trial, with only the essentials and honest limits (`example/RH1.md`, modelled on the exchange-by-description trial), is listed and `well-formed`. The example is the authoring check: whether an agent given the Skill writes such a record unaided is a rehearsal in the DO.
