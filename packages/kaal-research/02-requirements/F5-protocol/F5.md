# research/F5 protocol

A rehearsal record states how to run it again. Its `Design` names the `harness` the runs used (the tool or platform that started and observed the agents, in the author's words). It has a section `Protocol` with five lines: `materials`, the evidence paths needed to rerun, which include the path of the `prompt` and each of which is an evidence entry of the record; `run`, how each arm is run; `score`, how the answers are scored and by whom; `confirms`, what a rerun would show that supports the claims; and `refutes`, what it would show that goes against them. Each line is stated, not empty. The judgement checks that these are stated and that the materials are in the evidence. It does not check that the protocol can be followed or that it is sound, and its result still says form only.

**Done when** a record with a harness and a full protocol is `well-formed`, and each of these is `malformed` with its own rule: no `harness`, no `Protocol` section, an empty or missing `materials`, `run`, `score`, `confirms` or `refutes`, a materials path that is not an evidence entry, and materials that leave out the prompt.
