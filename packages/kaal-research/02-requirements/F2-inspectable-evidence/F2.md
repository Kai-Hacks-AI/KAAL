# research/F2 inspectable evidence

A record names its evidence by role, path and SHA-256. Essential: the `prompt` the agents were given, their `answers`, and the `scores` or judgement made of them. Optional and named when they exist: the `subject` the task ran on, the `key` and `rubric`, and an `excerpt` for a run that shows the treatment (an effect claim needs the key and the excerpts, F4). The judgement is handed the record's text and the `{ path, sha256 }` of the files the caller holds, and calls the record `well-formed` only if the three essentials are named, every named path is relative and stays inside the record's own folder (no absolute or temporary location, no `..`), and every named file is held and unchanged. The digest is the caller's; the judgement computes none. It says nothing about whether the answers support the scores.

**Done when** a record naming only the essentials is `well-formed`, and each of these is `malformed`: an essential not named, a path outside the folder, a file not held, a file whose digest differs.
