# research/F2 inspectable evidence

A record names its evidence by role, path and SHA-256: the prompt, the subject the task was given on, the key, the rubric, the answers and the scores, and an excerpt for each run that shows the treatment. The judgement is handed the record's text and the `{ path, sha256 }` of the files the caller holds, and calls the record `well-formed` only if every role is named, every path is relative and stays inside the record's own folder (no absolute or temporary location, no `..`), and every named file is held and unchanged. The digest is the caller's; the judgement computes none, so it needs no hashing of its own. It says nothing about whether the answers support the scores.

**Done when** a complete record is `well-formed` and each of these is `malformed`: a role not named, a path outside the folder, a file not held, a file whose digest differs.
