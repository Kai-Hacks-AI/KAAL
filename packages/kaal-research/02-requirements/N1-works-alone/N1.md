# research/N1 works alone

The finder and the judgement import nothing but Node built-ins and their own folder, know no repository path, phase, station or control, and run from a bare copy of the Skill's scripts outside any repository. Their command-line forms print JSON and exit 0 when all is well and 2 when something is refused or malformed.

**Done when** both run from such a copy on a record and print the result with the right exit codes.
