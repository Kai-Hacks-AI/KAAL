# research/A2 protocol-challenge-technique

The Skill `skills/kaal-research/` grows by three small things; no new script. `judge-rehearsal.mjs` checks the new form (`harness`, `Protocol`, `challenges` with `outcome` and `differs-in`, `technique`), and `find-rehearsals.mjs` lists `technique` and `challenges` beside each record. `SKILL.md` teaches an agent to write the protocol and to challenge a record, and points to `references/techniques/`, where each technique is one file named `<name>.md` with its version in its front matter (`technique`, `version`) and states what it is good for, what it cannot show, how to run it, how to score it and what a challenge must hold fixed. The first technique file is `judged-trial` at version 1, the method of RH1. Later techniques, such as automated parallel runs across several agent harnesses, are separate Changes: the folder is how the set grows. A change to a technique's steps raises its version and keeps the earlier file's text readable under its version (a section for each version, or the earlier file kept).

Whether the Skill teaches an agent to write a protocol someone else could follow is judged by a rehearsal in the DO, as in C1, and not by a Case. The existing example and RH1 gain a harness, a technique and a protocol in the DO, so they stay `well-formed`.
