## Claims
- id: c1
  claim: with the two Skills renamed (assay, vet), all three agents that had both Skills found the checking Skill by its description and derived the statuses
  scope: description
  rests-on: n1, n2, n3
  demonstrated: yes
- id: c2
  claim: having the checking Skill changed what agents did compared with Defect alone
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3, n1, n2, n3
  demonstrated: partly
  not-shown: defect-only gave 1 hit, 1 partial, 1 miss and both gave 2 hits, 1 miss, so the arms differ little at three runs; the misses happened before the exchange (the Defect Skill was never opened), the scoring was unblinded and done by the person who ran the trial
- id: c3
  claim: the wording of the description, not the names, is what made the match
  scope: effect
  rests-on: d1, d2, d3, n1, n2, n3
  demonstrated: no
  not-shown: no untreated arm for the description wording, no key frozen before the treatment, no blind scoring, no excerpts of what was opened (traces not kept), and the distractor Skill was opened in 0 of 9 runs so boundary precision is not tested; no confusable peer was tried beyond that one
## Limits
n-shows: three runs per arm show whether a difference is visible, never a rate
known-limits: session memory leaked KAAL rules into some answers; the distractor Skill (lint) was opened in 0 of 9 runs; Testing was a stub runner, not the real one; which runs opened which Skill was read from tool traces that were not kept; scoring by the person who ran the trial, nobody else saw the sessions; not tried: a blind scorer, more than 3 runs per group, the real runner
## Protocol
materials: evidence/prompt.txt, evidence/setup.md, evidence/answers.md, evidence/scores.md
run: in a sandbox project with a 3-Defect register (D1 failing Test Case, D2 passing, D3 none), deploy the Defect Skill with its references/exchanges.md (a seek, a fallback, and a pointer at the decision step) and, in the second and third arms, the Testing Skill plus a lint distractor Skill; in the third arm rename the Defect and Testing Skills to assay and vet. Start three fresh headless sessions per arm, give each the prompt, keep the answers and the tool traces
score: read each answer against the scores table (hit, partial, miss) and record which Skills it opened from the trace; the original scoring was by the person who ran the trial and arm was visible, a rerun should use a separate, blind scorer and keep what it saw
confirms: the same placements again, with the checking Skill found by description in all three neutral-name runs
refutes: agents in the neutral-name arm run the checks themselves or never reach the checking Skill, or the Skill is reached only when named
