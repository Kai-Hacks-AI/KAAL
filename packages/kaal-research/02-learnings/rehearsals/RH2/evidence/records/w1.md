## Claims
- id: c1
  claim: with neutral Skill names (assay and vet), all three sessions that had both Skills read the seek, found the Testing Skill by its description and derived the statuses, as written down
  scope: description
  rests-on: n1, n2, n3
  demonstrated: yes
- id: c2
  claim: having Testing deployed changed what agents did compared with Defect alone (1 hit, 1 partial, 1 miss against 2 hits and 1 miss)
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3
  demonstrated: partly
  not-shown: the difference is one hit between groups of three; all three misses happened before the exchange (the agent never loaded the Defect Skill), so they say nothing about the description; unblinded, scored by the runner, stub runner
- id: c3
  claim: the description, not the Skill names, is what made the match
  scope: effect
  rests-on: d1, d2, d3, n1, n2, n3
  demonstrated: no
  not-shown: no untreated arm for the description wording, no blind scoring, no key, exposure not shown by a kept excerpt, the distractor Skill (lint) was opened in 0 of 9 runs so boundary precision is not proven, and no peer with confusable vocabulary was tried
## Limits
n-shows: three runs per arm show whether a clear difference is visible, never a rate
not-tried: a blind scorer, more than 3 runs per group, the real runner
## Protocol
materials: evidence/prompt.txt, evidence/setup.md
run: for each group start three fresh headless sessions (model sonnet-5-5) in a sandbox project holding a 3-Defect register (D1 with a failing Test Case, D2 with a passing one, D3 with none); deploy the Defect Skill (with its references/exchanges.md stating a seek and a fallback, and a pointer at the decision step) in all groups; add the Testing Skill ("runs checks that point at an element") and a distractor lint Skill ("style and static-analysis rules over source text, does not run behavioural checks") in the groups Both and Both with neutral names, the latter with the two Skills renamed assay and vet; give each session the prompt and keep the answer and which Skills it opened
score: read each answer and the tool trace for which Skill was opened, and mark it hit, partial or miss as in evidence/answers.md; the original scorer was the person who ran the trial, unblinded; a rerun should have another session score under shuffled labels and keep the trace files, which the original did not
confirms: the Testing Skill is found by description when the names are neutral in all three sessions, and misses in the other groups come from not loading the Defect Skill
refutes: sessions with neutral names fail to find Testing or open the distractor instead, or the answers do not match the placements in evidence/scores.md
