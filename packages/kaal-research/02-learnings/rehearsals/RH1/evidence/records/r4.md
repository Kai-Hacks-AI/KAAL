## Claims
- id: c1
  claim: with neutral Skill names (assay, vet), all three agents that had both Skills found the Testing Skill by its description and derived the statuses
  scope: description
  rests-on: n1, n2, n3
  demonstrated: yes
- id: c2
  claim: having the Testing Skill changed what agents did compared with Defect alone
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3
  demonstrated: partly
  not-shown: the misses (d2, b1) happened before the exchange, because the agent never loaded the Defect Skill; the one partial (d1) read the fallback and still ran the checks; the run was unblinded and scored by the person who ran it
- id: c3
  claim: the boundary-precise wording of the description, not the names, is what made the match
  scope: effect
  rests-on: d1, d2, d3, n1, n2, n3
  demonstrated: no
  not-shown: the distractor Skill (lint) was opened in 0 of 9 runs, so boundary precision is not proven, only not contradicted; no untreated arm for the description wording; no peer with confusable vocabulary tried
## Limits
n-shows: three runs per arm show that a difference is visible or not, never a rate
other: Testing was a stub runner, not the real one; which runs opened which Skill was read from tool traces that were not kept, so exposure is recorded as delivered, not opened; scoring by the trial runner alone; no blind scorer, no more than 3 runs per group, real runner not tried
