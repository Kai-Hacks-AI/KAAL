model: sonnet-5-5
settings: headless sessions; no other settings recorded
blind: no

## Claims
- id: c1
  claim: with neutral Skill names (assay, vet), all three agents that had both Skills found the Testing Skill by its description and derived the statuses
  scope: description
  rests-on: n1, n2, n3
  demonstrated: partly
  not-shown: outcomes only as written down by the person who ran and scored the trial, unblinded; traces not kept; Testing was a stub runner; the distractor Skill was opened in 0 of 9 runs, so boundary precision is not proven; no confusable peer tried
- id: c2
  claim: having the Testing Skill changed what agents did compared with Defect alone
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3
  demonstrated: partly
  not-shown: two misses (d2, b1) never loaded the Defect Skill, so the exchange was not reached, and the partial (d1) read the fallback but ran the checks anyway; unblinded; memory leaked rules into some answers
## Limits
n-shows: three runs per arm show that a difference is visible or not, never a rate
not-tried: blind scorer, more than 3 runs per arm, the real runner
