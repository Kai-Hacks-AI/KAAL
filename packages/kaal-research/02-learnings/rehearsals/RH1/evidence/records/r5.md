## Claims
- id: c1
  claim: with the two Skills renamed (assay, vet), all three agents that had both Skills found the Testing Skill without it being named and derived the statuses (3 of 3 hits)
  scope: description
  rests-on: n1, n2, n3
  demonstrated: yes
- id: c2
  claim: having the Testing Skill changed what agents did compared with the Defect Skill alone (defect-only: 1 hit, 1 partial, 1 miss; both: 2 hits, 1 miss; neutral names: 3 hits)
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3, n1, n2, n3
  demonstrated: partly
  not-shown: the misses in d2 and b1 happened before the exchange (the Defect Skill was never opened), so they say nothing about Testing; the runs were scored by the person who ran them, unblinded; three runs per arm
- id: c3
  claim: the wording of the Testing Skill's description, not its name, is what made the match
  scope: effect
  rests-on: d1, d2, d3, n1, n2, n3
  demonstrated: no
  not-shown: no untreated arm for the description wording, no key frozen before the treatment, unblinded scoring, no run has an excerpt showing the Skill was opened, the distractor Skill was never opened so boundary precision is only not contradicted, and no confusable peer was tried
## Limits
n-shows: three runs per arm show that a difference is visible or not, never a rate
