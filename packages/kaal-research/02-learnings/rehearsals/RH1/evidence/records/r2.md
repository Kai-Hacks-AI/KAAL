## Claims
- id: c1
  claim: with the two Skills renamed to neutral names (assay, vet), all three agents read the seek, found the Testing Skill by its description and derived the statuses
  scope: description
  rests-on: n1, n2, n3
  demonstrated: yes
- id: c2
  claim: having the Testing Skill changed what agents did compared with the Defect Skill alone
  scope: comparison
  rests-on: d1, d2, d3, b1, b2, b3
  demonstrated: partly
  not-shown: the scores say the three non-hits share one cause before the exchange (d2 and b1 never loaded the Defect Skill; d1 read the fallback and still ran the checks), so the Testing Skill was not what differed; the runs were scored by the person who ran them, unblinded
- id: c3
  claim: the boundary-precise wording of the description, and not other features, made the match
  scope: effect
  rests-on: d1, d2, d3, n1, n2, n3
  demonstrated: no
  not-shown: no untreated arm for the wording, the distractor Skill (lint) was opened in 0 of 9 runs so boundary precision was never tested, no peer with confusable vocabulary was tried, no blind scoring, no key frozen before the runs
## Limits
n-shows: three runs per arm show that a difference is visible or not, never a rate
