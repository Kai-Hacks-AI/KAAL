# @kaihacksai/kaal-research

KAAL Research: a rehearsal is our own idea, run and observed, and recorded so that anyone can inspect what was done and what it does and does not show. This package holds, so far, only the PLAN of its first Change (`00-changes/C1-rehearsal-method`). No Skill, script or test is delivered yet; the draft scripts in that Change are for review only. It is not published and not part of the workspaces.

It will work with nothing else installed. A rehearsal lives in the consumer's `<capability>/02-learnings/rehearsals/`; what a consumer does with a found record is its own.
