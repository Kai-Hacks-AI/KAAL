# @kaihacksai/kaal-research

KAAL Research: a rehearsal is our own idea, run and observed, and recorded so that anyone can inspect what was done and what it does and does not show. Its Skill `skills/kaal-research/` is delivered by `00-changes/C1-rehearsal-method`. The Change `00-changes/C2-challenge-protocol` is, so far, only a PLAN (a protocol to rerun a record, challenges, and versioned techniques); its draft scripts are for review only. It is not published and not part of the workspaces.

It will work with nothing else installed. A rehearsal lives in the consumer's `<capability>/02-learnings/rehearsals/`; what a consumer does with a found record is its own.
