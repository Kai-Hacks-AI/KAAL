# hosting/C114 Hosting is the GitHub adapter of the KAAL Apps: manifest, token, reads and logo slot

Kai agreed on 26 November 2026 that Hosting owns the GitHub App adapter for all three KAAL Apps: the Dispatcher (Release's) and the Inspector and the Approver (Review's). That covers the App manifest, token minting, the API calls and the logo asset slot. The capabilities own the judgement and none of the GitHub. The Dispatcher may later dispatch other pull requests, and it raises them through Hosting's raise path (hosting/C113), so this Change is planned beside C113 and depends on it only for that path. This Change plans the adapter and the declaration the Apps' owners write. It starts no implementation, creates no App, installs nothing and moves no secret.

Provisional ids: C114, hosting/I22, F98 to F103, A43 to A45 and T318 to T326 and T329 to T331 were checked against `main` and every remote branch on 26 November 2026, with hosting/C113's provisional ids counted as taken (highest C113, I21, F97, A42, T317). They are confirmed again at the DO.
