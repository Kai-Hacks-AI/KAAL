# hosting/C117 Hosting posts a check run under an App's grant

The KAAL Inspector App exists (created and installed by the Owner on 27 November 2026) so that the controls' verdicts are signed as checks of an App whose installation has its own API budget, not the shared workflow token's. The Inspector's declaration lists the ability `post-checks`, which Hosting's C114 maps to the permission Checks: write, but C114 offers only reads and the raise: no call posts a check run. Controls' signing script would have to write the request, the headers and the verification itself. This Change plans the one call that is missing. It succeeds hosting/C114 (the grant, the App fixtures, `factOrigin`) and starts no implementation.

Provisional ids: C117, hosting/F112, A49, and T345 to T348 (serving hosting/I22). They are checked against `main` and every remote branch: the C114 collector holds F106, F107, A47 and T336 to T340; the C116 collector holds I24, F108 to F111, A48 and T341 to T344.
