# hosting/C169 postCheckRun states only what GitHub confirmed and takes no key outside the check

`postCheckRun` (hosting/C117) is on `main`. At its promotion review the CPO found two places where the implementation is looser than the C117 PLAN: the returned fact reports the caller's external id without checking the `external_id` GitHub returned, and a key outside the check is refused only when its value is not `undefined`. Nothing calls `postCheckRun` yet, so no verdict has been signed through either gap. This Change closes both, and starts no implementation.

Provisional ids: C169, T354 and T355, serving hosting/I22 and the elements hosting/F112 and A49 (reworded in the DO, no new element). They are checked against `main` and every remote branch: the C118 collector holds I25, F113, A50 and T349 to T353; the highest Change id on any branch is C168.
