# hosting/C110 Hosting reads the files of a revision

Reading the files of a Git revision, the base a judge reads from, is done today by seven separate pieces of code that share nothing (`baseline.md`). The Owner (19 Nov 2026) wants one place, so that no package builds its own setup, and chose Hosting. This Change is the first slice and takes one service only: `readRevision`, with the commit it resolves, as a library function and as a command in the Skill that share one implementation. Reading is the whole of it: nothing is written, fetched or checked out, and GitHub is not touched.

The slice is the library in `skills/kaal-hosting/scripts/` and the command beside it, the Skill and Agent text that point to them, and Test Cases hosting/T258 to hosting/T264. The first consumer, the collector check, moves in a following Engineering Change (`change.md`). Nothing is published and no pin moves.
