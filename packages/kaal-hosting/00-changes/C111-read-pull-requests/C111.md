# hosting/C111 Hosting reads the open pull requests of a repository, whichever transport the environment offers

The second Git or GitHub service to move into Hosting (the first was `readRevision`, hosting/C110). Show WIP (release/C99) needs the open pull requests of a repository with their reviews, review threads and checks. Today it starts `gh` itself and asks GitHub GraphQL, which a cloud session refuses, so an agent cannot run it. The Owner (19 November 2026): Show WIP asks Hosting for facts and knows no route; environment-specific routes live only inside Hosting; Hosting works through a Skill with corresponding Scripts; there is no single script with a switch, but one small Script per transport behind one shared fact shape and a thin selection step; the binaries may differ per environment.

This Change is the Hosting side only: the service, its transports and its Test Cases. The consumer (Show WIP) moves in release/C99, whose DO waits for this Change to be on `main`.

Provisional ids: C111, hosting/I19, F85 to F89, N13, A39 and T290 to T294 were checked against `main` on 19 November 2026 (highest C110, I18, F84, N12, A38, T279); they are confirmed again at the DO.
