# hosting/C113 Hosting renders the pull request templates and bodies from the types the capabilities declare

Kai ruled on 26 November 2026: Hosting is the clear owner of GitHub, so the pull request template generator belongs to Hosting. The chapters and content of each pull request type are owned by other capabilities (Change, Release and others). They declare them, and use Hosting to render them. No generator exists today: the templates under `.github/PULL_REQUEST_TEMPLATE/` are written by hand from Release's `05-src/wiring/templates` and installed by a WIRE. This Change plans the generator and the declaration interface the content owners use. It starts no implementation and installs nothing.

Asked by Engineering (engineering/C37, #2590) and Release (release/C138, #2586), whose DO is held on the declaration interface. Hosting agreed to the ownership on 26 November 2026.

Provisional ids: C113, hosting/I21, F93 to F97, A41 and A42, and T303 to T309 were checked against `main` and every remote branch on 26 November 2026 (highest C112, I20, F92, A40, N13, T302). They are confirmed again at the DO.
