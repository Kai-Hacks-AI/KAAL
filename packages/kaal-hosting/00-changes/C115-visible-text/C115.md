# hosting/C115 A declared pull request type can carry visible text

Kai ruled on 26 November 2026 (CTO call, via the coordinator) that kaal-change keeps the visible envelope line of HOTFIX, and that Hosting's declaration format gains a way to declare visible text. Today every text a declaration holds (`intro`, each `guidance`) is rendered by Hosting as a comment, so it is hidden from the reader of the rendered page. kaal-change's C14 (PLAN #2629) declares the four Change types and leaves the HOTFIX line out until this format exists; release's C138 DO waits on the same format. This Change plans the field. It starts no implementation and installs nothing.

Provisional ids: C115, hosting/I23, F104 and F105, A46, and T332 to T335. They are checked against `main` and every remote branch at the DO (highest on `main` today: C112 and the open C113 and C114 collectors).
