# review/I10 review-has-scope-and-reference

Review is broader than testing, and testing is more precise. A test verifies one exact subject; a review may examine an element, a file, a folder or a set of them, and judges what it examined against something: an Intent, a Requirement, an Architecture element, a Defect or any other reference. A reader can say, for every review item, what it examines and against what, and can ask the other way: which items examine this file, or this folder, and which judge against this Requirement.

**Done when** an item states what it examines, which may be a folder or a set, and optionally what it is judged against, and a reader, given a tree and a file, a folder or a reference, finds the items that examine it or judge against it.
