# review/F37 reference-of-an-item

What an item is judged against is its reference, written in the optional front matter field `against`: one or more ids of an element, an Intent, a Requirement, an Architecture element or a Defect for instance, or `path:` entries as in F36. An item without `against` is valid and has no reference; its Criteria stand alone. `navigate` lists the references of every item, and answers `judgedAgainst`, the items by reference, so that a reader can ask which items are judged against a Requirement. A reference entry that is empty or a malformed `path:` entry is a finding named `bad-against-reference`. A reference is not resolved and is not known to exist, as for a subject; Review keeps no list of kinds. An item that examines and is judged against the same single entry is listed without a finding.

**Done when** the references of an item are listed, the items are found by a reference, an item without a reference is valid, and each malformed reference is a named finding.
