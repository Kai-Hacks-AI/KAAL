# review/F26 validates-an-element

A review validates one element, of any kind, and says which. Its `subject.json` may carry the field `subject`: the id of the element, as the element states it, one non-empty id without spaces. The review record names that id, so the reviews of one element can be found by it. Review does not resolve the id, does not know the kind of element and does not check that the element exists. A review without a `subject` is still valid. A review of a focus Review does not define, a control for instance, is valid when its reference and actual are provided, and needs nothing more. The review fixes nothing, runs no test and decides nothing about the element it validates.
