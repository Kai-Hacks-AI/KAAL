# review/F20 focus

Every review states its focus, which fixes its reference and its actual. The focus promotion takes as reference what the promotion promised to change and as actual what changed. The focus capability takes as reference the Intent of the capability and as actual what it delivers. Any other focus is accepted only when its own reference and its actual are provided with it. The review reads the reference and the actual themselves, not their descriptions, at exact commits, and names each by what it read. The application lists them in its `subject.json`.
