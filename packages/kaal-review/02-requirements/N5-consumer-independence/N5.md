# review/N5 consumer-independence

Defining, performing and recording assessments, and navigating among them, work in any directory tree, with no Git repository, no station, no collector branch, no pull request host and no particular layout. The navigation reads the tree through Hosting alone and relies on no other KAAL package. A KAAL repository may supply its stations, branches and pull requests through an adapter, which reads the records and adds its own policy; the core holds none of them. The Skill states how to write and read items and results and names no KAAL station.

**Done when** the navigation runs over a bare temporary directory with no `.git`, and the delivered package declares only the permitted shared dependencies.
