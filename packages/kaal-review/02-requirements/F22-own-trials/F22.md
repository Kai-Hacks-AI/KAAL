# review/F22 own-trials

The review runs its own trial of the Skill and of a baseline without it. The reviewer writes its own statements, none taken from the author's key, and fixes its own key before any run; the key's hash is recorded with every run. Each arm has at least three runs, so that disagreement between runs is seen. The agent is asked for parts, finding and next move. Every run keeps its prompt, its raw output unedited and a record naming the observer, the agent, the model and the date. A difference from the reviewer's key is reported, never corrected.
