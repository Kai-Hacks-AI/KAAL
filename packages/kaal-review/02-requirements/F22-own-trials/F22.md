# review/F22 own-checks

Where the evidence of the delivery is an agent trial, the review runs a trial of its own: its own statements, none taken from the author's key (a snapshot of the author's statements is kept with the application), fixed in a key of its own before any run, and its hash recorded with every run. A trial that compares with a baseline has at least three runs per arm, so that disagreement between runs is seen. The agent is asked for everything the work says it reports. Every run keeps its prompt, its raw output unedited and a record naming the observer, the agent, the model and the date. A difference from the key is reported, never corrected. An application whose evidence is no trial says so in its `subject.json` and owes no trial.
