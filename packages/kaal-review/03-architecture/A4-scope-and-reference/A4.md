# review/A4 scope-and-reference

Both live in `skills/kaal-review/scripts/navigate.mjs` and in `references/review-items.md`; nothing else changes. `parse` reads `against` beside `validates` and judges the `path:` entries of both with one function that returns the finding or nothing. The completeness check keeps its finding `item-incomplete`; its detail says that an item needs a scope, a Question, Criteria and Expected evidence and names a missing reference in substance when it has neither `against` nor Criteria. An item gains `scope` (its `validates`, as read) and `against`. The answer gains `judgedAgainst`, a map from reference to the ids of the items, built as `validatedBy` is, with own-key objects. `about(answer, subject)` keeps its exact match for an element id and, for a `path:` subject, also returns the items whose scope is a folder that contains it; it reads text and never the disk. The command takes `--subject` as before and `--against <reference>` for the other side. The Skill stays free of KAAL: the words are those of the Skill reference, and no KAAL path or id is named in it.
