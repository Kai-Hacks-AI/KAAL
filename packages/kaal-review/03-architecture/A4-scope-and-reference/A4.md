# review/A4 scope-and-reference

Both live in `skills/kaal-review/scripts/navigate.mjs` and in `references/review-items.md`; nothing else changes. `parse` reads `against` beside `validates` and judges the `path:` entries of both with one function that returns the finding or nothing. The completeness check keeps its finding `item-incomplete` and now needs a scope, a reference, Criteria, a Question and Expected evidence; its detail names what is missing. A criterion equal to an entry of `against` or `validates` is the finding `criterion-restates-reference`. The reserved reference entry is `intrinsic`, and it is an ordinary key of `judgedAgainst`. An item gains `scope` (its `validates`, as read) and `against`. The answer gains `judgedAgainst`, a map from reference to the ids of the items, built as `validatedBy` is, with own-key objects. `about(answer, subject)` keeps its exact match for an element id and, for a `path:` subject, also returns the items whose scope is a folder that contains it; it reads text and never the disk. The command takes `--subject` as before and `--against <reference>` for the other side. The Skill stays free of KAAL: the words are those of the Skill reference, and no KAAL path or id is named in it.
