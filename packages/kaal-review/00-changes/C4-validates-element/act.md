# review/C4 ACT

A 4L retrospective of the Agent that carried the Change.

## Liked

A small request from another capability turned into one optional field, one confirmed rule and a real review of a real control. Review stayed target agnostic: the id is a string it does not resolve, and the field says nothing of the kind of element. Reusing the existing rule for a focus Review does not define meant no new rule was needed.

## Learned

A PLAN's RED Case that waits for a recorded application only proves the contract on that one application. The CPO's request to exercise malformed values was right: the contract is in the values it refuses, so T297 builds its own fresh applications and checks both directions. A Codex finding on the PLAN claimed a doubled backslash in a regular expression; the file held a single backslash, which I showed by running it, and I judged the finding invalid before acting on it.

## Lacked

A cheap way to run only the Cases a Change adds; I ran every test file and read a long output to find four failures. A way to read which control is in use by another capability's Case, so a review of a control does not need to read three folders to learn that.

## Longed for

A finder that lists the reviews of an element by its `subject`, owned by whoever consumes it. Review only makes the reviews findable; it does not find them.
