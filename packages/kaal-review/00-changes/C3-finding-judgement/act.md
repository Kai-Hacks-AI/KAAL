# review/C3 ACT

A 4L retrospective of the Agent that carried the Change.

## Liked

The CPO's split of the work made the Change small and clear: Review judges and says where the finding was found, and stops. The first real finding I judged was my own Codex finding on C4, and the process held: challenge it against the file, run what can be run, mark it, close it with a reason. Having the endings for invalid and unknown in the PLAN made the application easy to write.

## Learned

My first PLAN had Review say where a fix belongs, and the CPO's split removed it before any DO. The definition of Proven also tightened: a cited Case is not a reproduction. For an invalid finding there is no failure to reproduce, so the mark is Judged, with a Case cited as supporting evidence in the Comparison. A review of a finding is not worth much if it only repeats the thread reply, so the record keeps the challenge and the evidence apart from the closing reason.

## Lacked

A valid, deterministic finding to review. The only one at hand was invalid, so the handovers to prove, to record and to place are shown only as conditions, not as handed over. A way to quote code in a finding without its escapes being altered.

## Longed for

Whoever owns the end-to-end flow from a finding being raised to its defect resting where it belongs: still an Owner proposal. And a second application of a valid finding, once one arises.
