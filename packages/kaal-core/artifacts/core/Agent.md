# Agent

Agent is a dimension of CASE 6cffa01b750f77878b45ffc568824518711a1da10a579e8650b6847f357ebf60. It provides the instruction wiring that connects KAAL to agents: the means by which an agent, through the surface it already reads its instructions from, is pointed into KAAL.
