# Extension

A KAAL Extension is a Node through which a capability joins KAAL without becoming Core, as a KAAL Skill is, but as an Extension: the Extensions dimension of CASE 6cffa01b750f77878b45ffc568824518711a1da10a579e8650b6847f357ebf60 and the Skills dimension each provide their own registration, and the one does not stand in for the other.

A Node is a KAAL Extension exactly when its type refers, by name and ID, to this Node. KAAL's Extensions are therefore found by Node type alone, as KAAL Definitions and KAAL Skills are, and an Extension belongs to KAAL by being such a Node. This is the registration that the Extensions dimension of CASE provides.

This definition states what makes a Node an Extension and nothing of what an Extension does or of any host or environment it relates to: the Node carries what the capability means to KAAL, and its form beyond that is for the capability.
