# Canonical Skill Bytes: Requirements

Each Requirement names, in brackets, the Intents it serves. `core/C22` also amends `core/F7` (`plan/frontmatter/requirements.md`) and `core/F21` (`plan/installation/requirements.md`) in place.

## Nonfunctional

- **core/N13** [core/I14]: Core states no Skill format. It does not parse, check or rewrite a Skill's `SKILL.md`, and no Core rule names a frontmatter field or a body section of one. The canonical format of a Skill, a standard `SKILL.md`, is Engineer Skill's (`engineer-skill/C…`, numbered by Engineering), and so is checking a Skill against it. A `SKILL.md` is an Agent Skills standard artifact, not a KAAL Node, so `core/N1` does not apply to it.
