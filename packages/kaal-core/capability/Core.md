# Core

Core is the responsibility for the management capabilities that make a repository KAAL-managed: the recursive structure of Capabilities and their composition, installation contracts, and realization and lifecycle. It owns none of the domain semantics of Intent, Requirements, Architecture, Code, Testing or Operating; each discipline owns its own.
