# KAAL Request

KAAL Request is the capability by which a KAAL client deliberately addresses to KAAL an account of something it wants from KAAL that is not presently available or sufficient. The account is a carrier, kept locally with the embedded KAAL so that it remains available for later collection by KAAL. Its scope is the creation and local carriage of that carrier alone.

A carrier is addressed to KAAL by the fact that it was made with this capability. It is not the client's own request, and the capability neither replaces nor governs whatever the client keeps for its own requests, backlog, ideas, defects or incidents; the client remains responsible for telling what it keeps for itself from what it addresses to KAAL. A carrier has two parts, each a different kind of statement: what the client Wanted from KAAL, and what is Missing, that is, what KAAL does not provide, or provides insufficiently, for it.

KAAL Request is optional. It is not Core, a valid embedding does not need it, and embedding KAAL does not install it. It does not decide whether, how or when a carrier leaves the client, is collected, judged or answered: transport, submission and collection are other problems.
