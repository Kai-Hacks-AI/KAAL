# graph/C15 structure

Graph detects the cycles of a directed structure and walks it in both directions: `cycles`, `reach` and `reverse` over any string identities. This is the first small increment toward Graph 0.0.1 and is cut from `main`. It re-cuts the design of the stale `graph/C2` PLAN and `graph/C3` DO from the old `kaal/graph` collector, with the same Intent, Requirement and Case ids so they stay one artifact. It is a PLAN only: it ships no code.

## Baseline

`main` holds `kaal-graph` 0.0.1 with Form, identity, Edges, `Graph`, `traverse` and `check`. It has no `cycles`, `reach` or `reverse`. Nothing here depends on the Hosting rename, the release candidate (the held PROMOTION #621, C5, C6) or any other Change.

## Intent

- **graph/I1.** Graph detects and reports the cycles of a directed structure. It is deterministic, terminates on any structure and names each cycle's members. It judges nothing: whether a cycle is permitted is for whoever owns the meaning.
- **graph/I2.** These structural mechanics work on any identities a caller gives, names included. No new reference kind is needed, and a Node's `{ name, id }` references and Edges stay as they are.
- **graph/I3.** Nothing that exists changes: identify, Form, Edges, `Graph`, `traverse`, `check` and every Node id.

## Requirements

- **graph/F1** [I1, I2]: `cycles(successors)` reports every cycle as the strongly connected components that contain one. A component of two or more members is reported, and so is a single member with an edge to itself. Each cycle lists its members once, sorted; cycles are sorted by first member. Paths are never enumerated.
- **graph/F2** [I2]: `reach(successors, start)` yields `start` and every identity reachable from it, each once, breadth-first along sorted successors. It terminates on a cycle.
- **graph/F3** [I2]: `reverse(successors)` derives the sorted predecessors of every identity. Incoming relationships are computed, never stored.
- **graph/F4** [I2]: An identity is any string. `successors` maps each identity to the identities it points to, as a `Map` or a plain object. A successor that is not a key is an identity with no successors; resolving or refusing it is the caller's job.
- **graph/N1** [I1]: Determinism. The same structure gives the same result in any order of keys or successors.
- **graph/N2** [I1]: Termination and cost. Each function terminates on any structure, without recursion. Cost is O((V + E) log(V + E)) because of the sort for N1; the walk after it is O(V + E).
- **graph/N3** [I1, I3]: Purity. A call never changes its input, reads nothing from the host and returns frozen results.
- **graph/N4** [I3]: Additive. Every existing export and Node id is unchanged and Graph's existing tests stay GREEN.

## Architecture

- **graph/A1** [F1 to F4, N3]: a new module `skills/kaal-graph/scripts/structure.mjs` holds `cycles`, `reach` and `reverse` with their types. `edges.mjs` re-exports them beside `Graph`. The module imports nothing.
- **graph/A2** [F1, N1, N2]: `cycles` is Tarjan's strongly connected components, written iteratively with an explicit stack. Identities and successors are sorted by UTF-16 code unit order first. `reach` and `reverse` sort the same way.
- **graph/A3** [I2]: no name-only reference kind is added. Callers key `successors` by whatever name they have; resolving names stays theirs.
- **graph/A4** [N4]: `Graph#traverse`, `check` and the rest of `edges.mjs` are untouched. A `Graph#cycles` over Node Edges is not part of this Change.

## Testing

The Cases graph/T1 to graph/T7 are in this folder as `T<n>.red.mjs`, immutable to DO.

| Case | Checks |
| --- | --- |
| graph/T1 | F1, F4: no cycles in an acyclic structure; a self-edge is a cycle of one |
| graph/T2 | F1, I1: members sorted; disjoint cycles apart and in order; shared member is one component |
| graph/T3 | F2, F4: each identity once, `start` included, terminates on a cycle, reaches a non-key successor |
| graph/T4 | F3, F4: sorted predecessors, including for a non-key successor |
| graph/T5 | N1: same result in any key and successor order |
| graph/T6 | N2: a 100 000-member chain and ring finish without exhausting the stack |
| graph/T7 | N3, F4: input unchanged, results frozen, a plain object works like a `Map` |

Validated by review: A1 and A3 are placements; N4 is checked by Graph's existing tests staying GREEN; N2's cost bound is judged on A2's algorithm, since T6 proves termination at scale and does not measure complexity.
