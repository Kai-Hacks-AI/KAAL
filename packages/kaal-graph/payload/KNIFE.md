# KNIFE

- **K**: Kernel
- **N**: Node
- **I**: Identity
- **F**: Form
- **E**: Edge

KNIFE names KAAL's foundation, from the Kernel to the Edges between Nodes.

The Kernel is Core's: it is the bootstrap, not a Node, and Core owns it and the foundational constraints it sets. Node, Identity, Form and Edge are Graph's: reading a Node's Form and its identity from its exact bytes, and relating Nodes by Edges. A Node is rooted in the Kernel, which states what a Node is, and Core's genesis `Node` is the first one; that rooting does not make Node Core's.

An Edge is not a Node of its own. It is a relationship carried by its source Node, grouped by the Node that defines what the relationship means.

The order of the letters is a mnemonic, not a pipeline: nothing has to run in the order KNIFE names.
