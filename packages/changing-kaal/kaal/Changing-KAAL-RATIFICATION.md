# Changing KAAL

Changing KAAL is the capability for managing changes to KAAL through KAAL's change process. Its scope is that alone. It is not the changes themselves, and it is not the tools by which a change is carried out.

It uses RATIFICATION c589f60adf01f2c74de1f98dbaf090e52c32296819aaf0f41fa8a66abd3ff2fb as the architecture of its change process: the vocabulary by which it understands disciplined change. RATIFICATION is neither the change nor this Skill.
