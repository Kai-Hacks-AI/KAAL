# change/I26 change-folder

A Change gets from the current state to the target state, and its folder holds only what is about that move: its Gap, its baseline, its change-oriented Cases and its record. Everything outside the folder is about the target state, and each element the Change touches has its own target Case there. When the Change closes, its registration with Guard ends and nothing enduring ends with it: no Case that protected an element lived in the folder. Owner: Change.
