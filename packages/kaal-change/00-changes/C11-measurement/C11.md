# change/C11 measurement

A plan on **how to measure**, not a measurement. It fixes what KAAL records about Intent, Defect and Change, where, when and by whom, so that any metric can be derived later from records instead of being reconstructed from pull requests. No metric is chosen here. The pull request is a carrier and is not a unit.

## Baseline

`main` holds 27 Change folders, the ACT 4Ls, hosting Defect files (`packages/kaal-hosting/06-defects/D*.md`) and the CPO reviews on pull requests. None records when an Intent was stated or dropped, where a Defect was introduced or found, or how many rework loops a Change took. Today's only complete time series is pull requests, and it is flat: median open-to-merge is under one hour in every week of the repository (W41 to W45). A carrier-based metric cannot show improvement. The repository starts on 2026-10-12 and already uses KAAL, so no before-KAAL baseline exists inside it.
