# C10 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it.

## Liked

The trial being built to be wrong in public. The key was written before the guidance, the prompt hash and the observer were recorded, and differences from the key were reported instead of corrected. That made the S7 disagreement a finding and not an embarrassment, and it let the CPO ask sharp questions about the record instead of the claim. The CPO's two-concern ruling (Transition and Isolation) also fixed an architecture question that I had been circling with files and names.

## Learned

The branch is not the capability: I renamed a capability to match a branch and Kai had to correct it. A guide added to an existing Skill is a change to that Skill's shipped inventory, digests and Cases, so the first nested placement failed three separate checks before the right one passed. A widened description can break YAML validity with one colon, and only an acceptance Case caught it. The trial binds its prompt to the Skill as shipped, so every wording edit means a fresh run and a fresh observer. Eight runs on new prompts scored the same in both arms, which showed no regression and could not show a benefit; the honest reading of usefulness stayed "partly".

## Lacked

A way to run the package's own Workspaces and Acceptance tests in my container: the Hosting package is not built there, so the checks that failed in CI were the ones I could not run. A first statement of the shape of the whole Change (one Skill, two concerns, the worksheet belongs to Isolation) before the first PLAN, not after the second DO. An observer who is not a model of the same family.

## Longed For

A key and an observer that the Owner has read, so that S7 can be settled instead of stay disputed. A harder example with several runs per arm and a consuming agent that picks the Skill the way the host does. A shared place where a Skill's concerns and the reference each one owns are written down, so that a new reference is placed by the rule and not found by failing a check.
