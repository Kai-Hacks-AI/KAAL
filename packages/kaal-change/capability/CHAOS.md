# CHAOS

CHAOS, Changes Help Agents Organize Systematically, plays deliberately on Order versus Chaos: independent agents working in parallel become governable through bounded, identifiable Changes.

kaal-change defines the available ways to manage Changes; a repository embedding KAAL chooses how strictly it applies them. CHAOS adds no state, step or rule beyond the Change, Change Record and Change Lifecycle Definitions.

## Provenance

The Owner coined CHAOS in comments on KAAL #92 on 2026-10-16. Its first form, at 15:24 UTC, was "Changes Helping Agent Orders Systematically"; it took its current wording at 16:36 UTC. It was first realized in Communication, as an order for routing discussion. That meaning is now CCCC's, through KAAL #254, and this Definition deliberately does not carry it. The earlier bytes stay in the history of `kaal/communication`; this Definition is a correction, not a move, so its identity is new.
