# change/F55 retirement

A derived, detective control judges the deletion of a Change's `kaal-guard.json`. It applies only when a diff deletes one, and what it protects is the **continuity of effective verification** of the enduring objects the Change touched, not particular Test Cases. It judges at the head of the ACT, and it consumes the execution evidence the existing run already produced (Testing's evaluations, in the shape `assess` already reads: `run`, `plan`, `result`, `cases`, `findings`). It runs no test and keeps no second runner.

1. **Closure.** The folder holds `act.md`.
2. **History.** The records of the Change (every non-executable file of the folder: `act.md`, evidence, baseline, gap and the like) are kept. Executable files, the Cases and their helpers, are not frozen: a Case may be moved, split, consolidated, rewritten, replaced or removed, and its identity may change, because the obligation is verification, not a file.
3. **Continuity.** Every element folder (`01-intent` to `04-*`) the Change touched, between the state before the Change and the head, is verified at the head: at least one Case that claims it (`tests`, read at the head) passed in a counted evaluation of a check that is still registered at the head and is not being retired, **and no** Case that claims it has any other result in such an evaluation. One passing Case never covers another relevant Case's failure; mixed evidence is a finding that names the failing Case. A Case file or id that claims an element proves nothing without that execution evidence.
4. **Retiring checks.** Each check the deleted registration declares has an evaluation at the head, from the run that judged the head, and none of its Cases is anything but passed. A retiring check with no Case left is fine; one that is not evaluated, or that fails, is a finding. So the deletion cannot hide a failing Change check from the ACT's own final CI.
5. **Evidence.** Without counted evidence the control cannot judge: that is a finding, never a pass.

Producing the evaluations is the run's and Testing's. This control only reads them.
