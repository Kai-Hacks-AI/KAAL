# change/F54 folder-control

A derived, detective control judges the orientation of artifacts from the repository itself. The change kinds are C (Change) and G (Gap), the kinds of the Change lifecycle: the Change Record Definition owns that one closed set, and every other kind is a target kind by complement. A Defect (D) is an enduring domain object that may predate and outlive several Changes, so it is a target kind: a Defect's verification lives outside Change folders, beside the Defect. A Case inside a Change folder names only change kinds in its `tests`; a Case outside names no C or G. A document named `<KIND><n>[-slug].md` of a target kind never lies in a Change folder, and one of kind C or G never lies in an element folder (`01-intent` to `06-*`). No list of files, Cases or Changes is kept. It reads and judges; it writes and runs nothing, and wiring it into a gate is a second, preventive control.
