# change/F53 closure

A Change folder is closed when it holds `act.md`; open until then. The Change Record Definition states it. A closed folder that still holds its `kaal-guard.json` is a stale registration and a finding. Guard never reads closure: it runs what is registered. Registration is the one file `kaal-guard.json` in the folder, created at PLAN and deleted at ACT, and it lists no Case (one check whose command is a glob over the folder's `T*.test.mjs`).
