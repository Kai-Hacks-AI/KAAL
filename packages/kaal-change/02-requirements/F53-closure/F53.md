# change/F53 closure

A Change folder is closed when it holds `act.md`; open until then. The Change Record Definition states it. The state is derived from the two views of a pull request, never stored: `open` (no `act.md` at head), `closing` (`act.md` added at head: the ACT) and `closed` (`act.md` already at base). A closed Change is cold: its check prints "closed, nothing to run" and passes without running a Case.

The registration is the one file `kaal-guard.json` in the folder, created at PLAN and never deleted: ACT unwires nothing. It lists no Case: one passive check that runs the Change check on the folder (the runner is an argument). A registration whose check runs Cases directly would keep running them after the Change closes, and is a finding (`registration-not-passive`), which also catches a stale closed folder. Guard never reads closure: it runs what is registered and stays Change-agnostic.
