# change/F50 five-questions

Given a Change, an agent using the Skill answers: what is the current state; what is the intended outcome; what changes between them; which expectations are superseded and which protections remain valid; what evidence demonstrates a successful transition. It also asks whether one Change suffices or the transformation (A to D) needs a sequence of independently manageable Changes (A to B, B to C, C to D), each carried through its own PDCA. It names the boundaries between them, never their detailed plans, and does not decompose a transformation that one Change carries.
