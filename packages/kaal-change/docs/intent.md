# Intent

- **change/I19:** Bound and explain a proposed alteration across owner-defined
  Intent, functional/nonfunctional Requirements, relevant Defects, Architecture,
  interfaces, Cases and realizations.
- **change/I20:** Develop the real subject independently with incoming drivers
  and outgoing controlled collaborators, keeping compatibility/integration
  evidence separate from isolated test results.
- **change/I21:** Deliver a usable focused Change-isolation product without
  importing unrelated Change features or claiming repository completeness.

These concerns support iterative RED/GREEN/refactoring, not a waterfall.

- **change/I22:** Give an agent a small reusable Change practice anchor, combining
  useful manual isolation guidance with the delivered deterministic assessment,
  without requiring the broader Change lifecycle or an authoritative repository
  converter. A narrow 0.0.1 can state and verify that bounded promise.

- **change/I23:** Make the ordinary production package installation sufficient
  for its complete delivered verification, without hidden provider setup.
