# transition/A1 transition-package

The package `packages/kaal-transition/`, shaped like `packages/kaal-controls/`, owned by Change and independent of every other package. It holds the Skill (transition/A2), `scenarios.json` and a minimal shell. The key is nine statements about the example: the kinds of truth of each and its finding (none, mixed, historical-as-target, historical-as-evidence, retires-enduring or no-transition-evidence). It is written before the Skill.
