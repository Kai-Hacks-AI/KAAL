Account of: I am the controls thread. I wrote the PLAN, its revisions, the DO and this retro of C148 (recognizing an integration of the adapter) in my own collector. This is my account only: I have not asked the CPO or Release what they lacked.

## Liked
- subject: the review rounds that narrowed a claim before any code existed
  keeps: the CPO's first round turned "the entry runs through the adapter" into "the entry shows a recognizable integration", with execution and nonconformance kept apart, and F206 was amended so a recognition never overrides a confirmed `adapted: false`. The DO then had nothing to over-claim.

## Learned
- subject: reading names is not binding identity
  source: three review rounds on the same function. First a call of a name, then a name that is shadowed by a parameter, then a shadowing destructured parameter that the token heuristic missed. Each fix widened the list of declarations to look for. The sound answer was the reverse: support one narrow syntax (every occurrence of the name is a call) and refuse everything else as unknown.
- subject: a security scanner reads my code before the reviewer does
  source: building a regular expression from the imported name raised a high CodeQL alert (incomplete string escaping). Finding the call by position removed the alert and the need for escaping.

## Lacked
- subject: a lexical model of the entry before I wrote the first heuristic
  decision-point: writing the first version of the recognizer, where comments, strings, template literals, regex literals and declarations were handled one by one as they came up. The CPO's last note says the lexical boundary still needs a check for regex literals.
  cost: three review rounds and four commits.
  findable: yes
  address: Research

## Longed For
- subject: a small parser the package could rely on
  worked-anyway: the package carries no dependency, so the recognizer is a narrow syntax with refusal outside it, and a stronger reading, a run record of the entry, is left to the adapter's own evidence.

Decisions: none made, the owner decides.
