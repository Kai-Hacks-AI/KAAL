Account of: I am the controls thread. I wrote the PLAN, its amendment, the DO, a fix of it and this retro of C158 (the library knows the flag and judges the Running fact) in my own collector. This is my account only: I have not asked the CPO, Release or Testing what they lacked.

## Liked
- subject: three holds, each stated as a reproducible case
  keeps: the CPO's holds named an exact record (a run that found something while switched off, a flag with value `off` and state `on`) and the CTO named the exact patch that did not apply. Each came as a case to pin: I wrote the Case first, saw it RED, and then fixed the code.

## Learned
- subject: a rule that decides what counts must be written once and read the same by every consumer
  source: my PLAN counted only `PASS` and `FAIL` as execution evidence, and a run that reported findings (`REPORT`, from a detective run or a run switched off by its flag) was left out, as it had been for every detective control. The CPO's first hold found it on the judge. The fix was in the rule that `executed` and `judgeRunning` now share, and the PLAN was amended before the DO.
- subject: a judge must read a record as its writer could have written it, not as its fields say
  source: `judgeRunning` took `flag.state` at face value, so a record with value `off` and state `on` read as applied. The state is now read only when it follows the value and the name is text. Evidence that disagrees with itself is unknown, not on and not off.
- subject: a mutation patch is tied to the exact text it replaces
  source: after the flag fix changed a line in `judge-running.mjs`, the patch M9 no longer applied and my runner printed "did not apply" among thirteen results, which I did not read. The CTO found it. I regenerated the patches at the DO head and checked every block for RED by script, not by eye.

## Lacked
- subject: a mutation runner that fails when a patch does not apply or a mutation is not RED
  decision-point: running `mutations/run.sh` at the DO's head, which prints each result and leaves the reading to me, as in C155 and C157.
  cost: a mutation was claimed as caught that had not run. The third time the same gap showed.
  findable: yes
  address: Testing

  worked-anyway: the review found the missing verdict and the Case, run first, made the fix small.
