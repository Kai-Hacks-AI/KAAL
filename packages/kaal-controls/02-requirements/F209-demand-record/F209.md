# controls/F209 demand-record

1. `scripts/demand-record.mjs` exports `findRecordDue({controls, installed})`, pure.
2. For every control whose id is in `installed` and whose claim is `designed`, the finding is `record-due:<id>`. A claim of `implemented` or higher is not due. `installed` is what the adopter says is installed, because installing is a WIRE, which cannot write package files; the record is therefore due on the owning capability's next pull request into its collector.
3. The answer is a sorted list of unique names and is empty when nothing is found. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
4. It reads no file and writes nothing, and knows no repository, path, flag or service.
