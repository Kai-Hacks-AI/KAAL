# controls/F231 the lane judges observed RED

1. `test/lib/judge-lane.mjs` exports `judgeLane({ report, register, closed })`. `report` is a `kaal-testing/run-report@1`, `register` a `kaal-testing/expected-failures@1` and `closed` the list of Change ids whose ACT is recorded. It returns `{ ok, findings, held }` and is pure: it imports only `kaal-testing/expectations`, reads nothing and runs nothing.
2. It uses `compareExpectations` of testing and builds nothing of its own on top of the run report.
3. `held` lists the registered ids observed RED by an assertion. `ok` is true only when the run is complete, every registered id is held, no registered entry has a closed Change, and no other test is RED or UNKNOWN.
4. Findings are named `<kind>:<id>`: `green` (a registered Case passes), `error` (a registered Case ended before its assertion), `absent` (a registered Case was not run), `red` (an unregistered Case fails), `unknown` (an unregistered Case neither passed nor failed by assertion), `closed` (the entry's Change has its ACT) and `incomplete` (the run had execution problems).
5. A register entry without a `reference` naming a Change (`controls/C<n>`) is refused with a thrown error, so no exception is anonymous.
