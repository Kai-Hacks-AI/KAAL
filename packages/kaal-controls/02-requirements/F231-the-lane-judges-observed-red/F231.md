# controls/F231 the lane judges observed RED

1. `test/lib/judge-lane.mjs` exports `judgeLane({ report, register, changes })`. `report` is a `kaal-testing/run-report@1`, `register` a `kaal-testing/expected-failures@1` and `changes` the list `{ id, open, cases }` that `changesOf` (F233) gives. It returns `{ ok, findings, held }` and is pure: it imports only `kaal-testing/expectations`, reads nothing and runs nothing.
2. It uses `compareExpectations` of testing and builds nothing of its own on top of the run report.
3. `held` lists the registered ids observed RED by an assertion. `ok` is true only when the run is complete, every registered id is held, every registered entry names an open Change that exists and a Case that belongs to it, and no other test is RED or UNKNOWN.
4. Findings are named `<kind>:<id>`: `green` (a registered Case passes), `error` (a registered Case ended before its assertion), `absent` (a registered Case was not run), `red` (an unregistered Case fails), `unknown` (an unregistered Case neither passed nor failed by assertion), `nochange` (the entry's Change does not exist), `closed` (the entry's Change has its ACT), `foreign` (the Case does not belong to the entry's Change) and `incomplete` (the run had execution problems).
5. The Case of an entry is the last segment of its id, a path relative to the package, so a failing test that is not a Case of the open PLAN cannot be registered.
6. A register entry without a `reference` naming a Change (`controls/C<n>`) is refused with a thrown error, so no exception is anonymous.
