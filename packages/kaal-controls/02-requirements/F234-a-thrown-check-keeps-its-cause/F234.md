# controls/F234 a thrown check keeps its cause

1. When the check of `runControl` throws, the result carries `cause`. If the error has a `failure` whose `kind` is `rate-limited`, `forbidden`, `not-found`, `network` or `other` and whose `asked` and `place` are text, `cause` is its safe shape (F236): the allowlisted fields as given, and no other property.
2. A plain error gives `cause` `{ kind: 'check-error', message }` with the error's own message. A `failure` that is not in that shape gives `{ kind: 'check-error', message, malformed: true }`, and never a typed kind.
3. A check that answers has no `cause`. A `cause` never changes the verdict, which stays UNKNOWN, nor `blocked`, `mode`, `confirmed` or the record.
4. The log line of the result carries `cause` as its `kind`, `asked` and `place`, so the one line says why.
5. `runControl` never reads, calls or classifies a platform answer.
