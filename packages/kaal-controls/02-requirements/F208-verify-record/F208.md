# controls/F208 verify-record

1. `scripts/verify-record.mjs` exports `findDisagreeing({controls, records})`, pure.
2. For every control in `controls` (`{id, status, evidence}`), `deriveStatus` of the library (C141) gives a finding; it is listed as `record-lags:<id>` when the evidence shows more than the claim and `overclaims:<id>` when the claim shows more than the evidence. A claim of `implemented` is never listed. It is the one check of the answer "does the record agree with the evidence", flagging both directions, and it is the backstop on a promotion into main.
3. The answer is a sorted list of unique names and is empty when nothing is found. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
4. It reads no file and writes nothing, and knows no repository, path, flag or service.
