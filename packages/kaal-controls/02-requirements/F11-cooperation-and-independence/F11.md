# controls/F11 cooperation-and-independence

The four types cooperate: a directive states what is required, a detective control reveals when it is not met, a preventive control blocks the action it governs, a corrective control restores what was lost. They stay independent while they do:

- The presence of one is no evidence of another. A written rule is no check, a clean report is no block, and a block is no correction.
- A gate that requires a detective control's result combines the two. The detective control still only reveals; the gate prevents only the action it governs.
- Whatever combines controls is neither of them, and each is judged by its own type.
