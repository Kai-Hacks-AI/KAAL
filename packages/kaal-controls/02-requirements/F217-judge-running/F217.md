# controls/F217 judge-running

1. `scripts/judge-running.mjs` exports `judgeRunning({id, records, revision, established})`, pure: it reads no file and calls no service. Release, as the adopter, supplies the raw records and the runs it has independently established, as for `executed` (controls/F203).
2. A record counts only by the same rule as `executed`: valid (this control, `x` of `real`, a run, this revision, a verdict `PASS` or `FAIL`, by the adapter) and established by the adopter. The rule is written once and both functions use it. A record of another control or revision, of an unreal X, without a verdict, or not established is ignored, never counted against the control.
3. The answer is `{id, running, applied, modes, runs}`. `runs` is the number of records that count. `running` is `true` when at least one record counts, whatever its flag or mode, and `null` otherwise. It is never `false`: no record is not proof that a control did not run. Running is a fact about execution: a control that executed with its flag off ran. It carries no date.
4. The mode is told beside `running`, so that "running, off" never reads as applied. `modes` is the sorted list of the different modes of the counted records, each one of `off`, `detective`, `preventive` or `ratchet` (a record without one of these adds none). `applied` is `true` when a counted record shows the flag `on` and a mode of `detective`, `preventive` or `ratchet`, else `null` when a counted record has a flag state of `UNKNOWN`, a malformed flag or a flag that contradicts its own mode, else `false` when every counted record is `off`, and `null` when nothing counts. Unknown never stands for on.
5. Input that cannot be read as the lists and strings above throws, as `executed` does, and a verify Record fact built from this answer treats `null` as unknown (controls/F204). It never becomes a finding and never a pass.
6. It judges one Running fact per call. Which records exist, where they are kept and how a run is established are the adopter's. This adds no WIRE, flag, workflow or enforcement.
