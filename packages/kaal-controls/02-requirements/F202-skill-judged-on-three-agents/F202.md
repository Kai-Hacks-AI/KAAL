# controls/F202 skill-judged-on-three-agents

1. `00-changes/C140-skill-ratchet/trial/trial.md` is one portable trial: three prompts and one rubric, in plain text, with no tool, agent or setup named in a prompt and no word of KAAL. Anyone can run it on any agent that loads Skills.
2. Each agent is run with the Skill and without it (arms `skill` and `blank`), at least three runs of the prompt set per arm, on Claude, Codex and Antigravity. The Owner runs it with his own tooling.
3. Every run is scored on the rubric of the trial: whether `SKILL.md` was opened (R1) and, for each prompt it applies to, a score of 0 to 3 on contrast (R2), example (R3), baseline, history and end (R4), fail-closed unknown (R5) and clarity (R6).
4. The record is `trial/results.json`: the Skill revision, the judge, each run's agent, arm, prompt, `opened` and scores, and a `limits` sentence stating what the trial cannot show (blinding, run count, a judge from the same family).
5. The trial passes for an agent when its `skill` runs all opened `SKILL.md`, its mean on R2, R3, R4 and R5 is at least 2, its mean on R6 is 3, and on no criterion is its `skill` mean below its own `blank` mean. The Skill passes when it passes for all three agents.
6. A Case reads the record and says whether it is complete and whether each agent passes by item 5. It never decides whether the teaching works: the scores are the judge's.
7. The trial shows that the Skill works on these three agents. It does not claim an effect in general, and the `limits` sentence says so.
