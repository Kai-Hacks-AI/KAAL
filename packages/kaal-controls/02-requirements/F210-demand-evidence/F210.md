# controls/F210 demand-evidence

1. `scripts/demand-evidence.mjs` exports `findEvidenceDue({base, head, records})`, pure.
2. For every control whose `mode` in `head` is higher than in `base` (`off` below `detective` below `preventive`; a control absent from `base` was `off`), the finding is `evidence-due:<id>` unless the evidence is carried: for a raise to `detective`, a record of that control with a verdict other than `UNKNOWN` and a recorded `by`; for a raise to `preventive`, a derived status of `tested` (`deriveStatus`). A control whose mode did not rise is never asked.
3. The answer is a sorted list of unique names and is empty when nothing is found. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
4. It reads no file and writes nothing, and knows no repository, path, flag or service.
