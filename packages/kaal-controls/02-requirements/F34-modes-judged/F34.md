# controls/F34 modes-judged

1. A station mode is one of `detective`, `advisory`, `preventive` and `ratchet`. A control that has a ratchet at any station declares `exit`, one sentence on what it becomes when its baseline is empty; a control with a ratchet and no `exit` is listed with the problem `a ratchet has no exit`. A mode outside the four stays refused.
2. A script applies a mode to the answer of a check. A check's answer is a list of findings, each a name that stays the same from run to run, or no list when it could not judge. Detective reports the findings and blocks nothing. Advisory warns and blocks nothing. Preventive blocks when there is any finding. A check that could not judge is `UNKNOWN`, never a pass, and blocks in the blocking modes.
3. A ratchet blocks a finding that is not in its baseline and passes the findings that are, naming them as known. The baseline only shrinks: a baseline that holds a finding the previous baseline did not is a failure of the ratchet, reason `baseline-grew`. A finding that was resolved and removed from the baseline and appears again is new and blocks. A baseline finding that is no longer found is listed as resolved, for removal. When the baseline is empty the ratchet is spent: the script says so and that the next mode is preventive, and an empty baseline needs no baseline machinery.
4. The Skill says that the type of a control is its design and does not change with its mode, and that a claim follows the mode: only a preventive or ratchet mode may be said to prevent, a ratchet only what is new, a detective or advisory mode only reveals. It says what an exit is for and that a ratchet with none is not accepted, and gives the questions an agent asks of a check it finds. It names no flag, ruleset, pipeline step or repository. This is judged by an agent trial, not by a Case.
5. The package ships a short instructions file that says when to read the Skill and where it is, and repeats none of it. It is judged by an agent trial and by one Case on its structure.
