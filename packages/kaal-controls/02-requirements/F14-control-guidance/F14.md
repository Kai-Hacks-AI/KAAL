# controls/F14 control-guidance

The Agent Skill takes an agent through seven steps in order and each ends in something the agent writes down: 1 Intent, 2 Control type, 3 Requirements, 4 Architecture, 5 Cases, 6 RED, 7 DO and evidence. It is short: at most 900 words. Where a contract belongs to another capability it points to that contract by name and does not copy it.
