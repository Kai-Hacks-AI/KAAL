# controls/F38 ratchet-library

1. `scripts/ratchet.mjs` exports `judgeRun({findings, baseline, previous})`, pure: it reads no file and runs no command. For the same input it gives the verdict that `judge-mode` gives for mode `ratchet` (C21, C22), and `judge-mode` uses it.
2. A control with `strategy: ratchet` names in `baseline-source` the path of its baseline file, and the file is among the files the finder reads.
3. The baseline file is JSON: a list of strings, each once. A value that is not a path, a file that is absent, or a file that is not such a list lists the control with a problem naming `baseline-source` and a recovery.
4. The accepted baseline is read from the base, never from the pull request: the Skill says so, and the library takes only values.
