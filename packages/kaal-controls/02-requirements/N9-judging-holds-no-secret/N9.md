# controls/N9 judging-holds-no-secret

The workflow template and the App are shaped so that a candidate cannot reach the key. The judge job holds no secret and no write token, and checks out the base, not the candidate: the candidate's head is only an identifier handed over as data. The sign job needs the judge job, checks out nothing, runs no code of the candidate, and is the only job that reads the App's key. No step interpolates a title, a body or a branch name into a command. Every action is pinned to a full commit. The App asks for Checks: write and Pull requests: write, subscribes to no event and receives no webhook, and is not public. The package names no organization, repository or App.
