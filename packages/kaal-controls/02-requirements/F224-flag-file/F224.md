# controls/F224 flag-file

1. The flag file is `flags.json`, kept in the folder that holds the adopter's control records, and its text is `{ "schema": "kaal-controls/flags@1", "flags": [ { "control", "name", "value" } ] }`. `control` is the id of a control, `name` the name of its flag (non-empty text) and `value` text or `null` (read and not set). One entry for each control. The adopter reads the file and hands the text over; the library reads no file, environment or variable (controls/F216).
2. `scripts/flags.mjs` exports `parseFlags(text)` and `flagSource(entries)`, pure. `parseFlags` returns the entries sorted by control, or throws and returns nothing: text that is not JSON, another schema, a `flags` that is not a list, an entry that is not whole, a control twice. A partly read file is never used.
3. `flagSource(entries)` returns `{ of(control), controls() }`. `of(control)` is `{ name, value }` for an entry and `undefined` for a control with none, so that a missing flag is passed on as missing and is `UNKNOWN`, never off (controls/F216 item 1). `controls()` is the sorted list of the controls with an entry. The result of `of` is what the adopter passes as `boundary.flag`; the library adds no mode logic: `runControl` keeps deciding what a flag value means.
4. The source is a seam: anything with `of(control)` returning `{ name, value }` or `undefined` is a flag source, and `controls()` is optional. The file is the only source built. A source from Hosting is a later decision and no script of the library names one.
5. Ownership. The library (the package) owns the format, the reader and the report and ships no flag file and no adopter name. The adopter's controls instance owns the file and its values. In KAAL it is `engineering/14-operations/controls/flags.json`, beside the control records, and a flip is a pull request that changes that file, reviewed as a change. The library never writes it.
6. Which text is read is the adopter's: the check reads the file as it is at the base of the pull request, never the pull request's own copy, as for a baseline (controls/F211), so a pull request cannot switch off the control that judges it. The library cannot tell and says so; it does not read.
