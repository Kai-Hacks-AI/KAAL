# controls/F207 verify-delivery

1. `scripts/verify-delivery.mjs` exports `findUnrecorded({controls, delivered, revision})`, pure.
2. `delivered` is `{revision, entries}`: the entries observed in the actual delivery at that revision, never a list the adopter declares. When its `revision` is not the applicable `revision`, or it is missing, the check throws.
3. For every entry that is neither the id nor the path of a control in `controls`, the finding is `unrecorded:<entry>`.
4. The answer is a sorted list of unique names and is empty only when every observed entry is declared. An input that is not as described makes it throw, so that the adapter fails closed with `UNKNOWN`.
5. It reads no file and writes nothing, and knows no repository, path, flag or service.
