# controls/F207 verify-delivery

1. `scripts/verify-delivery.mjs` exports `findUnrecorded({controls, delivered})`, pure.
2. For every entry of `delivered` that is neither the id nor the path of a control in `controls`, the finding is `unrecorded:<entry>`. What is delivered is the adopter's declared set; the check reads no file.
3. The answer is a sorted list of unique names and is empty when nothing is found. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
4. It reads no file and writes nothing, and knows no repository, path, flag or service.
