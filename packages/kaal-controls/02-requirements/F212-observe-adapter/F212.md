# controls/F212 observe-adapter

1. `scripts/observe-adapter.mjs` exports `observeAdapted({control, entry, revision})`, pure, and returns an observation `{control, revision, adapted}` of the form that `findUnadapted` (controls/F206) reads. `entry` is `{path, text}`: the delivered entry of that control as the adopter read it at the revision.
2. Comments are not read. After removing line and block comments, `adapted` is `true` when the text imports `runControl` from a module whose specifier ends in `adapter.mjs` and calls `runControl(`; it is `false` when the text is non-empty and has neither the import nor a call of `runControl`.
3. Anything else is unknown and the function throws: no entry, an entry that is not text or is empty, an import without a call, a call without the import, or `control` or `revision` that is not a non-empty string. A declaration of the control is never read and cannot make the answer true.
4. It reads no file and writes nothing, and knows no repository, path, flag or service. Which file is the delivered entry of a control, and where the check runs, is the adopter's: release owns the delivery map, the station and the flag.
