# controls/F35 cli-says-unknown

1. The command of `scripts/judge-mode.mjs` gives its verdict as JSON and exits 0 when nothing is blocked, 1 when blocked and 2 when it could not judge.
2. A findings, baseline or previous file that is missing or cannot be read gives the verdict `UNKNOWN`, `blocked: true`, reason `unreadable-input`, as JSON, exit 2. It names the file.
3. A file that is not valid JSON gives `UNKNOWN`, `blocked: true`, reason `malformed-input`, as JSON, exit 2. It names the file.
4. Neither case prints a stack trace or exits 1.
