# controls/F211 ratchet-adoption

1. `scripts/ratchet.mjs` exports `judgeAdoption({base, head, change, window})`, pure, taking the same values as `judgeProgress`: `base` and `head` each `{baseline, history}`, `change` `{id, exists}` and `window` `{from, to}`.
2. It says `PASS` when the base's history is empty, the head's history is exactly one line `{at, change, from: null, to, removed: []}` with `to` the size of the head's baseline, `change` the id of the Change the pull request carries and `exists` true, and `at` inside the window.
3. It fails with a reason, each its own: `already-adopted` when the base's history is not empty; `line-mismatch` when the head's history is not exactly one line, or `from` is not `null`, or `to` is not the size of the head's baseline, or `removed` is not empty; `change-mismatch` and `change-unknown` as in `judgeProgress`; `time-out-of-window`; `baseline-grew` when the base already holds a baseline and the head's has a name it does not.
4. A baseline that is not a list of unique names, a missing `base`, `head`, `change` or `window`, or a time that cannot be read is `UNKNOWN`, never a pass.
5. It writes nothing, and `judgeProgress` and `judgeRetirement` behave as before.
