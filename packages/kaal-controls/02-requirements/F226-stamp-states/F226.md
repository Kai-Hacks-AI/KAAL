# controls/F226 stamp-states

1. Running of a control in a place has five states, STAMP: `STOPPED`, `TORN`, `ADVISORY`, `MUTE`, `PREVENTING`. D, I and T of DIRT do not change.
2. `scripts/stamp.mjs` exports `flagState(value)`, `toBoundary(name, value)` and `judgeStamp({ declared, runs })`, pure.
3. `flagState(value)` is the declared state the flag chooses: `PREVENTING` for `preventing` and for the legacy `on` (controls/F216), `ADVISORY` for `advisory` and for the legacy `off`, `STOPPED` for `stopped`, and `UNKNOWN` for anything else, including `null`, the empty text and a missing flag. A value that is not understood is never read as `STOPPED` or `ADVISORY`. The legacy `off` runs the control as a detective today, which is Advisory, so nothing changes for a run.
4. `toBoundary(name, value)` gives what the adopter hands to the adapter as `boundary.flag`: `{ name, value: 'on' }` for `PREVENTING`, `{ name, value: 'off' }` for `ADVISORY`, `{ name, value: null }` for `UNKNOWN` (read and not set, which the adapter runs switched off, controls/F216: it executes, judges as a detective, never blocks, and records `mode: off`, `applied: false`), and `null` for `STOPPED`, which means the adopter does not run the control. `name` must be non-empty text or `toBoundary` throws: a flag-aware caller always names its flag. An unknown flag therefore never authorizes enforcement, and the adapter is not changed. A caller that passes no `boundary.flag` at all is a legacy caller: the adapter still runs it as asked (controls/F216 item 3), it may block, and STAMP does not hide that (item 6).
5. `runs` is the list of the established runs of one control in one place, oldest first, each `{ run, verdict, mode, applied }`: `verdict` is `PASS`, `REPORT`, `FAIL` or `UNKNOWN` from the record, and `null` when the adopter established the run and has no record. The adopter supplies it, as it supplies the records of `judgeRunning`.
6. `judgeStamp({ declared, runs })` gives `{ stamp, blocking, reasons }`:
   - `declared` `STOPPED`: `stamp` `STOPPED`, `blocking` `false`.
   - `declared` `UNKNOWN`: `stamp` `MUTE`, `blocking` `null` without a run, reason `no-flag`.
   - `declared` `ADVISORY` or `PREVENTING` and no run: `MUTE`, `blocking` `null`, reason `no-trace`. Silence is never `ADVISORY`.
   - the latest run has a verdict `UNKNOWN` or none: `TORN`, reason `no-verdict`, and `blocking` `true` when `declared` is `PREVENTING`, else `false`.
   - otherwise `declared` `ADVISORY`: `ADVISORY`, `blocking` `false`. `declared` `PREVENTING`: `PREVENTING` and `blocking` `true` only when the latest run's `applied` is `true`; else `ADVISORY` observed, `blocking` `null` and reason `flag-not-applied`.
   - `declared` `PREVENTING` and no earlier run that was Advisory (a run with a verdict other than `UNKNOWN` and `applied` of `false`): reason `unproven-preventing`. The state is not changed by it. It is a finding, and a rule over the changes of the file is for the Owner to decide.
   - the reported `blocking` follows what the latest run actually did, so that the state never says less than the behavior: when the latest run has `applied` of `null` and a `mode` of `preventive` or `ratchet` (a legacy caller that passed no flag, which the adapter runs as asked), `blocking` is `true` whatever was declared except `STOPPED`, and the reason `blocks-without-flag` is added. A run of `mode` `off` and `applied` of `false` (an unknown or advisory flag passed to the adapter) never blocks, so `blocking` is `false` for it under `MUTE` and `ADVISORY`.
7. Anything that cannot be read as above (a `declared` that is not one of the five, `runs` that is not a list, a run that is not whole) throws, and a caller treats it as unknown. Nothing here blocks anything by itself: `blocking` is told to the adopter, whose gate acts on it, and `Torn` under `PREVENTING` blocks because a control that was meant to prevent and gave no verdict is not a pass.
8. Authorization. The first entries of an instance's flag file and each escalation of a control in a place (Advisory to Preventing) are separate Owner decisions. This Change defines the vocabulary and the report; it enables nothing.
