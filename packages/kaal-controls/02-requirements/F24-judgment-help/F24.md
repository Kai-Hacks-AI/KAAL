# controls/F24 judgment-help

Whether a claimed status is true cannot be decided by a script, so the Skill helps the one who judges it. `references/judging-status.md` has one part for each of `designed`, `implemented`, `running` and `tested`. Each part says what to look at, what evidence would support the claim, and what leaves the claim unresolved. The help asks for evidence the owner of the control can show, never accepts a declaration as its own proof, and names no status as the answer for a control. `SKILL.md` points at the reference within its word cap.

What a script can decide stays in the script (controls/F21). What it cannot, the Skill hands to an Agent or a person to judge.
