# controls/F233 the open PLAN and its Cases

1. `test/lib/changes-of.mjs` exports `changesOf(files)`, pure over `{ path, text }` entries (paths relative to the package). It returns the Changes as `{ id, open, cases }`, sorted by id.
2. A Case belongs to a Change by the chain already in the Records: the Case's `tests` names Requirements, a Requirement `serves` Intents, and a Change `implements` Intents. `cases` lists the Case paths so reached, relative to the package.
3. A Change is open until its folder holds `act.md`.
4. The lane judges that a register entry names an open Change that exists and a Case that belongs to it (F231); an entry for a nonexistent Change, a closed Change or an unrelated Case is a finding, so an unrelated failing Case cannot be registered against a PLAN.
