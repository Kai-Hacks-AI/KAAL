# controls/F36 ratchet-lifecycle

1. An accepted run (PASS) carries `next`, the baseline the adopter stores as the accepted baseline of the following run: the accepted baseline minus the findings no longer found. On a PASS the candidate's baseline equals `next`.
2. A rejected run (FAIL or UNKNOWN) carries no `next`: nothing is advanced by a run that did not pass.
3. Across accepted runs each accepted baseline is a subset of the one before it. After an improvement the allowance for a resolved finding is gone; a resolved finding that returns blocks, and its allowance put back is growth.
4. When the accepted baseline is empty the ratchet is spent and judges as preventive.
5. The lifecycle (adoption, accepted, rejected, improvement, rollback, end) and what only the adopter can guarantee are stated in `lifecycle.md` of the Change.
