# controls/F15 finder-lists

The finder lists every valid control as `id`, `title`, `description`, `has` and `path`, wherever it lies in the tree. For each control it also lists the Cases that point at it, found from the Case side (a Case header `// Case <id> tests: <ids>`). A control with no Case yet is still listed, with none. Refused items are reported with the reason.
