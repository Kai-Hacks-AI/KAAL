# controls/F218 base-contract

1. `scripts/lib/contract.mjs` is the base contract of both libraries. It imports nothing, reads nothing and knows no repository, tool or service.
2. It exports exactly `VERDICTS` (`PASS`, `REPORT`, `FAIL`, `UNKNOWN`), `isVerdict`, `isRevision` and `sameRevision`.
3. `isVerdict(v)` is true for an object whose `verdict` is one of `VERDICTS` and whose `blocked` is a boolean, and false for anything else.
4. A revision is a full commit id: 40 or 64 hexadecimal characters. `isRevision(x)` is true only for such a string, in either letter case. An abbreviation, a label, an empty string and a value that is not a string are not revisions. `sameRevision(a, b)` is true only when both are revisions and equal without regard to letter case.
5. This is where the judged revision of Testing's evidence contract (testing/C84, planned) lands for Controls: what a record names is a revision in this sense. This Change only places the rule. Tightening `executed`, `findEvidenceDue` and `runAdapterRatchet` to demand it is a later Change, after testing/C84 and hosting/C118 are on main, because existing Cases pass labels as revisions.
