# controls/F218 base-contract

1. `scripts/lib/contract.mjs` is the base contract of both libraries. It imports nothing, reads nothing and knows no repository, tool or service.
2. It exports exactly `VERDICTS` (`PASS`, `REPORT`, `FAIL`, `UNKNOWN`), `isVerdict`, `isIdentity` and `sameIdentity`.
3. `isVerdict(v)` is true for an object whose `verdict` is one of `VERDICTS` and whose `blocked` is a boolean, and false for anything else.
4. An identity is the opaque identity of the content examined (testing/C84, hosting/C118): a string with at least one character that is not whitespace, and nothing more. No format is assumed, no source is named, and no case is folded. `isIdentity(x)` is true only for such a string; an empty or blank string and a value that is not a string are not identities. `sameIdentity(a, b)` is true only when both are identities and the strings are equal.
5. This is where the content identity of Testing's evidence contract (testing/C84, approved) lands for Controls, as the same rule and no more: how content is identified and where the identity comes from is Hosting's (hosting/C118 contentIdentity, Git only as provenance). This Change only places the rule. Tightening `executed`, `findEvidenceDue` and `runAdapterRatchet` to demand it is a later Change, after hosting/C118 is on main, because existing Cases pass labels as identities.
