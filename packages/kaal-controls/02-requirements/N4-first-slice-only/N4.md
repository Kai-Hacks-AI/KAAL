# controls/N4 first-slice-only

The first delivery is the semantics of the four types and nothing around them. The Skill prescribes no technical realization, no naming verbs, no verdict contract, no lifecycle placement and no step-by-step procedure for designing a control, and it makes the traceability process of a Change no part of itself. It is authored in the package `kaal-controls` and is not deployed to any place where agents discover skills. No Capability Node or Control Definition exists for it.
