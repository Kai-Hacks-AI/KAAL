# controls/F13 control-shape

A control is a Markdown file whose frontmatter has exactly `id`, `title`, `description`, `type` and `has`. The `type` is decided by controls/F16.

- `id` is `<capability>/CTL<n>`.
- `title` and `description` are text. The description is one short sentence.
- `has` lists one or more Intent ids.
- A control stores no state, and no pointer to its test. A control test is a Case whose `tests` names the control.

An item that misses a field, has an empty `has`, or carries `state` or `tests` is refused whole.
