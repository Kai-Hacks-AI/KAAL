# controls/F206 verify-adapter

1. `scripts/verify-adapter.mjs` exports `findUnadapted({controls, delivered, adapted})`, pure.
2. For every control that declares a station, or whose id is in `delivered`, and whose id is not in `adapted`, the finding is `unadapted:<id>`. `adapted` is the list the adopter passes in, for instance from the workflows that call the adapter; the check reads no workflow.
3. The answer is a sorted list of unique names and is empty when nothing is found. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
4. It reads no file and writes nothing, and knows no repository, path, flag or service.
