# controls/F206 verify-adapter

1. `scripts/verify-adapter.mjs` exports `findUnadapted({controls, delivered, observed, revision})`, pure.
2. `observed` is the list of observations `{control, revision, adapted}` that the adopter made of the actual implementation or delivery: whether the delivered entry of that control runs through the adapter, `true` or `false`. It is established independently of the control's declaration. An observation counts only for its own control and the applicable `revision`.
3. For every control that declares a station, or whose id is in `delivered`: an observation `adapted: false` gives `unadapted:<id>`; no observation for this control and revision gives `unobserved:<id>`, never a clean result; `adapted: true` gives nothing. What the declaration says about itself is never read as proof, and a list the adopter merely supplies is not an observation.
4. The answer is a sorted list of unique names and is empty only when every control with a station, or delivered, is observed to run through the adapter. An input that is not a list makes it throw, so that the adapter fails closed with `UNKNOWN`.
5. It reads no file and writes nothing, and knows no repository, path, flag or service.
