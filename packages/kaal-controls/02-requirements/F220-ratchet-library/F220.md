# controls/F220 ratchet-library

1. The ratchet library is `scripts/lib/ratchet/`: `run.mjs` (`judgeRun`, `applyBaseline`), `step.mjs` (`judgeProgress`, `judgeAdoption`, `judgeRetirement`, `judgeRatchetStep`) and `strategy.mjs`. The code is the code of `ratchet.mjs` and `judge-ratchet.mjs`, moved, and no rule changes.
2. `strategy.mjs` exports `ratchetStrategy`: `{ name: 'ratchet', judge({ findings, baseline, previous }) }`, which returns what `judgeRun` returns for the same input.
3. The ratchet library imports only its own files and `../contract.mjs`. It does not import the controls library.
4. The controls library does not import the ratchet library: no file in `scripts/lib/` outside `lib/ratchet/` has an import specifier naming `ratchet`. A specific ratchet (such as `adapter-ratchet.mjs`) and the composition root (`adapter.mjs`, the command at `judge-mode.mjs`) may import it.
5. The dependency runs one way: both libraries stand on `lib/contract.mjs`; the ratchet strategy fills the controls library's slot; neither imports the other.
