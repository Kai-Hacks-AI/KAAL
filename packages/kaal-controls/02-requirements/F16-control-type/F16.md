# controls/F16 control-type

A control declares `type` in its frontmatter. It is mandatory and holds exactly one of `directive`, `preventive`, `detective` or `corrective`, spelled in lower case.

An item with no `type`, an empty `type`, or a `type` outside the four stays listed, fails validation, and the problem names `type` (controls/F20, which replaces the refusal of controls/C9). The finder lists the type of every control it finds. Which type a control has is judged by what it does when the rule is broken (controls/F10), not by this requirement.
