# controls/F235 one line guides to the cause

1. `scripts/lib/guide-cause.mjs` exports `guideCause(cause)`, pure: it imports nothing, reads nothing and names no station, platform or KAAL term. It returns one line of text, or `null` for no cause.
2. By kind: `rate-limited` names the bucket and the reset time (or the seconds to retry); `forbidden` names what was asked, the place and the status; `not-found` names what was asked and the place; `network` names the place; `other` and `check-error` show the platform's or the check's own message; each also names what was asked where the cause has it.
3. A platform message is quoted verbatim and never rewritten or summarized.
4. Guidance is built from the safe cause (F236).
5. `runControl` returns `guidance` equal to `guideCause(cause)` whenever it returns a `cause`.
