# controls/F14 unique-ids

A control id is unique in the repository searched. When two items carry the same id, both stay listed, fail validation and the finder reports the duplicate (controls/F20, which replaces the refusal of controls/C8). A Change id such as `controls/C8` is never read as a control: `CTL` is matched as a whole.
