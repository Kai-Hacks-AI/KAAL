# controls/F221 shims-for-callers

1. `scripts/ratchet.mjs`, `scripts/judge-ratchet.mjs` and `scripts/judge-mode.mjs` stay at their paths as deprecated shims (controls/N8, shim rule): not published (`!` entries in `package.json` `files`), each marked `DEPRECATED shim`, kept until the callers move.
2. A caller that fetches only `judge-mode.mjs` and `ratchet.mjs` from another revision (release/T1431 does) must keep working. So these two shims are self-contained as a pair: `ratchet.mjs` imports nothing, and `judge-mode.mjs` imports only `./ratchet.mjs` and Node's own modules. The pair holds the same code as the library, and a Case compares them so that the copy cannot drift (the shims go when the callers move).
3. `scripts/judge-ratchet.mjs` re-exports the library step.
4. No Case of another capability changes.
