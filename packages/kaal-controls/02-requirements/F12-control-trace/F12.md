# controls/F12 control-trace

A control is traced Intent, Requirements, Architecture, Cases, using the relationships of the shared relationship model: a Change implements an Intent, a Requirement serves an Intent, an Architecture element addresses a Requirement, a Case tests what it points at. Controls adds no relationship, no edge type and no registry of controls. It states only what a control adds to each link: the Intent names the undesirable outcome and why it matters, the Requirements state what the control must achieve, the Architecture says where it operates, what judges the condition and what realizes or enforces the result, and every Case points only at what it tests.
