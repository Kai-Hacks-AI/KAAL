# controls/F33 runs-accounted-for

1. A record of a Case of the control whose outcome is RED or UNKNOWN and which carries no `handled` makes the verdict `UNKNOWN` with reason `unhandled`, even when every declared kind has its GREEN runs. The verdict lists those runs in `unhandled`. A record with `handled` is listed in `handledRuns` with what it says, counts toward no kind and does not block. The base record of a `:fail` kind is not a run to account for.
2. A record carries `by`, who or what ran the Case and wrote the record. A record with no non-empty `by` is not counted and is listed in `unrecorded`.
3. The state line shows the number of unhandled runs when there are any, and a verdict with reason `unhandled` shows `UNKNOWN unhandled`.
4. The Skill says that whoever records a run is not whoever wrote the mechanism it runs against or the Cases that run it, and that a run is recorded from what the runner reported, never from memory. A script cannot check it, so it is a rule for an agent to apply and a reviewer to read.
