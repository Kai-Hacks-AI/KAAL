# controls/F40 whole-tree-before-preventive

1. `scripts/scope.mjs` exports `holdsProperty({findingsOf, judge, base, head})`, pure. It holds when the findings `judge(base, head)` reports equal `findingsOf(head)` minus `findingsOf(base)` as sets. It says `holds: false` with `onlyInJudge` and `onlyInDiff` when they differ, and `holds: false` with `reason: 'unstable-findings'` when a finding is not a string or a tree names one twice.
2. `decideAdoption({property, provoked, scan})` is pure and answers one of: `UNKNOWN` when an input is missing; `NOT_READY` with the reason `property-fails`, `not-provoked` (the seeded violation was not found, or did not clear when removed) or `unstable-findings`; `READY` as `preventive` when the scan has no findings; `READY` as `ratchet` with `baseline` (the scanned findings, sorted, each once) and `history` (one line without `at` and `change`: `from: null`, `to: N`, `removed: []`) when it has N.
3. A `READY` answer says `needs: 'owner-go'`: the function never switches a control.
