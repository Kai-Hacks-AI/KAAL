# controls/F232 the package test is the lane

1. `npm test` of the package runs `test/lane.mjs`. The lane runs the package's `test/*.test.mjs` with `runCases` of `kaal-testing/run`, reads `test/plan-register.json`, derives the Changes and their Cases from the package's own `00-changes`, `01-intent` and `02-requirements` with `changesOf` (F233), and judges with F231.
2. It prints the held ids with their Change, every finding with its name, and the observed counts, never the counts alone. It exits 0 when `ok`, 1 with findings and 2 for invalid input (an unreadable register or an unusable root); nothing passes by silence.
3. `--root`, `--register` and the test files can be given, so the lane runs on a fixture the same way it runs on the package.
4. The package's own register exists, is valid and is empty when no PLAN is open.
5. `kaal-testing` is a dev dependency only; `files` in `package.json` is unchanged.
