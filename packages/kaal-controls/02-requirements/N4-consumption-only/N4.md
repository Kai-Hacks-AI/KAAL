# controls/N4 consumption-only

Controls consumes the contracts of other capabilities by name and defines none of them: Testing owns verification, validation, findings and Case design, Graph owns the relationship model, Requirements and Architecture own their documents. Controls keeps no registry of controls, builds no enforcement framework and executes nothing. Its Node and Definition are portable: they name no platform, so no pull request, workflow, ruleset or branch appears in them. Only the worked example may name a platform, as an example.
