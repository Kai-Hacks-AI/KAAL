# controls/F236 diagnostics hold no credentials

1. `scripts/lib/guide-cause.mjs` exports `redactCause(cause)`, pure. It returns the cause with every text field (`asked`, `place`, `platformMessage`, `message`) cleaned of what looks like a credential: a GitHub token (`ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`, `github_pat_`), a `Bearer` or `Basic` token, an `Authorization` header value, and the secret part of `x-access-token:<secret>@` in a URL. Each is replaced by `[redacted]`; nothing else is changed, so a cause with no credential is returned equal to the input.
2. `runControl` carries `redactCause(cause)`, never the raw cause, into `cause`, `guidance` and the log line. A failure's `headers` and any request headers are never part of the cause: the typed failure has no field for them and Controls copies none.
3. The redaction is by shape and is a second line of defence: the fact source remains responsible for not putting a secret in a failure.
