# controls/F236 diagnostics hold no credentials

1. `scripts/lib/guide-cause.mjs` exports `safeCause(cause)`, pure. It builds a new object from an explicit allowlist and copies nothing else, so an unexpected property of the typed failure, at any depth, is not emitted.
2. The safe shape is: `kind` (one of the six platform kinds `rate-limited`, `forbidden`, `not-found`, `network`, `setting`, `other`, or `check-error`), `basis` (`answer`, `text` or `budget`), `ambiguous` (true, and only with `kind` `other`), `asked` and `place` (text), `status` (a number), `platformMessage` and `message` (text), `malformed` (true), and `limit` for `rate-limited` only, with exactly `bucket` (text), `remaining` (a number), `resetAt` (text) and `retryAfterSeconds` (a number). A field of the wrong type is dropped, never coerced.
3. Every text in the safe shape is cleaned of what looks like a credential: a GitHub token (`ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`, `github_pat_`), a `Bearer` or `Basic` token, an `Authorization` header value, and the secret part of `x-access-token:<secret>@` in a URL. Each is replaced by `[redacted]`; nothing else changes, so a failure that holds only safe fields and no credential is returned equal to the input.
4. `runControl` carries `safeCause(cause)`, never the raw cause, into `cause`, `guidance` and the log line. Headers, bodies, tokens, keys and URL queries have no field in the safe shape; Controls copies none, whatever the failure holds.
5. The allowlist follows Hosting's failure contract (`PlatformFailure`); a field Hosting adds is added to the allowlist by its own Change. The redaction by shape is a second line of defence: the fact source remains responsible for not putting a secret in a failure.
