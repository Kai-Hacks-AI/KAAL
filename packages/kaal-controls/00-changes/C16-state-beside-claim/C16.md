# controls/C16 state beside claim

The package shows, beside each control's claimed `status`, the state its evidence supports and the progress of each declared kind of X toward the control's own minimum, for every control that declares one. Nothing is enforced and no claim is changed: the reader sees both and decides. It builds on controls/C15 and reads the same records. KAAL's own minimums are a separate Engineering Change.
