# controls/C167 an adopter outside KAAL runs the package from what it ships

Product priority: one way of doing controls and ratchets, independent of the adopting solution, and proof that it is. Every Case of the package runs inside the KAAL repository, so a script that reaches outside what the package ships, or a name of KAAL in what it returns, passes unnoticed until an outsider adopts it. The Change puts a consumer into the package's own suite: a directory outside the repository that holds only the shipped files, with its own stations, records, flag file and ratchet, and goes through the whole cycle by the public functions. It is the first step of the independent adoption trial (#2933), and it asks no migration of KAAL's own controls.
