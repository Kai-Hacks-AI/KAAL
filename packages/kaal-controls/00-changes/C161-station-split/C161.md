# controls/C161 the station names are the adopter's input, not the Skill's vocabulary

Third step of the package alignment for npm. The Skill fixes seven KAAL stations (`Developing`, `Collecting`, `Integrating`, `Hotfixing`, `Wiring`, `Promoting`, `Publishing`) in the finder (`find-controls.mjs:32`) and names them in two references (four lines). A station is a point where an adopter's work passes; which ones exist is the adopter's setup, and engineering carries it (controls/N8, A11). This Change adds the Case T1711 (RED on the collector: four lines in three files) and, in its DO, makes the list of valid stations an input of the finder and words the references with a neutral example. It authorizes no WIRE, flag, publish or ruleset. No KAAL flag name (`KAAL_<CAP>_<CONTROL>`) is in the Skill today; T1711 keeps it so.
