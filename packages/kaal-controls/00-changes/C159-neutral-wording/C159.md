# controls/C159 the Skill names no hosting term and no repository id form

First step of the package alignment for npm (Kai's decision of 27 November: publication authorized, conditional on scrubbing). The Skill says "pull request" in eight places and shows a Change id form (`<capability>/C8`) in one. "Pull request" is a hosting term and a Change id is KAAL's, so neither belongs in a package that works in any setup (controls/N8). This Change adds the Case T1574 (package-relative, RED on the collector) and words those places neutrally in its DO. It changes no behavior, no input or output name and no control record, and it authorizes no WIRE, flag, publish or ruleset.
