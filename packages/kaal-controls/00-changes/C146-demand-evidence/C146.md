# controls/C146 demand Evidence finds that a pull request that raises the mode of a control carries the evidence for the new mode

One small control with one property, built on the library of controls/C141 (the adapter and `deriveStatus`). Asked for by Kai: small, meaningful controls, each following the change protocol until it blocks.

**The control.** `controls/CTL5`, `demand Evidence`, type detective, status designed. For every control whose `mode` in `head` is higher than in `base` (`off` below `detective` below `preventive`; a control absent from `base` was `off`), the finding is `evidence-due:<id>` unless the evidence is carried: for a raise to `detective`, a record of that control with a verdict other than `UNKNOWN` and a recorded `by`; for a raise to `preventive`, a derived status of `tested` (`deriveStatus`). A control whose mode did not rise is never asked.

**The check.** `scripts/demand-evidence.mjs` exports `findEvidenceDue({base, head, records})`, pure. It returns a sorted list of unique names, empty when nothing is found, and throws on an input that is not a list, so the adapter fails closed with `UNKNOWN`. It reads no file and knows no repository.

**The rollout, by the change protocol.**
1. **Detective.** The check reports through the adapter and blocks nothing.
2. **Advisory.** The adopter runs it as an advisory check behind its own flag, and evidence is collected: Cases on fixtures, real runs on pull requests, and a provoked failure.
3. **Preventive.** Only on the Owner's explicit go, and only with the provoked-fail evidence the protocol asks for.

## Not here

Wiring the control as a station or a required check, the flag, the ruleset, and migrating the controls it finds are release's. Nothing is implemented before the Owner's go on this PLAN.

## Revised after the CPO clarification

A raise carries the facts its new mode needs, each with its own proof and none implying another: running for detective, running and tested for preventive. This follows the four independent facts of controls/C141 (defined, implemented, running, tested): each has its own proof for the specific control and revision, none implies another, and missing evidence is UNKNOWN (the check throws, so the adapter fails closed), never a clean verdict and never proof of absence.
