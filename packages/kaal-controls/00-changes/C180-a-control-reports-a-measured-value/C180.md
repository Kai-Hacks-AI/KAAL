# controls/C180 a control reports a measured value

A control or ratchet answers pass or fail, and that hides its effect. Engineering C47 already prints the number of API calls of the branching audit so the saving can be measured before and after; that number has no home in the controls product. The Owner's direction is that measured reporting is a value proposition of Controls and its children, such as ratchets: one standard way to report a measured value so an effect is visible and comparable over time. The Change adds that one mechanism: a check may return measures next to its findings, `runControl` carries them into the result, the log line and the record without ever changing the verdict, and a pure function compares two sets of measures. Who counts (Hosting counts API calls, Testing produces evidence) stays with its owner; Controls carries and compares. It wires, enforces and installs nothing.
