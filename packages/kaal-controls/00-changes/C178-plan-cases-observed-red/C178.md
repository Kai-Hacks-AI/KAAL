# controls/C178 a PLAN's Cases are observed RED in the package lane

Since C165 the package suite runs in the required Workspaces lane, so a PLAN pull request whose Cases are still RED (as a PLAN requires) fails a required check. The Change makes the lane judge that situation instead of hiding it: the Cases of a PLAN listed in a register must be observed RED by an assertion, every other Case must pass, and anything else fails the lane. It reuses the testing package's run and expectations mechanism (`kaal-testing/run`, `kaal-testing/expectations`); the package adds only the judge of the result, which testing leaves to its consumer. It wires, enforces and installs nothing new.
