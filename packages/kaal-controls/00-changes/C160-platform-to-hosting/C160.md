# controls/C160 the Skill scripts do no platform work; hosting reads the files

Second step of the package alignment for npm. Kai's rule of 27 November: platform mechanics, such as cross-OS file handling, are implemented in hosting and never in controls; foundation holds shared KAAL semantics above the hosting abstraction. The scripts of the Skill still do platform work in five files: file system reads and directory walks (`check-controls.mjs`, `evidence.mjs`, `find-controls.mjs`, `judge-mode.mjs`), line-ending normalisation (`find-controls.mjs`) and the reading of Git (`registry.mjs`). This Change adds the Case T1575 (package-relative, RED on the collector: ten lines in five files) and moves that work to hosting in its DO. The semantic functions already take `{path, text}` entries and stay as they are. It authorizes no WIRE, flag, publish or ruleset.
