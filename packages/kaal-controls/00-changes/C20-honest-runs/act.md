## Learned

The behaviour we were protecting was written down as a Case. T1088 had asserted that a RED run beside the minimum is still PASS, and nobody had read it as a decision until the question "does every UNKNOWN get handled" was asked of it. A Case built on a control must build a valid one.

The script only asks that an explanation exists; the CPO's note is right that a recorded explanation is not independent verification, and the rule that the recorder is not the author of the mechanism is still a sentence in a reference.
