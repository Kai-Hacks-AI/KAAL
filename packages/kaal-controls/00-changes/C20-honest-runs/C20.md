# controls/C20 honest runs

A control is shown tested only when every run of its Cases is accounted for. A run that did not come out GREEN, a control that failed where it should have passed or a run that could not be decided, is either explained or it keeps the claim unproven, however many GREEN runs there are beside it. Every record says who or what ran it, and the Skill says that whoever records a run is not whoever wrote the mechanism it runs against.

This answers a gap named in review of C17: its minimum counts GREEN runs, and the RED and UNKNOWN runs next to them are listed and never judged. Slice 2 of the controls work after C19; the realization slice moves to C21.
