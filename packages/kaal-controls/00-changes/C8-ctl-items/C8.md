# controls/C8 ctl items

Gives a control an identity of its own, `<capability>/CTL<n>`, and a minimal finder that lists every control in a repository. A control states only its id, title, description and the Intents it has. A control test is a Case that points back at the control, like a Requirement points at an Intent. The finder is a deterministic script inside the kaal-controls Skill. It only finds controls: it resolves no Intent, walks no chain, runs no test and checks no gate.
