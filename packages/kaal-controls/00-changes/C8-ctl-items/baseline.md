# C8 baseline

The baseline is `main`. Work that is not on `main` is not delivered functionality, and this Change depends on nothing that is not on `main`.

- `main` holds `packages/kaal-controls/` with the Skill on the four types (C7). It defines no id scheme, no control declaration and no way to list controls.
- `engineering/controls/` holds only the C3 PLAN text. It is Engineering's own tooling and is not part of this Change.
- The id prefix `CTL` is allocated to controls by the coordinator on 16 Nov 2026.
