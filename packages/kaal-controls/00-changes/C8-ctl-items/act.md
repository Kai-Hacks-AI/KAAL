## Liked

The shape got smaller with every answer. It began as an item with several relations and ended as id, title, description and `has`, with the test pointing back, like a Requirement points at an Intent. ## Learned

A sync is a merge commit on the collector's current tip, never main's tip as a branch, and any landing on the collector makes an approved sync stale, so a sync and a PLAN landing together cost a second sync and a second approval. Branching fails the first run of every new PR until auto-merge registers, and a disable and enable of auto-merge clears it. A skill with a word cap needs its new text in a reference file.
