# controls/C164 the flags are in a file and the library reports where every control stands

Kai's decisions, recorded: the detective or preventive flag of a wired control lives in a file, and the library reports where every control stands. This Change records the intent I32, the Requirements F224 (the flag file: format, reader, source seam, ownership) and F225 (the status report), the architecture A215 and the Cases T1723 to T1726. The package owns the format, the reader and the report and ships no flag and no adopter name. The adopter's controls instance owns the file and its values, and a flip is a reviewed pull request to that file. The flag source is a seam of one function, and the file is the only source built (YAGNI). It builds on C158 (the flag in the run and judgeRunning) and authorizes no DO, WIRE, flag, workflow, required check, ruleset or publish.
