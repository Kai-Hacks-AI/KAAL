The baseline is `main` after the C17 promotion. `judgeEvidence` says PASS when each declared kind has enough GREEN runs and a `:fail` kind has a base run that is RED and different from the head run. A control can therefore show Tested on a Case that checks something nearby and on a provoked failure that withheld a fixture.
