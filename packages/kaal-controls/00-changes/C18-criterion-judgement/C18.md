# controls/C18 criterion judgement

The package checks as far as a script can whether a control's Test Cases show what its type promises, and reads the reviews that validate the rest. A provoked failure must not have withheld a Case or a fixture and, as far as the record says, must show what the type needs: a refusal at a declared preventive station, a report, a restoration. A control is verified by Test Cases and validated by a kaal-review record whose focus is the control; the package keeps no validation shape of its own. It says what a review of a control must cover, looks reviews up by the control id and shows whether each read the control's Intents and Cases, beside the result and never changing a verdict. It builds on controls/C15 and the state line of controls/C16, and adds no enforcement.
