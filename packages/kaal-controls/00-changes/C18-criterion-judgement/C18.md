# controls/C18 criterion judgement

The package checks as far as a script can whether a control's Test Cases show what its type promises, and has the agent judge the rest. A provoked failure must not have withheld a Case or a fixture and, as far as a record says, must show what the type needs: a refusal at a declared preventive station, a report, a restoration. The agent reads the control's criterion beside its Cases, says whether they cover it, and records that as a judgement beside the results. The judgement is shown, marked stale when the control or its Cases changed, and never changes a verdict. It builds on controls/C15 and the state line of controls/C16, and adds no enforcement.
