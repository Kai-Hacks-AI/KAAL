# C7 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C7 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

Two CPO reviews that each removed something. The first PLAN copied the handover and grew a package, a procedure, verdicts, verbs and places. The review cut it to the one thing the Skill had to teach, and the Cases became simpler to write and to trust. Writing the scenario key before the Skill also helped: the Skill had nothing to be tuned to.

## Learned

A reviewer's placement direction can be a first reading. The move to `engineering/controls/` was withdrawn after one push, so the placement question should be asked of the product's owner before the files are moved. A trial shows what one agent did once: its eight answers matched, but they come from one run with a protocol that told it how to judge claims. The PR tool appends attribution to a body by itself, so a PLAN or DO body has to be read back after it is created, not trusted.

## Lacked

A way to see a PR body as the checker will see it, tool-added wrappers included. A way to run the Cases of a package in CI without editing the root file list. An ownership claim for a slice that has no Node. A definition of PASS, FAIL and UNKNOWN on `main`, which the PLANs of release management already cite.

## Longed For

A verify Plan that reads the whole body, so that a footer or a hidden comment fails it and not a reviewer. A second and third trial with different agents, so that the Skill is judged on more than one run. Cases that are found and run wherever a capability keeps them.

## Closed

The three Gaps of this Change are closed: G1, G2 and G3, by Cases T16, T17 and T18, green in the collector with the Skill and the recorded trial.
