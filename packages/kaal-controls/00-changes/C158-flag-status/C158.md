# controls/C158 the library knows the flag and judges the Running fact

Kai's questions: how is the status of a control known without the flag, and is the judgement part of the library? This Change records the intent I30 and two Requirements. F216: the adopter hands the flag's name and value to the adapter in the boundary, a flag that is not exactly `on` runs the control switched off (it still executes and is recorded with `mode: off`, `applied: false`), a missing flag is unknown, and the log and the record carry the flag. F217: a pure `judgeRunning` turns run records into the DIRT Running fact of a control, true by an executed run, never false, with the mode and whether the flag applied it told beside it. The library reads no environment. Release, as the adopter, supplies the raw records. It authorizes no WIRE, flag, workflow, required check or ruleset.
