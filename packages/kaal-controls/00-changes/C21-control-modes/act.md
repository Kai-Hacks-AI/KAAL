# C21 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C21 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

The CHECK was defined before it ran: Test Cases, judgment definitions J1 to J5 and four planned weakenings, each pointing at the element it examined. The independent appraisal then found real gaps in wording (the filter alone would pass a grown baseline, an unrecognised mode did not block) that the Cases could not see, and they were fixed as wording and one line, not as a rework.

## Learned

An approved PLAN is not the product model. The PLAN was approved with `advisory` and a shipped `AGENTS.md`, and the CPO then corrected both against the established taxonomy and the two-file layout: a ratchet is a temporary mode of a preventive control, not a type, and development instructions are not shipped. Target documents and Cases were changed on purpose and recorded in `change.md`. A headless trial agent carries the session's team memory unless it is switched off: the first trial's baseline arm already knew the answer, and only a direct question to an agent exposed it. The Skill changed what agents said about type, growth, unknown and exit, and changed nothing about who owns what: agents placed the split correctly without it.

## Lacked

Before the PLAN, a read of the layout and product model that the concept had to fit (the type versus mode distinction, what is shipped). A first answer to the CPO's changes-requested that said plainly which item was not mine to give: the independent dispositions. And a way to see which trial runs opened the Skill, which was not checked.

## Longed For

A trial harness that starts agents with no memory and a true no-Skill arm by default, and scores them by someone other than the author. A review of the write-back half of the responsibility split: no trial run addressed persisting the next baseline.
