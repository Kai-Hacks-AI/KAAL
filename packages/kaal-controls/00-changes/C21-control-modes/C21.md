# controls/C21 control modes

kaal-controls learns the general concept of how a check is put to use. One check gives one answer, in or out of its specification, and flags both what is missing and what is too much. The same answer is used in one of four modes: detective (it reports), advisory (it warns where the author acts and blocks nothing), preventive (it blocks) and ratchet (a preventive that blocks only what is worse than a recorded baseline, which only shrinks). A ratchet whose baseline reaches nothing is cleaned up into plain preventive and its baseline is removed, and a ratchet with no such exit is not accepted. The type of a control is design and does not change with its mode; a claim is as strong as the mode and no stronger.

It is worked in the order of BASS, one step at a time, and each element states what verifies it. Bare is the concept as agreed in conversation. Agent is a short instructions file that points at the Skill. Skill is one reference on modes and a pointer. Script is a pure function that applies a mode to an answer, and the finder that accepts the four modes.

Not in this Change: any particular check or layout (engineering's C30 applies the concept and is only an example here), any place where a mode is switched on, and who may switch it.
