# C21 check

A bounded demonstration, in the CHECK of the DO, that the Cases notice what they claim to. Hand-run: no standing framework and no committed mutation tool. For each row the weakening is loaded into a throwaway copy of the DO's `judge-mode.mjs`, the Cases are run, and the claim, the weakening, the Case that witnessed it and the assertion that failed are recorded in the Change's evidence. A weakening no Case notices is a finding, kept as it is, and a Case is added in the DO.

| Claim | Weakening to load | Expected witness |
| --- | --- | --- |
| a finding outside the baseline blocks | accept all findings | T1109 |
| a baseline only shrinks | disable detection of baseline growth | T1112 |
| a resolved allowance is gone | retain resolved allowances (do not advance, ignore stale) | T1109, T1112 |
| missing evidence is not success | treat a missing reference as success | T1113 |

The agent trial of `verification.md` is separate: it tests the Skill's words, not the script. Its failures are retained and not manufactured.
