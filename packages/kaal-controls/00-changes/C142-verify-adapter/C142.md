# controls/C142 verify Adapter finds that a control that has a station, or is delivered, does not run through the adapter

One small control with one property, built on the library of controls/C141 (the adapter and `deriveStatus`). Asked for by Kai: small, meaningful controls, each following the change protocol until it blocks.

**The control.** `controls/CTL1`, `verify Adapter`, type detective, status designed. For every control that declares a station, or whose id is in `delivered`, the finding is `unadapted:<id>` when the adopter's observation of the delivered implementation at the applicable revision says it does not run through the adapter, and `unobserved:<id>` when there is no such observation: incomplete evidence is never clean. Membership is established from the actual implementation or delivery, independently of the declaration and correlated to the control and the revision; a list the adopter merely supplies is not proof. This follows the four independent facts of controls/C141.

**The check.** `scripts/verify-adapter.mjs` exports `findUnadapted({controls, delivered, observed, revision})`, pure. It returns a sorted list of unique names, empty when nothing is found, and throws on an input that is not a list, so the adapter fails closed with `UNKNOWN`. It reads no file and knows no repository.

**The rollout, by the change protocol.**
1. **Detective.** The check reports through the adapter and blocks nothing.
2. **Advisory.** The adopter runs it as an advisory check behind its own flag, and evidence is collected: Cases on fixtures, real runs on pull requests, and a provoked failure.
3. **Preventive.** Only on the Owner's explicit go, and only with the provoked-fail evidence the protocol asks for. Since controls that exist today would fail, it runs as a ratchet (C24, C25): their names form the baseline, shrink with a history as release migrates them, and the ratchet ends at zero.

## Not here

Wiring the control as a station or a required check, the flag, the ruleset, and migrating the controls it finds are release's. Nothing is implemented before the Owner's go on this PLAN.
