# controls/C165 the required lane runs the controls suite

Kai's go on closing the gap. The Cases of `@kaihacksai/kaal-controls` ran only in an advisory job on a pull request, never in the merge group, because the package is not a workspace of the root, so the required Workspaces lane skipped them. Two promotions (the Skill names no hosting term, and the flags in a file) each went green through the queue and turned `main` red together. The Change makes the package a workspace, so the lane that is already required runs its suite on a pull request and in the merge group. See controls/I33, controls/F227 and the Case T1729.
