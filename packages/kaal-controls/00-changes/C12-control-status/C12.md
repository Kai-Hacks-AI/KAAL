# controls/C12 control status

Closes a small gap. A control declaration cannot say how far the control has come, so a declared control is easily read as an effective one. A control now declares a mandatory `status`: `designed`, `implemented`, `running` or `tested`. The finder checks it and lists it. Nothing else changes.
