# controls/C12 control status

Closes a small gap. A control declaration cannot say how far the control has come, so a declared control is easily read as an effective one. A control now declares a mandatory `status`: `designed`, `implemented`, `running` or `tested` (DIRT, cumulative). The finder lists it, and a permanent check in the package fails visibly on a missing or invalid status and says how to recover. The Skill helps whoever judges whether a claimed status is true, which no script can decide. The Skill and its scripts stay unaware of the KAAL repository and work in any setup. Engineering deploys the check on its own controls and keeps the migration guidance. Product and Engineering only: no GitHub workflow, required check or enforcement.
