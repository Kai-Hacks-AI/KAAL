# controls/C9 ctl type

Closes a small gap. The Skill distinguishes four types of control, but a control declaration could not say which one it is. A control now declares a mandatory `type`: `directive`, `preventive`, `detective` or `corrective`. The finder checks it and lists it. Nothing else changes.
