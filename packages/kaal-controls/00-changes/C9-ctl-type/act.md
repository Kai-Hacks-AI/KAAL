# C9 act

A 4L retrospective of the Change, from the viewpoint of the agent that carried it. It closes C9 in the collector. What `main` teaches can only be recorded after the promotion, and is not claimed here.

## Liked

The CPO named the gap in one message and bounded it: one mandatory field, four values, nothing else. That made the PLAN small, with seven Cases that failed on their own assertions and went green against a throwaway reference. The C8 Cases kept their assertions and only gained a type, which showed the shape had held.

## Learned

A new mandatory field also changes the Cases and the requirement text that said "exactly" the old fields, so F13 and F16 had to be read together to avoid contradicting each other. A Case that expects a refusal can pass for the wrong reason while the field is still unknown, so each refusal Case first asserts that the valid form is listed. An item without an id is not a candidate at all, so it is neither listed nor refused. Branching still fails the first run of a new PR and passes on the next.

## Lacked

A single place that states the allowed values once. The finder, the reference and the Cases each list the four types. A check that the type matches what the control does, which is a judgment and stays with the Skill.
