# controls/C15 minimum evidence for Tested

A control may state its own minimum evidence for `tested`, and the package can judge it. Evidence is not a new kind of test: it is the control's own Test Cases run against an X, so a control says which kinds of X, how many runs of each, and that one of them is a real failure. A script says PASS or UNKNOWN from the declaration and recorded runs, and the check, given records, fails a `tested` claim that is not shown. Nothing needs GitHub or a KAAL path: where the records live and which runner makes them is for the repository that uses the package. The Engineering side (KAAL's numbers, its records and the flag a WIRE flips) is a separate Change.
