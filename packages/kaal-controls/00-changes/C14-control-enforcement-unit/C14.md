# controls/C14 controls register at stations

The first slice of the Control Enforcement Unit (`design.md`). A control may declare at which stations it judges and in which mode, and one script lists the controls registered at a station from the base of a pull request, never from the working tree. The finder lists `stations` and reports a bad line as a problem. The Skill gets the reference that says what a station is. Nothing judges, signs, runs on GitHub or needs an App yet, so the slice is provable with Cases alone and is useful on its own: `verify Stages` (release/C70) and the Agents can ask which controls are meant to judge a station. The package holds it all, with no KAAL path.
