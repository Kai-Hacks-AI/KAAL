# controls/C181 KAAL's first flags file

The controls library reads flags from a file the adopter owns (C164), and KAAL's controls instance has none. Release needs one for the two controls of the Promotion Source replacement, release/CTL40 and release/CTL41, so its swap can read a flag at every station. Release's configuration readiness is its own Case (T1798, adoption-ready) and reads a fixture until this file is on main. The Change creates `engineering/14-operations/controls/flags.json` with exactly those two controls at the four stations where Promotion Source runs, each `advisory`. Nothing reads the file until the swap WIRE, so it is inert; every later entry and every flip is its own decision. The Owner approved raising this Change (28 Nov 2026, 12:00).
