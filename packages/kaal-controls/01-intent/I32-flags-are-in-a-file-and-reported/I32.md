# controls/I32 the flags are in a file and the library reports where every control stands

Whether a wired control applies (preventive) or only reports (detective) is a flag, and the flag lives in a file, so that a change of it is a reviewed change with a history and the same file reads the same on every platform. The library defines the file format, reads its text and reports, for every control, its declared type, its flag, its effective mode, whether its runs applied it and its last run, so that no one has to ask where a control stands. The library ships no flag and names no adopter: the adopter's controls instance owns the file and its values, and a flip is a pull request to that file. The source of a flag is a seam, and the file is the only source built. Whether Hosting offers another one, such as GitHub variables, is a later decision.
