# controls/I32 the flags are in a file and the library says where every control stands, per place, in STAMP

Running is the fact of one control in one place, and it has five states, STAMP: Stopped, Torn, Advisory, Mute, Preventing. Stopped, Advisory and Preventing are chosen, by a flag in a file, so that a change of it is a reviewed change with a history. Torn and Mute are found by the library and never chosen: Torn is a control that was meant to run and gave no verdict, a loud error, which blocks under a Preventing flag; Mute is silence, no flag or no trace of a run, and is never read as Stopped or Advisory. The library defines the file format and reads its text, judges the state from the flag and the established runs, and reports it for every control and place. Escalation is stepwise: no Preventing without the proof of an earlier Advisory run. The Definition, Implementation and Test facts of DIRT do not change here. The library ships no flag and names no adopter: the adopter's controls instance owns the file and its values, and the flag source is a seam of which the file is the only one built.
