# controls/I39 KAAL states where its controls run, in a file

The controls library knows how to read a flag file and nothing says where KAAL's own controls stand. The intent is that KAAL's controls instance holds one reviewed file that states, per control and station, whether it is stopped, advisory or preventing, so a flip is a pull request with history, and the first entries are the advisory ones that change nothing until something reads them.
