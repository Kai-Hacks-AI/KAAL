# controls/I16 care decision model

A control that finds something wrong does not decide what happens to it. Detection lists the findings. Review records a disposition for every one: valid, invalid with evidence, or unknown and still to be investigated. An authorized decision-maker then selects one response for each valid finding only: **CARE**, Contain, Accept, Ratchet, Eliminate. Contain limits the exposure while the finding stays. Accept keeps the finding with a named owner and a stated reason. Ratchet is a preventive strategy that supports progressive corrective work, so no finding in it is accepted by being there. Eliminate corrects the finding. An invalid or unknown finding never takes a response and is never implicitly accepted. No finding is ever accepted by being old, and no response is chosen by the scan that found it.

The wording of the whole phrase, the Owner's, as one nested memory aid that is not tested:

**CONTROL DIRT WITH CARE**

- **CONTROL**: Controls Observe Noncompliance, Testing Reliable Optimised Lifecycles
- **DIRT**: Designed, Implemented, Running, Tested (the status a control declares)
- **WITH**: While Implemented Tests Help
- **CARE**: Contain, Accept, Ratchet, Eliminate (the decision model this intent states)

Beside it stands **RATCHETS**, Raises Agents Toward Controlled Higher Engineering Targets Systematically (controls/I15), the mnemonic of the one response that is also a mode.
