# controls/I30 the library knows the status of a run

A control's status is not read from silence. When a control has a flag, the adopter hands the flag's name and value to the one shared library, the library applies it, and the run records which flag and which value it saw, so that a run that was switched off is a recorded run and not a missing one. From the run records the library judges the Running fact of each control in the product's terms: Running is proven only by a run that is valid, established and of this revision, it is true or unknown and never false, and whether the flag applied the control is told beside it, never inside it. The library reads no environment, repository variable or file: what is not handed over is unknown, and unknown never stands for on, for off or for a pass.
