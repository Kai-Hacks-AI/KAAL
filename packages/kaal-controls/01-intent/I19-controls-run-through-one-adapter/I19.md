# controls/I19 every control runs through one thin adapter that leaves the evidence of its record

A check only finds. Everything else that every control needs, which mode it runs in, the allowance of a ratchet, the refusal to pass when it could not judge, a line of log, and the line that shows it ran, is done once, by one thin adapter that every control runs through. The line it leaves is execution evidence for that control and revision, and nothing more. Defined, implemented, running and tested are four independent facts, each with its own proof, none implying another, and a claim is compared with each fact alone. A missing proof is unknown, never proof of absence. The adapter and that comparison are a library. What is checked with them, one property at a time, is a control of its own.
