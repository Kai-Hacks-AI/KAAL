# controls/I19 every control runs through one thin adapter that leaves the evidence of its record

A check only finds. Everything else that every control needs, which mode it runs in, the allowance of a ratchet, the refusal to pass when it could not judge, a line of log, and the line that shows it ran, is done once, by one thin adapter that every control runs through. The line it leaves is evidence, and from evidence the status a control has reached is derived and can be compared with the record. The adapter and that derivation are a library. What is checked with them, one property at a time, is a control of its own.
