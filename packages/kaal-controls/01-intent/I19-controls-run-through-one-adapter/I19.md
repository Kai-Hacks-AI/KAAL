# controls/I19 every control runs through one thin adapter, and its record cannot lag

A check only finds. Everything else that every control needs, which mode it runs in, the allowance of a ratchet, the refusal to pass when it could not judge, where its baseline came from, a line of log, and the line that shows it ran, is done once, by one thin adapter that every control runs through. The adapter is how a run leaves evidence, and from that evidence the control's record is known: a record that says less than the evidence shows is a finding, and so is one that says more. A control that is delivered with no record, or that does not run through the adapter, is a finding too. A review detects these first and blocks them only once it has been seen to work.
