# controls/I17 accepted failure

A finding is an observation. When it is valid it becomes a Test Case and a Defect, and those are what persist. A control that fails keeps failing in its report until the failure is gone. If the failure is accepted, the report still says FAIL and adds that it is ACCEPTED. A separate verdict may permit delivery for that specifically authorized failure, using the failing Test Cases and an acceptance list. A new or different failure is not covered. Acceptance never turns a FAIL into a PASS, and it never covers more than it names. It lives only while its Defect is open: fixing the Defect voids it, and a later failure of the same Test Case is a regression that needs a new decision.
