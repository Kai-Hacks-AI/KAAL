# controls/I35 the package works for someone who is not KAAL

The package is meant to be one way of doing controls and ratchets for any solution, not an extract of KAAL. Today every Case runs inside the KAAL repository, with its layout around the package, so a file that reaches outside what the package ships, or a word of KAAL in a place only an outsider would read, passes unnoticed. The independent adoption trial (#2933) will find such a leak, but late and by hand.

The intent is that a consumer with nothing of KAAL, its own stations, its own control records, its own flag file and one ratchet, works from the files the package ships and through its public interface only, and that nothing it gets back names a station or a part of a solution that is not its own. This is a fixture inside the package's own suite, so the leak shows in the lane on the pull request that causes it. It is not the adoption trial, and it asks no migration of KAAL's own controls.
