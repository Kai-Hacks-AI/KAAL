# controls/I10 state beside claim

A control's `status` is what it claims, and a claim can lag or run ahead of what is shown. The package therefore shows, beside the claim, the state that its evidence supports and how far each declared kind of X has come toward the control's own minimum, for every control that declares one and not only those that claim `tested`. The reader sees the claim, the computed state and the progress together and decides. Showing is not enforcing: the package never changes a claim and never fails a claim below Tested.
