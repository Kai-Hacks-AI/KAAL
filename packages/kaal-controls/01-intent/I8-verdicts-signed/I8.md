# controls/I8 verdicts signed

A control that blocks a merge does so through a verdict that nothing the merge changes can forge. The control says at which stations it judges and in which mode, a runner judges with the code of the base and never with the code of the candidate, and a separate step that holds the only secret signs the verdict as a check on the exact head. A verdict that cannot be read, a control that did not answer and a verdict for another head are never a pass. A control is Running at a station once a signed check from it exists there.
