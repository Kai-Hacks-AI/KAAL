# controls/I26 recognize Adapter integration

Whether a delivered control is built to run through the adapter can be read from its delivered entry as it is at a revision, never from what the control declares. That reading is structure: it shows that the integration is recognizable, not that it ran. Execution is shown by a run record, separately. What the structure does not show is unknown, never nonconformance.
