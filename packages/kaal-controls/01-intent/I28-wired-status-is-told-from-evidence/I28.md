# controls/I28 what is wired is told from evidence, never from a declaration

A control that exists as code is not a control that protects. Which controls are installed in the delivery, which exist only as code and wait for a WIRE request, and which are installed but not yet shown to run, is told from what the adopter observed, never from what a control says about itself. Evidence that cannot be trusted gives no status, only unknown. The report is for the Owner's decisions and is never a finding.
