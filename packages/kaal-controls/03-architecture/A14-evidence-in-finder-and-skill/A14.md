# controls/A14 evidence-in-finder-and-skill

The finder `skills/kaal-controls/scripts/find-controls.mjs` reads the optional `evidence` line and lists `evidence` as `[{ kind, runs, fail }]`, reporting a bad line as a problem of `evidence` with a recovery. The script `scripts/evidence.mjs` exports `judgeEvidence(control, records)`, which uses the Cases the finder already lists for the control, and `readRecords(path)`, which reads a JSON file or a directory of JSON files. Its command prints the verdict of each control that claims `tested`. `check-controls.mjs` takes `--records <path>` and, given records, adds a problem of `status` for each `tested` claim that is not PASS. The records are Case outcomes with the X they ran against; where they are kept, and how a runner's report becomes records, is for the repository that uses the package. The Skill gains no line in `SKILL.md`: `references/declaring-controls.md` says how to declare `evidence` and `references/judging-status.md` says how Tested is shown. The scripts stay in the Skill's `scripts/` folder, know no repository path and need nothing beyond the foundation and the hosting.
