# controls/A15 state-in-evidence-script

`scripts/evidence.mjs` exports `computedState(control, verdict)` and `stateLine(control, verdict)` beside `judgeEvidence`, and its command prints `stateLine` for each control that declares `evidence`, whatever its status, or the verdicts as JSON with `--json`. It reads only what the finder already lists (`valid`, `status`, `evidence`, `tests`) and the records it is given, knows no repository path and adds nothing to the Skill's dependencies. `references/judging-status.md` says that the computed state is what the evidence shows and the claim stays a claim; `SKILL.md` gains no line.
