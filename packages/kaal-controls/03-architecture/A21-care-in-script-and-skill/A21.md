# controls/A21 care-in-script-and-skill

`scripts/care.mjs` is a pure function, `judgeDecision`, over a list of finding ids, a list of disposition records and a list of decision records. It owns the completeness of the record: one disposition per finding, one decision per valid finding and none for another, a known response, the fields each needs. The adopter owns where the records are kept, who is authorized to select, and what a PASS lets it do. It reads no file and knows no repository, path, flag or role. `references/care.md` carries the model in wording that names no other package and none of KAAL's own words, and `SKILL.md` gains one pointer line within its 600 words. The qualification that lists the findings stays in `scripts/scope.mjs` and is not changed.
