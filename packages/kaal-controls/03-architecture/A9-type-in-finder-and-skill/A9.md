# controls/A9 type-in-finder-and-skill

The finder `skills/kaal-controls/scripts/find-controls.mjs` takes `type` as a fifth field of a control, checks it against the four values and returns it on each listed control. The Skill reference `references/declaring-controls.md` shows the `type` line and names the four values. `SKILL.md` stays under its word cap and only points at the reference.
