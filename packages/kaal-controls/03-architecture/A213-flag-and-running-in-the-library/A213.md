# controls/A213 flag-and-running-in-the-library

The flag is a fact of the run, so it enters the adapter (`scripts/adapter.mjs`) through the boundary, next to `x`, `run` and `sha`, and leaves in the log and the record. The adapter gains one concern, the application of the flag, and only that: a flag that is not `on` makes the control run in the mode `off`. The proof rule of `executed` (a valid record that the adopter has independently established) is taken out into one function that `executed` and `judgeRunning` both use, so the rule is written once. `judgeRunning` sits in its own script, `scripts/judge-running.mjs`, pure, beside verify Record: verify Record compares a claim with a fact, and `judgeRunning` is what produces the `running` fact. Where the records live, how a run is established and what the flag variable is named are the adopter's. Release supplies the raw records, as the adopter.
