# controls/A10 status-in-finder-and-skill

The finder `skills/kaal-controls/scripts/find-controls.mjs` takes `status` as a sixth field of a control, checks it against the four values and returns it on each listed control. The Skill reference `references/declaring-controls.md` shows the `status` line and names the four values in order and shows the check command. `SKILL.md` stays under its word cap and only points at the reference.

The check `skills/kaal-controls/scripts/check-controls.mjs` imports the finder, turns each refused declaration into a problem with a recovery, exports `DIRT` and exits 1 on any problem. It writes nothing. The rule lives in the package alone: Engineering deploys the check (controls/A11) and does not copy it.
