# controls/A10 status-in-finder-and-skill

The finder `skills/kaal-controls/scripts/find-controls.mjs` takes `status` as a sixth field of a control, checks it against the four values and returns it on each listed control. The Skill reference `references/declaring-controls.md` shows the `status` line and names the four values in order. `SKILL.md` stays under its word cap and only points at the reference.
