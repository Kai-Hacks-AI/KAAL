# controls/A6 control-contract

The Node `Controls`, typed by Core's `KAAL Capability` (`capability/Controls.md`), and the Definition `Control`, typed by Core's `KAAL Definition` (`payload/Control.md`). The Node states class, verb, verdict, the separation of control, mechanism and enforcement, and the four places. The Definition states what a Control Node is. Neither names a platform. A control that needs the platform states it in the Architecture of the capability that owns the control.
