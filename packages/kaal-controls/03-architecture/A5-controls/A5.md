# controls/A5 controls

The deployment target of the Controls capability: the package `kaal-controls` in the layout of the other capabilities (`packages/kaal-<name>/`), with its own LICENSE, README and ownership claim. It holds the contract of a control (controls/A6) and the Agent Skill that applies it (controls/A7). It holds no code, no registry and no enforcement; Engineering stays the incubator of the controls a capability builds, and Controls is the reusable semantics they consume.
