# controls/A202 adapter-in-script

`scripts/adapter.mjs` holds two pure functions over the existing libraries: `runControl` joins `judgeMode`, the ratchet library and the record, and `deriveStatus` compares a claim with the evidence. It owns the join. The adopter owns what is delivered, which controls it runs through the adapter, where `records.jsonl` is kept and how a run is known to exist, and passes them in. It reads no file and knows no repository, path, flag, service or workflow. Each control stays a declaration and a pure check (C142 to C146).
