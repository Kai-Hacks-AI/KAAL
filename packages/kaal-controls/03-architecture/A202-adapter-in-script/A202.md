# controls/A202 adapter-in-script

`scripts/adapter.mjs` holds two pure functions over the existing libraries: `runControl` joins `judgeMode`, the ratchet library and the record; `executed` reads the one fact the adapter can show, running, from a valid record that the adopter has independently established; and `compareClaims` compares each declared claim with its own fact. It owns the join, and it is no authority for the other three facts: defined, implemented and tested are established by their own proofs and passed in. The adopter owns what is delivered, which controls it runs through the adapter, where `records.jsonl` is kept and how a run is established to exist (the `established` list, verified against the service by the adopter), and passes them in. It reads no file and knows no repository, path, flag, service or workflow. Each control stays a declaration and a pure check (C142 to C146).
