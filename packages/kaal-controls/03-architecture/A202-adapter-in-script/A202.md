# controls/A202 adapter-in-script

`scripts/adapter.mjs` holds three pure functions over the existing libraries: `runControl` joins `judgeMode`, the ratchet library and the record, `deriveStatus` compares a claim with the evidence, and `judgeRegistration` lists what is not registered correctly. It owns the join. The adopter owns what is delivered, which controls it runs through the adapter, where `records.jsonl` is kept and how a run is known to exist, and passes them in. It reads no file and knows no repository, path, flag, service or workflow, so it applies to any repository that has controls. Each control stays a declaration and a pure check.
