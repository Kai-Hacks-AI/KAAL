# controls/A209 recognize-adapter-in-script

`scripts/recognize-adapter.mjs` is one pure function, `recognizeIntegration`, over values the adopter passes in. It owns what counts as a recognizable integration: the import of `runControl` from exactly the adapter module and a call of it that can run. It claims no execution and no nonconformance. The adopter owns the delivered entry and its revision, the adapter path, the station and the flag, and feeds the recognitions to `findUnadapted` (controls/A203), which reads them as observed without a finding; an entry that is not recognized is unknown there (controls/F206), through the adapter of controls/C141.
