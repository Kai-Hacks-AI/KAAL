# controls/A8 finder-in-skill

The finder is `skills/kaal-controls/scripts/find-controls.mjs`, inside the Skill and so inside the package `files`. Its pure function `findControls(files)` takes `{ path, text }` items and returns `{ controls, refused }`. It imports nothing. A command line entry gathers the Markdown and `.mjs` files of a directory and prints the result as JSON. The Skill judges what a good control is, and the script verifies the shape.

A control item lives in `CTL<n>-<slug>/CTL<n>.md` with its Case beside it, `T<n>.test.mjs`, like every other item. The numbered concern folder is not decided by this Change.
