# controls/A7 scenarios

`scenarios.json`: situations written without any platform, each with the types it holds and whether the claim it ends in is supported. It is the key an agent's answers are compared with. An agent given only the Skill answers each scenario; its recorded answers are the behavioral evidence that the Skill teaches the distinctions. The key is written before the Skill, so that the Skill cannot be tuned to it.
