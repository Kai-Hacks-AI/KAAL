# controls/A5 controls-package

The deployment target of this first slice: the package `packages/kaal-controls/`, in the layout of the other capabilities, developed in a capability collector. It holds the candidate Skill (controls/A6) and the scenarios that demonstrate it (controls/A7), and only a minimal package shell around them. It has no Capability Node and no Control Definition, and the Skill is deployed to no place where agents discover skills. `engineering/controls/` stays Engineering's own tooling and is not touched.
