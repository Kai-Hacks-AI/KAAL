# controls/A20 mode-in-script-and-skill

`scripts/judge-mode.mjs` is a pure function, `judgeMode`, over a mode, a list of findings and, for a ratchet, the baseline and the previous baseline; its command reads JSON files and exits 0, 1 or 2. It knows no repository, path, flag or tool, and takes the findings from whoever ran the check. `scripts/find-controls.mjs` accepts the four modes in `stations` and requires `exit` of a control with a ratchet. `references/modes.md` carries the concept in wording that names no other package and none of KAAL's own words; `SKILL.md` gains one pointer line within its 600 words, and the Skill's files name no other package (controls/T777). `AGENTS.md` at the package root points at the Skill and repeats nothing, and `package.json` ships it with `skills`. The check that produces the findings, and the place where a mode is switched on, belong to whoever uses the Skill, not to this package.
