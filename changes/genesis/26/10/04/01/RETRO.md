# Retro

## Learned

The checks that Engineering KAAL Skill carries turned out to be reusable on a second capability without any change: `check-skill` and `register-skill --check` accepted Changing KAAL as written. I had expected to find assumptions about the first capability baked into them.

## Liked

The briefing's Do and Do not lists settled, before I reached them, where each piece of wording belonged. When I was unsure whether a sentence went in the Node or in the Agent Skill, the answer was already there, and I did not have to weigh it.

## Lacked

A usable failure message from the sealing helper on a fresh checkout. My first attempt printed a TypeScript error about missing `node` types and wrote no seal; the cause, that nothing had been installed yet, I had to work out myself, and for a moment I read the output as if the Node had been sealed.

## Longed

To begin a future change by reading the retros of earlier ones for the same name, so that what one agent learned reaches the next before it starts rather than only after.
