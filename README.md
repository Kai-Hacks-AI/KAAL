# KAAL
KHAIs Artificial Agent League

## Layout

TypeScript npm-workspaces monorepo. Each deployable unit is an npm package under `packages/`.

```
npm install
npm run build
npm test
```

To add a package, create `packages/<name>/` with its own `package.json` and `tsconfig.json` (extend `../../tsconfig.base.json`).

## kaal-core

`packages/kaal-core` produces the KAAL Kernel payload, which belongs in `root/.kaal`. The payload is one file, `core/KERNEL.md`: the first Node, which defines Node, Edge and immutability and is itself a Node. It is generated by TypeScript (`kernelMarkdown()`); there is no hand-maintained copy.

`check-kaal-kernel` (`npm run check-kaal-kernel`; the root script delegates to kaal-core, which owns the check) is the verification. It checks the generated Kernel against the bootstrap contract (`verifyKernel`) and against its seal, `packages/kaal-core/kernel.sha256`. The pre-commit hook (`.githooks`, enabled by `npm install`) and CI (`.github/workflows/check-kaal-kernel.yml`) both invoke it. A deliberate Kernel change updates the seal in the same commit.
