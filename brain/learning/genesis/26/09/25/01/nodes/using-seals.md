# Using Seals

KAAL uses the **using-seals** skill so a learning, once closed, cannot change unnoticed: past understanding stays exactly as it was learned.

KAAL seals BRAIN on every push to `main`. Each lineage is a chain and each learning a unit, oldest first; a learning is closed when it is sealed. `main` is the history every change is checked against, and only sealing on `main` writes seal state.

The skill explains how sealing and checking work. This node records why KAAL uses it.
