# architecture

The conceptual architecture overview of KAAL: a picture and its explanation of where an Agent, KAAL and the Six Ds stand to one another.

- [overview.md](overview.md): what the overview shows, what each part is responsible for, and which parts exist today and which are target architecture. Read this first.
- [overview.svg](overview.svg): the canonical visual, kept as SVG source.

The overview is a projection. It is not a Node, it is not sealed, and it defines nothing: KAAL's meanings are stated by its Nodes, and where the overview and a Node differ, the Node is right and the overview is stale. Start from `.kaal/AGENTS.md` and Core to find the authoritative definitions; `overview.md` names the ones each part relates to.

This directory is documentation only. It carries no code and no tests, and it is not part of any package.
